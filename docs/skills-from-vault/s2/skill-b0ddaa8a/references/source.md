## 一句话

移动端不是桌面缩水版：以触控范式、离线优先、商店分发约束驱动的开发与增长闭环。

## 要点
- 范式差异：手势/热区/安全区 · 弱网与离线缓存 · 电量与后台限制 · 推送与深度链接。
- 交付链：原生或跨端选型 → CI 签名分发 → TestFlight/内测 → ASO 与商店审核合规。
- 增长配套：[[uSkill-aso-optimizer]]（ASO）承接安装转化；与 [[移动应用开发]] 中文入口同名映射。
