
# 循环工程-财务智能体红队对抗配置

> 骨架配置 — 待接入 MCP 券商数据

## 核心机制

- **标识符**: `LOOP-TREASURY`
- **触发频率**: 每周（MCP 券商数据拉取完成时触发）
- **自博弈机制**: 候选交易策略 → 纚队模块（`uPrompt-Treasury-Critic`）→ 隔离沙盒黑天鹅行情极限绞杀 → 验证通过 → 签字队列
- **OVP 目标**: 模拟/实盘胜率 ≥ 65%
- **安全爪条件**: 胜率 < 65% 或单笔仓位 > 5%

## 方法论增强（Eugene Yan）

### 双会话纠偏（长回测可选）
回测执行 > 30min 时启用：主会话跑回测，副会话每阶段检查是否偏离原始策略假设（执行漂移）或误解了交易规则（方向漂移）。

### 转录本驱动优化
每月分析回测会话中的"胜率计算错了""这个风险没覆盖到"等修正，更新回测模板和风控规则。

## 🔄 IF/THEN 决策分支

- IF 输入数据质量不足以支撑自动化决策 → THEN 转交人工判断，输出不确定性说明
- IF 执行过程中遇到未预期的异常 → THEN 记录异常 + 降级处理 + 升级给人类
- IF 输出结果置信度 < 0.6 → THEN 标记低置信度 + 要求人工验证
- ELSE（所有检查通过）→ THEN 输出结果 + 验证证据

## ⚠️ 异常处理

| 异常类型 | 触发条件 | 处理方式 |
|---------|---------|---------|
| 输入缺失 | 必填参数为空 | 提示用户补充输入 |
| 格式错误 | 输入格式不符合要求 | 给出格式示例 + 重新输入 |
| 执行超时 | 单次执行超过阈值 | 降级处理 + 记录日志 |
| 结果异常 | 输出明显不合理 | 标记异常 + 人工复核 |

**降级策略**：
- 当 AI 辅助不可用时，回退到手动执行模式
- 当数据源不可用时，使用缓存数据并标注时效性
- 当遇到未知异常时，记录现场 + 升级给人类

```
你是一位投资红队对抗分析师，负责对候选交易策略执行压力测试。请对以下策略进行红队审查：

候选策略名称：[填入策略名称]
策略核心逻辑：[填入买入/卖出条件]
回测数据来源：[填入券商API / K线数据等]
回测时间范围：[填入起止日期]

红队审查要求：
1. 黑天鹅场景模拟：构造 3 个极端市场情景（如闪崩、流动性枯竭、政策突变），评估策略在每种情景下的最大回撤
2. 风控规则验证：检查单笔仓位是否 >5%，止损逻辑是否触发
3. 胜率计算复核：独立验证回测胜率，标注计算方法假设
4. 执行漂移检测：检查策略执行是否偏离原始逻辑

输出格式：
- 红队结论：[PASS / REJECT / CONDITIONAL]
- 黑天鹅回撤：[情景1: X%, 情景2: X%, 情景3: X%]
- 胜率复核：[红队计算胜率] vs [原回测胜率]
- 风控违规：[如有，列出具体违规项]
```
