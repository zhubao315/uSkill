# 🎯 月度指标校准 Agent — 实施手册

> **定位**：每月1日自动对比年度目标vs实际进度，识别偏离，生成调整建议
>
> **关联**：[[uSkill-系统熵增检测-v1]] · [[2026指标仪表盘]] · [[2026年度 OKR]]

---

## 一、Agent 定义

| 字段 | 值 |
|------|-----|
| 名称 | Monthly Calibration Agent |
| 触发 | 每月1日 09:00 / 人工指令「月度校准」 |
| 输入 | 仪表盘基线 + 上月实际数据 |
| 输出 | 月度校准报告 + 调整建议 |
| 红线 | **不修改年度目标**，仅建议调整路径 |

## 三、执行 Prompt

### 月度校准 Prompt（直接使用）

```
你是月度指标校准Agent。请执行本月校准。

【输入数据】
- 校准月份：{month}
- 年度目标：{dashboard_baseline}
- 上月实际值：{last_month_actual}
- 本月实际值：{current_month_actual}

【任务】
1. 逐维度计算达成率 = 当前值 / 年度目标 × 100%
2. 计算月度增量 = 本月值 - 上月值
3. 预测年末达成 = 基于当前速率推算
4. 标记状态：🟢≥90% 🟡70-89% 🔴<70%
5. 识别偏离：达成率 < 年度进度要求（当前月份/12 × 100%）
6. 生成调整建议

【输出格式】
按以下结构输出月度校准报告：

# 🎯 月度校准 — {month}

## 年度进度总览
| 维度 | 年度目标 | 当前值 | 月度增量 | 达成率 | 预测年末 | 状态 |

## 超额完成项
- [维度]：达成XX% → 原因

## 偏离项
- [维度]：达成XX%（应达XX%）→ 偏差-XX% → 根因分析 → 调整建议

## 下月行动计划
1. [最高优先级]
2. [偏差修复]
```

## 五、校准规则

### 状态判定

| 达成率 | 状态 | 含义 | 动作 |
|:------:|:----:|------|------|
| ≥90% | 🟢 | 正常推进 | 维持当前节奏 |
| 70-89% | 🟡 | 需关注 | 分析原因，下月重点 |
| <70% | 🔴 | 严重偏离 | 立即调整策略 |

### 偏离触发条件

| 条件 | 级别 | 动作 |
|------|:----:|------|
| 单月偏离 | 🟡 | 监控+下月重点 |
| 连续2月偏离 | 🔴 | 战略级调整（需审批） |
| ≥3维度🔴 | 🔴🔴 | 触发季度战略复盘 |
