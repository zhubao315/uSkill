## 二、R1-R4 规则引擎

### R1：单日止损

```yaml
rule: R1-单日止损
threshold: -30000  # 单日亏损 ≥ 3万
check_frequency: 实时(交易时段) + 收盘确认
action:
  - 关闭当日交易窗口
  - 推送通知：⚠️ R1触发 | 当日亏损: ¥XX | 建议：停止交易24h
  - 记录到日记：原因+情绪+反思
  - 24h冷静期后可恢复，仓位≤50%
exception:
  - 总仓位<30%时不触发
  - 系统性风险(熔断/全球暴跌)单独评估
```

### R2：周度止损

```yaml
rule: R2-周度止损
threshold: -50000  # 本周累计亏损 ≥ 5万
check_frequency: 每周五收盘后
action:
  - 当日减仓50%
  - 周末强制复盘
  - 生成亏损分析报告 → 04-Investor/亏损分析/
  - 下周仓位≤50%，直到连续2周盈利
exception:
  - 月度回撤>8% → 直接R4评估
```

### R3：行业集中度

```yaml
rule: R3-行业集中度
threshold: 0.30  # 单行业 >30%
check_frequency: 每日收盘后 + 每周一9:30
formula: "行业占比 = (单行业持仓市值) / (总持仓市值) × 100%"
action:
  - 推送提醒（不强制减仓）
  - 评估：临时波动 or 结构性问题
  - 结构性问题 → 2周内调整至≤30%
target_allocation:
  半导体: ≤20%
  科创50/AI: ≤20%
  高股息/低波动: ≥20%
  港股/海外: ≤10%
  现金/货基: ≥15%
```

### R4：跨市场敞口

```yaml
rule: R4-跨市场敞口
threshold: 0.10  # 海外 >10%
check_frequency: 每日 + 每周
formula: "海外占比 = (海外持仓市值) / (总持仓市值) × 100%"
action:
  - 评估海外资产与A股相关性
  - 高相关(>0.6) → 2周内减仓至5%
  - 中相关(0.3-0.6) → 减仓至8%
  - 低相关(<0.3) → 可保留但记录
trigger_events:
  - 美股大幅波动(>3%) → 立即评估
  - 港股单日>5% → 立即评估
  - 汇率大幅波动(>2%) → 立即评估
```

### R5：贵金属专项监控（新增）

```yaml
rule: R5-贵金属专项监控
assets:
  - 黄金ETF (华夏/华安)
  - 白银LOF (国投白银)

monitoring_points:
  - 国际金价/银价走势
  - 美联储利率预期
  - 美元指数
  - VIX恐慌指数

thresholds:
  单日波动: ±2%  # 贵金属单日波动超过2%触发预警
  持仓占比: 40%  # 贵金属总持仓超过40%触发预警
  相关性: 0.8    # 黄金白银相关性超过0.8提示冗余
action:
  - 分析贵金属走势与宏观因素关联
  - 评估持仓合理性
  - 生成贵金属专项分析报告

## 七、每日执行流程

### 时段 1：收盘后（15:30）

```
Step 1: 采集当日数据
  - 输入：持仓列表 + 收盘价
  - 计算：当日盈亏、持仓市值、行业分布

Step 2: R1-R3 检查
  - 当日盈亏、行业集中度检查

Step 3: 贵金属专项分析
  - 国际金价/银价走势分析
  - 宏观因素关联分析
  - 持仓合理性评估

Step 4: 短期预测
  - 技术面、资金面、情绪面分析
  - 生成短期走势预测

Step 5: 研报收集
  - 扫描最新研报
  - 生成研报摘要

Step 6: 生成日报 + 结论
```

### 时段 2：晚间（21:00）

```
Step 7: 海外市场检查
  - 美股/港股开盘情况
  - 汇率波动

Step 8: R4 检查
  - 海外持仓占比
  - 触发事件检测

Step 9: 贵金属晚间分析
  - 国际市场贵金属走势
  - 与A股相关性评估

1. 不得违反相关法律法规和平台规则
2. 不得泄露用户隐私数据
3. 不得在未经验证的情况下做出不可逆决策

## 🔒 Gated Workflow `[v3新增]`

> 来源：addyosmani 的门禁 + claude-skills 的 Agent Harness

```
DISCUSS → PLAN → EXECUTE → VERIFY → CLOSE
   ↓         ↓        ↓          ↓        ↓
 Context   方案     执行      证据     Done/
 Read     确认     任务      检查    Escalate
```

### Phase 1: DISCUSS
- [ ] 输出 Context Read 一行判断
- [ ] 确认用户意图
- [ ] 确认约束条件

### Phase 2: PLAN
- [ ] 制定执行方案
- [ ] 确认资源可用
- [ ] 人工审批计划

### Phase 3: EXECUTE
- [ ] 逐个任务实现
- [ ] 每步有输出记录

### Phase 4: VERIFY
- [ ] 检查核心输出
- [ ] 验证完整性
- [ ] 输出证据

### Phase 5: CLOSE
- [ ] 所有检查通过 → 标记完成
- [ ] 有未通过项 → 升级给人类
- [ ] 预算耗尽 → 强制升级，不伪装成功

## 🔄 IF/THEN 决策分支

- IF 市场处于恐慌状态（VIX > 30）→ THEN 启动逆向投资检查清单，评估是否为买入机会
- IF 持仓集中度 > 40%（单只股票）→ THEN 触发分散化建议，降低单一风险
- IF 浮亏 > 20% → THEN 启动止损审查，判断是基本面变化还是市场波动
- ELSE（市场平稳 + 持仓合理）→ THEN 输出维持建议 + 定投计划

## 🎯 技能概述

> 本技能提供 投资理财 领域的标准化操作流程，帮助用户高效完成相关任务。

**核心价值**：将复杂操作标准化为可重复执行的步骤，降低出错率，提升效率。

**适用场景**：
1. 日常操作执行
2. 新手快速上手
3. 质量一致性保证
