# 游戏音频设计

## 🎯 目标

> 构建沉浸式音频系统，让声音成为游戏体验的隐形增强器。

**核心价值**：好的游戏音频玩家注意不到，但关掉后立刻觉得「少了什么」。本 Skill 将音频设计标准化为可实现的技术规格。

## 📥 输入

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|:----:|--------|------|
| `audio_scope` | enum | ✅ | — | 范围：`sfx`（音效）/ `music`（音乐）/ `ambient`（环境音）/ `spatial`（空间音频）/ `full`（全套） |
| `engine` | enum | ❌ | `"unity"` | 引擎：`unity` / `unreal` / `godot` |
| `middleware` | enum | ❌ | `"none"` | 音频中间件：`none` / `fmod` / `wwise` |
| `platform` | enum | ❌ | `"mobile"` | 目标平台 |
| `budget` | object | ❌ | — | 音频预算（同时播放数/内存/文件大小） |

## 📋 执行步骤

### Step 1: 音频设计规划
1. **优先级分级** — S 级（UI/战斗反馈）> A 级（环境叙事）> B 级（装饰音）
2. **空间规划** — 哪些音效需要 3D 空间化，哪些是全局
3. **自适应规则** — 音乐/环境音如何根据游戏状态变化
4. **检查点**：✅ 音效优先级是否分级？空间化方案是否确定？

### Step 2: 音效制作与整合
1. **音效制作** — 录音/合成/编辑/混音
2. **引擎整合** — 创建 Audio Event，配置触发条件
3. **空间化配置** — 设置衰减曲线、遮挡、混响区域
4. **检查点**：✅ 音效是否与视觉反馈同步？空间化是否正确？

### Step 3: 音乐与环境音
1. **分层音乐** — 根据游戏状态叠加不同音乐层
2. **无缝循环** — 避免循环点的突兀感
3. **环境音景** — 根据区域/时间/天气切换环境音
4. **检查点**：✅ 音乐切换是否无缝？环境音是否匹配场景？

### Step 4: 优化与测试
1. **内存优化** — 压缩格式、流式加载、按需卸载
2. **同时播放数** — 限制同时播放的音效数量
3. **设备测试** — 在目标设备上测试音频延迟和音质
4. **检查点**：✅ 内存是否在预算内？设备测试是否通过？

## ⚠️ 异常处理

| 异常 | 条件 | 处理方式 |
|------|------|----------|
| 音效延迟 | >100ms | 预加载关键音效、优化文件大小 |
| 同时播放爆音 | 超过通道限制 | 按优先级剔除低优先级音效 |
| 循环疲劳 | 重复感明显 | 增加音乐变体、使用分层混合 |

## 💬 沟通风格

- **感官优先**：先描述「玩家听到什么感受」，再说技术实现
- **具体到毫秒**：音效延迟精确到 ms，不说「差不多同步」
- **预算思维**：每个音效都有内存和通道预算

## 📝 自检清单

- [ ] 音效是否与视觉反馈同步（<50ms）？
- [ ] 是否做了空间化衰减配置？
- [ ] 音乐循环是否无缝？
- [ ] 内存是否在预算内？
- [ ] 同时播放数是否有限制？
- [ ] 目标设备是否测试过？
