
# uSkill 引用桥接方案

> 解决 71%（485/674）uSkill 零入链的结构性问题

---

## 问题诊断

| 指标 | 数值 |
|------|------|
| uSkill 总数 | 674 |
| 零入链（孤立） | 485（71%） |
| 有入链 | 189（28%） |
| 高价值孤立（>5KB） | 327 |

**核心问题**：uSkill 被创建后，没有被日记、项目笔记、概念笔记引用，变成了「写了但没人看」的知识孤岛。

---

## 桥接策略

### 策略一：日记织链（最高效）

**规则**：每次写日记时，如果内容涉及某个领域，末尾自动织入该领域最相关的 uSkill wikilink。

**执行方式**：
1. 写完日记正文后，扫描内容关键词
2. 匹配 uSkill 名称或内容关键词
3. 在 `## 🔗 相关` 区域添加 1-3 个 uSkill 链接

**示例**：
```
## 🔗 相关
- [[肖雪]]
- [[跑步训练计划]]
- [[uSkill-health-lifestyle-plan-outdoor-expedition]]  ← 新增桥接
```

### 策略二：概念笔记挂载（中等效率）

**规则**：01-BRAIN 概念笔记的「知识关联」区域，挂载相关 uSkill 作为「实践方法」。

**执行方式**：
1. 概念笔记已有上游/下游关联
2. 新增「实践方法」层级，指向具体 uSkill
3. 每个概念笔记挂载 1-2 个最相关的 uSkill

**示例**：
```markdown
## 知识关联
- **上游概念**：[[内心堡垒]]
- **实践方法**：[[uSkill-thinking-first-principles]] ← 新增桥接
```

### 策略三：项目笔记嵌入（低频但高价值）

**规则**：项目笔记中涉及具体 SOP/工具时，嵌入对应 uSkill 的引用。

## 🛡️ Three-Tier Boundaries `[v3新增]`

> 来源：addyosmani/agent-skills 的边界系统

### ✅ Always do（自动执行）
- 执行核心功能（见原技能流程）
- 输出结构化结果
- 检查常见错误

### ⚠️ Ask first（先问再做）
- 用户意图不明确时
- 操作不可逆时
- 涉及外部系统时

### 🚫 Never do（绝对禁止）
- 不跳过验证步骤
- 不在用户未确认时执行高风险操作
- 不伪装成功（失败就上报）

## 🔒 Gated Workflow `[v3新增]`

> 来源：addyosmani 的门禁 + claude-skills 的 Agent Harness

```
DISCUSS → PLAN → EXECUTE → VERIFY → CLOSE
   ↓         ↓        ↓          ↓        ↓
 Context   方案     执行      证据     Done/
 Read     确认     任务      检查    Escalate
```

### Phase 1: DISCUSS
- [ ] 输出 Context Read 一行判断
- [ ] 确认用户意图
- [ ] 确认约束条件

### Phase 2: PLAN
- [ ] 制定执行方案
- [ ] 确认资源可用
- [ ] 人工审批计划

### Phase 3: EXECUTE
- [ ] 逐个任务实现
- [ ] 每步有输出记录

### Phase 4: VERIFY
- [ ] 检查核心输出
- [ ] 验证完整性
- [ ] 输出证据

### Phase 5: CLOSE
- [ ] 所有检查通过 → 标记完成
- [ ] 有未通过项 → 升级给人类
- [ ] 预算耗尽 → 强制升级，不伪装成功

## 🔄 IF/THEN 决策分支

- IF 输入数据质量不足以支撑自动化决策 → THEN 转交人工判断，输出不确定性说明
- IF 执行过程中遇到未预期的异常 → THEN 记录异常 + 降级处理 + 升级给人类
- IF 输出结果置信度 < 0.6 → THEN 标记低置信度 + 要求人工验证
- ELSE（所有检查通过）→ THEN 输出结果 + 验证证据

## 🎯 技能概述

> 本技能提供 通用 领域的标准化操作流程，帮助用户高效完成相关任务。

**核心价值**：将复杂操作标准化为可重复执行的步骤，降低出错率，提升效率。

**适用场景**：
1. 日常操作执行
2. 新手快速上手
3. 质量一致性保证

## 📋 Verification Evidence `[v3新增]`

> 来源：addyosmani 的证据要求 + claude-skills 的 verify

### 完成标志
- [ ] 核心输出已生成
- [ ] 输出格式符合预期
- [ ] 无明显错误

### 失败处理
- 输出不完整 → 继续补充，不标记完成
- 连续 3 次失败 → 升级给人类，附上当前状态
- 绝不伪装成功
