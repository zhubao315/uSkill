# 后视镜陷阱识别术

# 🛠️ 后视镜陷阱识别术

## 1. 技能定义

基于麦克卢汉"后视镜思维"（Rearview Mirror Thinking）理论，建立一套识别并突破认知框架惯性的操作方法论。核心原则是"不用旧框架理解新媒介"——当新技术出现时，强制悬置上一代媒介的思维框架，让新媒介自己说话。

## 2. 底层原理

麦克卢汉指出："我们透过后视镜来观察现在，我们倒退着走向未来。"

后视镜思维的本质是**认知惯性**：大脑偏好用已知框架理解未知，因为这样消耗的认知资源最少。但代价是错失新媒介真正的可能性窗口。

典型表现：
- 汽车刚被发明时叫"无马马车"（horseless carriage）
- 人们问"AI会不会替代我的工作"（用工具论框架套认知媒介）
- 人们问"AI和互联网有什么区别"（用旧媒介分类框架套新物种）

突破方法是建立**框架悬置**能力——暂时放下旧框架，用"空白框架提问法"替代后视镜提问法。

## 3. 运行协议

**协议 1：后视镜识别检测（Rearview Mirror Detection）**
1. 检测是否出现后视镜语言：'这不过是……的升级版'、'这和……没什么区别'、'这能用来做……'
2. 若出现 → 触发"后视镜警告"
3. 强制切换到"空白框架模式"

**协议 2：空白框架提问法（Blank Frame Questioning）**
1. 将后视镜问题替换为第二人称问题：
   - 后视镜：'AI能替代什么工作？' → 空白：'因为AI，什么以前不可能的事变得可能了？'
   - 后视镜：'AI和互联网有什么区别？' → 空白：'AI创造了什么全新的社会形态？'
2. 强制写出3个"不可能之事变为可能"的场景
3. 对每个场景追问二阶效应

**协议 3：媒介考古对话（Media Archaeology Dialogue）**
1. 找到新技术的"历史前身"（如AI→印刷术→文字）
2. 分析前身媒介引发的文明变革
3. 对比前身与当前媒介的差异
4. 从差异中推导"不可预见的变革方向"

**协议 4：框架悬置练习（Frame Suspension Practice）**
1. 面对新技术时，先写下你的第一反应（后视镜框架）
2. 将第一反应放在一边，强制自己用"我不知道它会怎样"的空白状态重新观察
3. 用10分钟写出"如果我从未见过任何类似技术，我会如何想象它的可能性"
4. 对比两份笔记，识别后视镜盲区

## 🛡️ Three-Tier Boundaries `[v3新增]`

> 来源：addyosmani/agent-skills 的边界系统

### ✅ Always do（自动执行）
- 执行核心功能（见原技能流程）
- 输出结构化结果
- 检查常见错误

### ⚠️ Ask first（先问再做）
- 用户意图不明确时
- 操作不可逆时
- 涉及外部系统时

### 🚫 Never do（绝对禁止）
- 不跳过验证步骤
- 不在用户未确认时执行高风险操作
- 不伪装成功（失败就上报）

## 🔒 Gated Workflow `[v3新增]`

> 来源：addyosmani 的门禁 + claude-skills 的 Agent Harness

```
DISCUSS → PLAN → EXECUTE → VERIFY → CLOSE
   ↓         ↓        ↓          ↓        ↓
 Context   方案     执行      证据     Done/
 Read     确认     任务      检查    Escalate
```

### Phase 1: DISCUSS
- [ ] 输出 Context Read 一行判断
- [ ] 确认用户意图
- [ ] 确认约束条件

### Phase 2: PLAN
- [ ] 制定执行方案
- [ ] 确认资源可用
- [ ] 人工审批计划

### Phase 3: EXECUTE
- [ ] 逐个任务实现
- [ ] 每步有输出记录

### Phase 4: VERIFY
- [ ] 检查核心输出
- [ ] 验证完整性
- [ ] 输出证据

### Phase 5: CLOSE
- [ ] 所有检查通过 → 标记完成
- [ ] 有未通过项 → 升级给人类
- [ ] 预算耗尽 → 强制升级，不伪装成功

## 📋 Verification Evidence `[v3新增]`

> 来源：addyosmani 的证据要求 + claude-skills 的 verify

### 完成标志
- [ ] 核心输出已生成
- [ ] 输出格式符合预期
- [ ] 无明显错误

### 失败处理
- 输出不完整 → 继续补充，不标记完成
- 连续 3 次失败 → 升级给人类，附上当前状态
- 绝不伪装成功

## 🔄 IF/THEN 决策分支

- IF 执行预算耗尽（token/时间）→ THEN 强制升级给人类，不伪装成功
- IF 输入数据质量不足以支撑决策 → THEN 转交人工判断，输出不确定性说明
- IF 检测到循环依赖（A 等 B，B 等 A）→ THEN 打破循环，选择一方先执行
- ELSE（所有检查通过）→ THEN 输出结果 + 验证证据
