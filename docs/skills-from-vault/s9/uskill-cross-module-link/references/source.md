# 🔗 uSkill-317: 跨模块联动

## 🎯 目标

> 检查 uSkill↔uWise↔uRead 三方数据联动，识别孤立词条，提升知识图谱连通性。

---

## 📥 输入

| 参数 | 类型 | 必填 | 说明 |
|------|------|:----:|------|
| `modules` | `array` | ❌ | 需检查的模块（默认全部） |

---

## 📤 输出

```json
{
  "link_density": [{"pair": "string", "links": "number", "target": "number"}],
  "orphan_entries": [{"entry": "string", "module": "string", "suggestion": "string"}],
  "recommendations": ["string"]
}
```

---

## 🔄 执行流程

```
1. [链接扫描] → 扫描各模块间 wikilink
   → IF 模块目录不存在 → 跳过该模块+标注
   → 扫描范围：uSkill↔uWise、uSkill↔uRead、uWise↔uRead

2. [密度计算] → 计算链接密度
   → 密度 = 链接数 / 词条数
   → 目标密度 ≥ 2
   → IF 密度 < 1 → 标注"链接严重不足"

3. [孤立识别] → 识别孤立词条
   → 标准：外部链接数 = 0
   → IF 孤立率 > 10% → 标注"知识孤岛风险"

4. [联动建议] → 生成链接建议
   → 孤立词条 → 建议链接到相关词条
   → 密度低 → 建议增加交叉引用
   → THEN 输出具体链接建议

5. [质量自检] → 验证检查结果
   - [ ] 所有模块已扫描
   - [ ] 链接密度计算正确
   - [ ] 孤立词条列表完整
   - [ ] 建议具体可执行

6. [输出报告] → 链接密度 + 孤立列表 + 联动建议
```

---

## 📝 Prompt 模板

### 标准联动 Prompt

```
你是跨模块联动Agent。请检查三方数据联动。

【检查模块】{modules}

【联动维度】
1. 链接密度：各模块间链接数/词条数
2. 孤立词条：无外部链接的词条
3. 联动建议：增加链接的具体建议

【输出格式】
按标准 JSON 输出，包含 link_density、orphan_entries、recommendations。
```

## ⚠️ 异常处理

| 异常场景 | 处理方式 | 降级策略 |
|----------|----------|----------|
| 模块目录不存在 | 跳过该模块 | 仅检查存在的模块 |
| 链接格式异常 | 尝试解析 | 跳过无法解析的链接 |
| 无孤立词条 | 输出"链接健康" | — |

## 🔒 Gated Workflow `[v3新增]`

> 来源：addyosmani 的门禁 + claude-skills 的 Agent Harness

```
DISCUSS → PLAN → EXECUTE → VERIFY → CLOSE
   ↓         ↓        ↓          ↓        ↓
 Context   方案     执行      证据     Done/
 Read     确认     任务      检查    Escalate
```

### Phase 1: DISCUSS
- [ ] 输出 Context Read 一行判断
- [ ] 确认用户意图
- [ ] 确认约束条件

### Phase 2: PLAN
- [ ] 制定执行方案
- [ ] 确认资源可用
- [ ] 人工审批计划

### Phase 3: EXECUTE
- [ ] 逐个任务实现
- [ ] 每步有输出记录

### Phase 4: VERIFY
- [ ] 检查核心输出
- [ ] 验证完整性
- [ ] 输出证据

### Phase 5: CLOSE
- [ ] 所有检查通过 → 标记完成
- [ ] 有未通过项 → 升级给人类
- [ ] 预算耗尽 → 强制升级，不伪装成功
