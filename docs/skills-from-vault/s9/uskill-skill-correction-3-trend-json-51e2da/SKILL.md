# Correction #3 — 监控面板数据与 trend.json 脱节

## 原始问题

调度入口的监控仪表板区域（第七节）写死了 6/26 的快照数据（10,158篇、断链率1.6%、复用率50.6%），但 trend.json v1.9（7/2）已更新为 9,761篇、断链3条、复用率83.7%。面板数字与数据源脱节超过 7 天。

## 错误输出

```
全库: 10,158篇    ← 已过期
断链率: 1.6%      ← 已过期
复用率: 50.6%     ← 已过期（实际83.7%）
```

## 修正后输出

```
全库: 9,761篇     ← 对齐 trend.json v1.9
断链: 3条         ← 对齐 trend.json v1.9
复用率: 83.7%     ← 对齐 trend.json v1.9
```

## 规则提取

1. 监控面板的数字不得写死，必须标注数据源和时间戳
2. 每次审计完成后，调度入口的状态面板应自动刷新
3. 面板应改为指令性文本（"从 trend.json 读取"），而非静态数字

## 归档规则

- 该错误已修正 1 次
- 再出现 2 次则升级为「绝对禁令」写入 Core Prompt
