
# uSkill-关系网络连接器衰减预警

> 关系网络连接器（Social Capital Connector）的关系衰减预警，维护高质量社会资本。

---

## 工程定位

### 核心目标

- **核心圈规模**：9-12人亲密核心圈
- **衰减标准**：90天未互动
- **决策机制**：人工签字拦截

### 运行环境

- **部署位置**：个人云加密本地存储
- **数据来源**：合规沟通日志（NLP）与核心关系图谱
- **隐私保护**：数据已脱敏

---

## 衰减监测机制

### 监测维度

- **互动频率**：沟通频率统计
- **互惠度**：双向互动的平衡性
- **深度指标**：深度交流的比例

### LQS评分

- **多维评分**：连接质量分数（Link Quality Score）
- **基线对比**：与历史基线对比
- **趋势分析**：衰减趋势分析

### 预警条件

- **时间阈值**：90天未深度互动
- **分数阈值**：LQS跌破基线
- **断崖下跌**：分数出现断崖式下跌

## 提示词（uPrompt-Social-Connector）

```markdown
# Role
你是运行在个人云加密存储底座上的【关系网络连接器（Social Capital Connector）】。

# Context
为了维护高质量的社会资本，系统设定了 9-12 人的亲密核心圈，并要求通过沟通频率、互惠度进行连接质量分数（LQS）多维评分。

# Input Data
* 当前 9-12 人亲密核心圈名单：{{Core_Circle_List}}
* 过去 90 天本地加密通讯日志统计（已脱敏）：{{NLP_Interaction_Logs}}

# Task
1. 计算亲密核心圈内每个节点的最新互动衰减指数。
2. 如果发现有核心圈成员满足【90天未互动】或 LQS 分数出现断崖式下跌，自动标记为"衰减预警"。
3. 严禁全自动拉黑或替换成员！生成一份核心圈变动提议，等待调度主体月度复盘时进行【人工签字决策】。

# Output Format
### ⚠️ 关系衰减与核心圈变动预警
1. **衰减检测：** 节点 [姓名] 已有 XX 天无深度互动，LQS 评分已跌破基线。
2. **红队评估：** 该节点属于高价值深度连接，不建议直接降维，触发"需重新激活"标记。
3. **【人在环路签字请求】：**
   * [ ] 方案 A：授权连接器在下周日程中自动编排一次主动深度连接（语音/会面）。
   * [ ] 方案 B：月度复盘时确认该成员调出核心圈，补位新节点。
```

## 执行配置

### 触发词

`「检查关系衰减预警」`

### Cron 规则

- **每周日**：通讯日志同步完成后触发
- **事件触发**：LQS 断崖式下跌 >20% 时立即预警

### 与 Daily Loop 联动

- 晨间计划读取衰减预警，纳入社交任务建议
- 晚间复盘确认当日是否完成主动连接

### 异常重试 SOP

- **通讯日志同步失败**：使用上次缓存数据，标记 `⚠️ 数据源延迟`
- **NLP 脱敏处理异常**：挂起该节点评估，不影响其他节点

## 🔒 Gated Workflow `[v3新增]`

> 来源：addyosmani 的门禁 + claude-skills 的 Agent Harness

```
DISCUSS → PLAN → EXECUTE → VERIFY → CLOSE
   ↓         ↓        ↓          ↓        ↓
 Context   方案     执行      证据     Done/
 Read     确认     任务      检查    Escalate
```

### Phase 1: DISCUSS
- [ ] 输出 Context Read 一行判断
- [ ] 确认用户意图
- [ ] 确认约束条件

### Phase 2: PLAN
- [ ] 制定执行方案
- [ ] 确认资源可用
- [ ] 人工审批计划

### Phase 3: EXECUTE
- [ ] 逐个任务实现
- [ ] 每步有输出记录

### Phase 4: VERIFY
- [ ] 检查核心输出
- [ ] 验证完整性
- [ ] 输出证据

### Phase 5: CLOSE
- [ ] 所有检查通过 → 标记完成
- [ ] 有未通过项 → 升级给人类
- [ ] 预算耗尽 → 强制升级，不伪装成功

## 📥 输入 Schema

| 参数 | 类型 | 必填 | 说明 |
|------|------|:----:|------|
| contact_list | array | ✅ | 核心圈联系人列表（姓名+最近互动日期） |
| interaction_window | number | ❌ | 衰减检测窗口天数（默认 90 天） |
| severity_threshold | enum | ❌ | 告警阈值（low/medium/high，默认 medium） |

## 📤 输出 Schema

| 字段 | 类型 | 说明 |
|------|------|------|
| decay_alerts | array | 衰减告警列表（联系人+衰减天数+建议动作） |
| lqs_score | number | 关系质量评分（0-100） |
| at_risk_count | array | 高风险联系人数量 |

## 🔄 执行流程

1. **数据采集**：从通讯录/日历/社交媒体提取互动记录
2. **衰减计算**：对比当前日期与最近互动日期，计算衰减天数
3. **风险分级**：按衰减天数和关系重要性分级（高/中/低）
4. **建议生成**：为每个衰减联系人生成具体恢复建议
5. **报告输出**：生成衰减预警报告 + 行动清单

## 🔄 IF/THEN 决策分支

- IF 核心圈联系人衰减 > 30 天 → THEN 生成"紧急恢复"建议（如约咖啡/发消息/邀请活动）
- IF LQS 评分 < 40 → THEN 触发深度诊断，检查是否系统性关系维护不足，输出关系健康报告
- IF 同一联系人连续 2 次衰减 → THEN 升级为高优先级，建议安排面对面深度交流
- ELSE（所有联系人衰减 < 15 天）→ THEN 输出"关系健康"状态，无需动作

## 💡 使用示例

- **场景 1**：每周日复盘 — 检查本周与核心圈的互动情况
- **场景 2**：月度关系审计 — 生成 LQS 评分 + 衰减趋势图
- **场景 3**：出差前检查 — 评估出差期间哪些关系需要提前维护
