
# Correction #1 — 跑步数据提取格式

## 原始输入

Agent 从 Daily Note 提取跑步数据时，只提取了距离和配速，遗漏了心率对比。

## Agent 错误输出

```json
{
  "distance": "13.14km",
  "pace": "5'59\"",
  "type": "有氧耐力"
}
```

## 人工黄金修正

```json
{
  "distance": "13.14km",
  "pace": "5'59\"",
  "type": "有氧耐力",
  "heart_rate_comparison": "同配速下比6/29↓17bpm，心肺效率↑",
  "sleep": "6.9h",
  "hrv": "26ms"
}
```

## 规则提取

当提取跑步数据时，必须同时提取：
1. 距离 + 配速 + 类型（基础三件套）
2. 心率对比（如有）
3. 睡眠时长（如有）
4. HRV 数据（如有）

## 归档规则

- 该错误已修正 1 次
- 再出现 2 次则升级为「绝对禁令」写入 Core Prompt

## ⚠️ 异常处理

| 异常类型 | 触发条件 | 处理方式 |
|---------|---------|---------|
| 输入缺失 | 必填参数为空 | 提示用户补充输入 |
| 格式错误 | 输入格式不符合要求 | 给出格式示例 + 重新输入 |
| 执行超时 | 单次执行超过阈值 | 降级处理 + 记录日志 |
| 结果异常 | 输出明显不合理 | 标记异常 + 人工复核 |

**降级策略**：
- 当 AI 辅助不可用时，回退到手动执行模式
- 当数据源不可用时，使用缓存数据并标注时效性
- 当遇到未知异常时，记录现场 + 升级给人类

## 📊 数据采集规范

**必采数据**：
- [[心率变异性（HRV）]]：每日晨起静息心率 + HRV 值
- 睡眠数据：入睡时间/深睡比例/REM 周期/醒来次数
- 运动数据：训练时长/配速/心率区间/恢复时间
- 主观感受：RPE 自觉用力等级（1-10）+ 睡眠质量评分

**采集频率**：
- HRV/心率：每日 1 次（晨起）
- 运动数据：每次训练后
- 主观感受：每日晚间
- 综合评估：每周 1 次

**数据质量要求**：
- 连续采集 ≥ 7 天方可进行趋势分析
- 单日数据缺失不超过 20%
- 异常值（如 HRV 骤降 > 30%）需人工确认

## 📈 分析方法论

**趋势分析**：
- 7 日移动平均：消除日间波动，识别中期趋势
- 周环比/月环比：评估改善或恶化速度
- 基线对比：与个人历史最佳/最差数据对比

**关联分析**：
- HRV × 睡眠质量：评估恢复状态
