# uSkill-指标仪表盘更新

> 自动更新全维度指标仪表盘，确保数据实时性与决策可用性。
> 分类：监控类 | 优先级：P1 | 排期：Q2

---

## 1. 目标定义

- **核心目标**：自动汇总各uSkill的执行数据，更新年度指标仪表盘的6大一级指标与10项二级过程指标，确保数据实时、准确、可决策
- **价值对齐**：与「理性主义」强关联——基于实时数据做决策；与「反熵主义」关联——自动更新对抗手动维护的衰减
- **适用场景**：每日收盘后 / 每周日晚 / 每月末 / 人工指令「更新仪表盘」

---

## 2. 边界约束

- **能力边界**：
  - 能做：数据采集、指标计算、趋势可视化、预测推算、预警检查
  - 不能做：修改目标值（需人类决策）、编造数据、修改历史数据
- **触发条件**：
  - 启动：定时触发（日/周/月） / 人工指令「更新仪表盘」
  - 终止：仪表盘更新完成 + 异常数据标注完成
- **红线规则**：
  - 数据来源必须可追溯
  - 不得修改历史数据（只追加）
  - 异常数据必须标注
  - 不得以估算替代实际数据（估算需明确标注）

### 输入格式
```yaml
inputs:
  update_scope: daily|weekly|monthly  # 必填，更新范围
  data_sources:                       # 必填，数据源引用列表
    - source: string                  # 数据源名称
      type: uSkill|uWise|uRead|external
      ref: string                     # 引用路径
  baseline_dashboard: ref             # 选填，当前仪表盘引用
  override_date: date                 # 选填，覆盖日期（默认今天）
```

## 4. 核心推理链路

```
1. [数据采集] → 从各uSkill/uWise/uRead/外部源采集执行数据
   → 采集范围：根据update_scope确定（daily=当日/weekly=本周/monthly=本月）
   → 判断条件：数据源是否≥80%可用？
     → 是：进入步骤2
     → 否：标注「数据源异常」，使用可用数据+标注缺失
   → 中间产物：原始数据汇总表

2. [指标计算] → 计算达成率、趋势、增量
   → 达成率：当前进度 / 年度目标 × 100%
   → 趋势：与上一周期对比 ↑/↓/→
   → 增量：本周/本月新增
   → 中间产物：指标计算结果表

3. [预测推算] → 基于当前速率推算年末达成
   → 预测公式：当前达成率 + (当前速率 × 剩余时间)
   → 判断条件：预测达成率是否<80%？
     → 是：标记为🟡或🔴
     → 否：标记为🟢
   → 中间产物：预测推算结果

4. [预警检查] → 检查风险预警线
   → 预警规则：
     a. 收入进度 < 时间进度 × 80% → 🔴
     b. 运动跑量 < 月度目标 × 70% → 🟡
     c. uSkill合规率 < 90% → 🔴
   → 判断条件：是否有新触发的预警？
     → 是：标注为新增预警
     → 否：维持上次预警状态
   → 中间产物：预警状态表

5. [仪表盘更新] → 组装更新后的仪表盘
   → 数据质量检查：完整率、异常数据、估算数据标注
   → 历史数据追加：记录本周期数据到历史序列
   → 最终输出：更新后仪表盘 + 数据质量报告 + 预警状态
```
