# 地图制图设计

description: |
  当用户需要设计美观易读的地图、选择配色方案、优化地图布局、制作出版级地图时使用此 Skill。
  触发词：'地图设计'、'制图'、'地图配色'、'地图出图'、'cartography'、'地图美化'。

# [[地图制图设计]]

## 🎯 目标

> 将空间数据转化为视觉清晰、信息有效传达、符合制图规范的地图产品。

**核心价值**：一张好地图的标准不是好看，而是「用户能否在 3 秒内获取核心信息」。本 Skill 将制图流程标准化，确保每个设计决策都服务于信息传达。

**适用场景**：
- 报告/论文配图（出版级地图）
- 城市规划/交通分析可视化
- 跑步/骑行路线图
- 北京文化/建筑/地理专题地图
- Web 地图的底图和数据图层设计

## 📥 输入

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|:----:|--------|------|
| `data_layers` | array | ✅ | — | 待制图的数据图层列表 |
| `map_purpose` | string | ✅ | — | 地图用途（一句话说清这张图要传达什么） |
| `audience` | enum | ❌ | `"general"` | 受众：`general`（公众）/ `technical`（专业）/ `executive`（决策层） |
| `medium` | enum | ❌ | `"screen"` | 媒介：`screen`（屏幕）/ `print`（打印）/ `both` |
| `style` | enum | ❌ | `"modern"` | 风格：`modern`（现代简洁）/ `classic`（经典制图）/ `dark`（暗色主题）/ `data_viz`（数据可视化） |
| `size` | enum | ❌ | `"a4"` | 尺寸：`a4` / `a3` / `banner` / `square` / `custom` |
| `colorblind_safe` | boolean | ❌ | `true` | 是否强制色盲友好配色 |

## 📋 执行步骤

### Step 1: 设计策略
1. **信息层次** — 确定：用户第一眼看什么？第二眼？第三眼？
2. **配色方案** — 根据数据类型选择：顺序色（量级）/ 分歧色（偏差）/ 分类色（类别）
3. **色盲检查** — 使用 ColorBrewer 或 Coblis 模拟色盲视角
4. **检查点**：✅ 信息层次是否明确？配色是否色盲友好？

### Step 2: 符号化与标注
1. **符号设计** — 点/线/面符号的大小、颜色、透明度
2. **标注规则** — 重要要素大字标注，次要要素小字或不标注
3. **标注避让** — 设置标注优先级和避让规则，避免重叠
4. **检查点**：✅ 标注是否清晰可读？是否有重叠？

### Step 3: 布局排版
1. **主图区域** — 占版面 60-70%，居中或偏左
2. **图例** — 放置在空白区域，不遮挡数据
3. **辅助元素** — 比例尺、指北针、标题、数据来源、制作日期
4. **留白** — 不要填满每个角落，适当留白增加呼吸感
5. **检查点**：✅ 所有必要元素是否齐全？布局是否平衡？

### Step 4: 输出与验证
1. **屏幕输出** — 分辨率 ≥150dpi，RGB 色彩模式
2. **打印输出** — 分辨率 ≥300dpi，CMYK 色彩模式，出血线
3. **验证测试** — 给非专业用户看 3 秒，问"这张图在说什么"
4. **检查点**：✅ 输出分辨率是否达标？非专业用户能否理解？

## ⚠️ 异常处理

| 异常 | 条件 | 处理方式 |
|------|------|----------|
| 配色争议 | 不确定用什么配色 | 优先选 ColorBrewer 方案，让数据说话 |
| 标注冲突 | 标注太多太密 | 设置标注优先级，次要标注改为 hover 显示 |
| 跨平台色差 | 打印与屏幕颜色不一致 | 用 ICC 校色，打印前打样验证 |

## 💬 沟通风格

- **设计导向**：先说"用户应该看到什么"，再说"怎么实现"
- **具体到像素**：字体大小精确到 pt，间距精确到 mm
- **证据驱动**：用色盲模拟工具验证，不凭感觉判断

## 📝 自检清单

- [ ] 配色是否色盲友好？
- [ ] 信息层次是否清晰（1/2/3 眼）？
- [ ] 标注是否有避让规则？
- [ ] 图例是否能让非专业用户理解？
- [ ] 所有文字在缩放后是否可读？
- [ ] 打印版本是否经过 CMYK 转换？
