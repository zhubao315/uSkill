
# Correction #2 — 数据契约字段名不匹配

## 原始问题

调度入口提示词中引用 `{{broken_link_rate}}`，但 trend.json v1.9 的实际字段是 `broken_links_total`（绝对数，非百分比）。数据契约 v1 未做字段别名映射，导致调度层读取时拿到空值。

## 错误输出

```markdown
断链率: {{broken_link_rate}}%  ← trend.json 中不存在此字段
```

## 修正后输出

```markdown
断链: {{broken_links_total}}条  ← 与 trend.json 字段对齐
```

## 规则提取

1. 数据契约的字段映射必须与 trend.json schema 逐字段对齐，不能假设字段名
2. 调度层消费 trend.json 前，应先校验必填字段是否存在，缺失则标记 `⚠️ 数据源异常`
3. 新增字段时，数据契约 v1.1 必须同步更新映射表

## 归档规则

- 该错误已修正 1 次
- 再出现 2 次则升级为「绝对禁令」写入 Core Prompt
