## 🎯 目标

在遇到绝对化断言、权威说教、群体狂热或自身执念时，部署「Que sais-je?」怀疑杠杆打断认知惯性，将外部断言的信息权重调低 50%，保留选择空间。

**核心公式**：`认知自由度 = 断言输入 × 反例数 / 情绪唤醒度`

### 适用信号
1. 对方使用“绝对”“必然”“所有人都”等全称量词。
2. 自身产生强烈情绪认同或反感。
3. 群体出现 FOMO 式一致预期（尤其投研场景，参见[[循环工程-财务智能体红队对抗配置]]）。

### 战略价值
防火墙不是否定工具，而是**认知防御 + 行动保障**的双层机制：怀疑针对认知，不阻塞行动。它把蒙田式“我知道什么？”(Que sais-je?) 转化为可执行的三相协议，是[[元认知-Schema]]在每日决策中的最小可行单元。

### 三大铁律
1. **先写后疑**：断言必须落笔，才允许启动怀疑，防止空转。
2. **三反例门槛**：未列满 3 条成立反例前，不得下调权重。
3. **认知行动分离**：怀疑只改权重，不替行动做否决。

## 📥 输入

| 输入项 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| 断言/建议 | 文本 | 是 | 来自外部（权威/群体）或内部（自身执念）的确定性陈述 |
| 情绪唤醒度 | 0–10 数值 | 否 | 当下对断言的情绪强度；缺省按自报估算 |
| 上下文标签 | 文本 | 否 | 如“投研”“技术选型”“人际”，用于触发差异化的反例库 |
| 历史反例缓存 | 列表 | 否 | 此前同类断言被证伪的案例，用于加速怀疑插入 |

**输入校验前置**：IF 断言为空 THEN 跳过协议；IF 上下文=高风险领域（法律/财务/医疗）THEN 强制升级人工确认。

---

## 📤 输出

1. **降级后的断言权重**：原信息权重 × 0.5（基础怀疑系数，可按反例数进一步下调）。
2. **3 条不依赖该断言也能成立的反例**：结构化列表。
3. **决策分离结论**：明确“认知上保留怀疑 / 行动上按现行框架执行”。
4. **防火墙日志条目**：写入当日复盘，关联[[元认知-Schema]]。

## 🔄 执行流程

### Phase 1: 触发识别
当以下信号出现时自动激活防火墙：全称量词、强情绪认同/反感、群体 FOMO 一致预期。

### Phase 2: 怀疑插入
默念触发词 **Que sais-je?**，执行 3-反例协议：
1. 将断言写下来。
2. 强制列出 3 个不依赖该断言也能成立的反例。
3. 评估原断言信息权重是否应下调。

### Phase 3: 决策分离
- 怀疑是针对**认知**的防御工具，不是**行动**的障碍。
- 区分“依照规则生活”（行动上遵循现行框架）与“依照理性思考”（认知上保持独立）。

### 决策分支（IF/THEN）
- IF 上下文=投研且群体 FOMO 强烈 THEN 信息权重强制下调至 ≤0.3，并触发[[循环工程-财务智能体红队对抗配置]]红队复核。
- IF 反例数 ≥ 3 且情绪唤醒度 > 7 THEN 暂停行动 24h，仅记录不决策。
- IF 断言来自高可信源（如已验证的[[风控规则手册]]）THEN 怀疑系数降至 0.8，不强制降权。
- IF 连续 3 次对同一类断言触发防火墙 THEN 沉淀为独立 K3 元认知卡片，纳入[[元认知-Schema]]长期监控。

### 认知自由度公式说明
`认知自由度 = 断言输入 × 反例数 / 情绪唤醒度`
- **断言输入**：该断言对你当前决策的信息权重（默认 1.0）。
- **反例数**：Phase 2 中实际列出的成立反例数量（0–N）。
- **情绪唤醒度**：当下对断言的情绪强度（0–10）；越高，认知自由度越低。
- 示例：断言输入 1.0、反例 3、唤醒度 6 → 自由度 = 1.0×3/6 = 0.5，即信息权重应下调 50%。

### 反例演练库（真实场景）
| 断言 | 上下文 | 反例① | 反例② | 反例③ | 处置 |
|------|--------|-------|-------|-------|------|
| “AI 算力股必然翻倍” | 投研/FOMO | 2022 算力杀估值 | 需求不及预期 | 政策限电 | 权重 ≤0.3 + 红队复核 |
| “这个架构方案绝对最优” | 技术选型 | 历史同类方案运维债高 | 团队不熟该技术 | 可替代方案更省 | 降权 + 留观察 |
| “大厂都在用所以没错” | 人际/从众 | 大厂也曾集体误判 | 场景与己不同 | 成本结构差异 | 仅记录不行动 |

### 日常嵌入节奏
防火墙不依赖独立会话，而是嵌入既有循环：

| 时机 | 嵌入点 | 触发动作 |
|------|--------|----------|
| 晨间计划 | [[uSkill-agent-每日领域共生循环系统]] 任务生成 | 对“必做”类断言插怀疑杠杆 |
| 投研决策 | [[对冲信号监测器]] 信号触发 | 群体 FOMO 时强制降权 |
| 晚间复盘 | 当日对话提炼 | 记录被触发的断言与反例 |
| 红队复核 | [[循环工程-财务智能体红队对抗配置]] | 策略签字前最后一次怀疑 |

### 与元认知-Schema 的关系
本协议是[[元认知-Schema]]的“防火墙”相的最小可执行单元。Schema 另含「暂停」与「觉察」两相：当防火墙识别出强情绪唤醒（>7）且反例充分时，应升级为「暂停」相，留出 24h 冷却；「觉察」相则负责事后把本次触发沉淀为 K3 元认知卡片，形成长期免疫。三者合流方为完整元认知闭环。

## 📝 Prompt 模板

- **怀疑杠杆注入**: `你是我的“怀疑杠杆”审查官。下面这条断言：“[粘贴断言]”，上下文是“[投研/技术/人际]”，我的情绪唤醒度自评 [0-10]。请：1. 指出其中的全称量词或隐含假设；2. 给出 3 个不依赖该断言也能成立的反例；3. 建议该断言应保留的信息权重（0-1）。`
- **反例压力测试**: `针对决策“[决策描述]”，请扮演红队，列出 3 个可能让它彻底失效的情景，并说明每个情景下我的损失边界。`

## ⚠️ 异常处理

| 异常 | 触发条件 | 处置 |
|------|----------|------|
| 反例枯竭 | 无法列出 ≥3 反例 | 降低怀疑系数至 0.8，标注“待观察”，不阻断行动 |
| 情绪过载 | 唤醒度 > 9 | 强制暂停，转人工/物理活动，24h 内不决策 |
| 权威压制 | 断言来自不可质疑的高位 | 仍执行最小怀疑，记录“被迫接受”日志供事后复盘 |
| 过度怀疑 | 对一切断言都插杠杆 | 回退：仅对全称量词与高唤醒场景触发，避免分析瘫痪 |

**硬约束**：不得因怀疑而阻塞必要的合规/安全行动；高风险领域须人工兜底。
