## 🔄 执行流程

### 控制台一：晨间计划 (08:00 AM)
**核心逻辑**：依据 Operator 所在领域（四维身份 + 隐藏身份），每天早上 8 点生成一份待办清单。清单包含 **5 个具体的任务建议**，并为每个任务提供**详细的概要实施方案**。不按紧急程度排单，而从核心领域提取高价值“机会窗”。
- **触发词**：`「执行晨间计划」`
- **任务生成规则**：
  1. 从四维身份（架构师/投资人/终身学习者/生活艺术家）+ 隐藏身份（摄影/健身/国学等）中选取当日最高杠杆的 5 个领域
  2. 每个任务必须有：具体动作 + 详细实施方案（3-5 步）+ 预期成果物
  3. 至少覆盖 3 个不同身份维度，避免单维度偏科
- **决策分支**：
  - IF `Dominant_Domain_Pct >= 40%` THEN 消减 30% IT 编码，向恢复流倾斜。
  - IF 审计快照存在“待修复”项 THEN 将审计修复作为 5 个任务之一纳入。
  - → 否：标准五任务调度。

### 控制台二：午间资讯 (12:00 PM)
**核心逻辑**：拒绝垃圾信息，强制锁定**分布式四源降级组合**（实测 36kr 不可用、华尔街见闻受限）。
- **触发词**：`「执行午间资讯」`
- **决策分支**：
  - IF 主源超时 THEN 自动切换至 HN Firebase + 机器之心 + 东方财富 + GitHub Trending。
  - IF 某领域当日无新知 THEN 复用昨日高价值条目并标注“延续观察”。

### 控制台三：晚间复盘 (20:00 PM)
**核心逻辑**：解构当日对话与闪念，执行**双链织入协议**：每篇新建/修改笔记强制检索 2–3 篇语义相关已有笔记，末尾织入 `## 相关` 与 `wikilink`，断链率死锁 <5%（实测 1.6% ✅）。
- **触发词**：`「开始晚间复盘」`
- **决策分支**：
  - IF 新建笔记未织入 ≥2 双链 THEN 阻断落盘，回补链接后再归档。
  - IF 当日对话含投研决策 THEN 同步触发[[循环工程-财务智能体红队对抗配置]]复核。

### 控制台四：每日灵感 (09:00 AM)
**核心逻辑**：基于 `02-BUILD/26-人工智能/uPrompt/创作/提示词-创作-每日.md` 中的模板矩阵，每日 9 点由 `09-REFERENCE/93-脚本/daily_inspiration_generator.py`（L1）自动生成「每日灵感」骨架，覆盖每日原则、灵感、音乐、书籍、推荐、三问六大模块，并回写 [[∑ 灵感池]] 日捕捉；语义填充由 L2 `✨@uPrompt-Daily-Inspiration` 执行。灵感内容与当日晨间计划、知识库实际内容交叉引用，拒绝孤立鸡汤。
- **触发**：cron `0 9 * * *`（Loop 0）+ 触发词 `「执行每日灵感」`（L2 补全语义）
- **数据源**：`[[提示词-创作-每日灵感]]`（模板矩阵）+ 当日晨间计划（交叉引用）+ [[∑ 灵感池]]（种子）+ 知识库内容（关联推荐）
- **决策分支**：
  - IF 晨间计划已执行 THEN 每日灵感中的推荐（音乐/书籍/工具）必须与当日任务维度关联。
  - IF 晨间计划未执行 THEN 降级为通用灵感生成，但仍尝试关联知识库已有内容。
