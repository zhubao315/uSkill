# uSkill-agent-认知偏差对抗协议：七协议认知训练工具箱

## 🎯 目标

> 主动构建"基于证据的乐观主义"与"反脆弱决策结构"，对抗大脑天生的负面信息偏见、线性思维偏差与媒介麻木，将乐观与理性从情绪转化为可执行的战略选择。

**核心价值**：本 Skill 整合七套已验证的认知/决策协议，覆盖"对抗偏见 → 建立反馈 → 诊断环境 → 捕捉机会 → 配置资产 → 激发创新 → 构建选择权"的完整链条。先识别用户所处的问题域，再路由到对应子协议。

**七协议一览**：
1. 认知偏差对抗协议（基于证据的乐观主义）
2. 反馈闭环构建协议（控制论）
3. 媒介环境感知协议（麦克卢汉）
4. 指数型机会识别协议（6D 模型）
5. 杠铃策略实施协议（塔勒布反脆弱）
6. 突破创新协议（XPRIZE 模式）
7. 选择权构建协议（凸性结构）

## 🔄 执行流程

**Step 0 — 路由**：依据 `problem_domain` 选择子协议（见 IF/THEN）。

**IF/THEN 决策分支**：
- IF `problem_domain == bias` THEN 进入协议1（认知偏差对抗）：识别偏差类型 → 构建反驳清单。
- IF `problem_domain == feedback` THEN 进入协议2（反馈闭环）：Input/Output/Feedback/Control 四闸门。
- IF `problem_domain == media` THEN 进入协议3（媒介感知）：计算热值指数，维持 0.4–0.6 认知甜区。
- IF `problem_domain == opportunity` THEN 进入协议4（指数机会）：用 6D 模型审计技能与机会窗口。
- IF `problem_domain == barbell` THEN 进入协议5（杠铃）：保守端≥85%、激进端≤15%，无中间地带。
- IF `problem_domain == innovation` THEN 进入协议6（突破创新）：结果悬赏制，不规定路径。
- IF `problem_domain == optionality` THEN 进入协议7（选择权）：凸性评分 = 潜在收益/最大损失，需 > 3。
- IF `risk_level == high` THEN 暂停执行并转人工确认（财务/医疗/法律）。

### 协议1：认知偏差对抗协议

**技能定义**：主动构建"基于证据的乐观主义"，对抗大脑天生的负面信息偏见，建立理性世界观。通过结构化的信息过滤和认知训练，将乐观从情绪转化为战略选择。

**底层原理**：
- 杏仁核偏好：进化遗留的负面敏感机制，在现代被媒体放大
- 邓巴数限制：人类社交圈上限 150 人，无法直观理解全球数据
- 信息过载：超出认知处理能力，导致决策疲劳

**运行协议**：
- 协议1 信息食谱优化：限流碎片化新闻（≤15分钟/天）；主动摄入指数型技术进展（30分钟/天）；建立"反驳清单"（每个悲观论点找一个技术解决案例）。执行频率：每日。
- 协议2 悲观论点解构：识别论点中的认知偏差类型；寻找反例数据；构建基于证据的反驳。执行频率：遇到悲观论点时。
- 协议3 乐观仪表盘：追踪关键领域的技术进步；量化"世界正在变好"的证据；定期回顾强化乐观信念。执行频率：每月1次。

*关联：[[认知偏差]]*

---

### 协议2：反馈闭环构建协议

**技能定义**：基于维纳控制论，将"设计反馈"转化为可执行方法论。核心原则："不设计结果，设计反馈"——构建高质量反馈闭环，让系统自动趋向最优状态。

**底层原理**：控制论核心公式 `新行动 = 旧行动 + f(目标 - 真实输出)`。没有反馈的系统 = 开环运行 = 必然熵增。反馈质量决定控制精度。

**运行协议**：
- 协议1 负熵信息捕获（Input Gate）：仅接收高信噪比信息源；拒绝碎片化新闻/情绪化评论；每条信息用自己话重述为原子观点；与知识库建≥2条双链。
- 协议2 硬输出激活（Output Gate）：每学完模块必须"硬输出"（文章/分享/可运行代码）；输出须可反驳；进入公共领域。
- 协议3 反馈捕获与纠偏（Feedback Gate）：主动搜集同行评议/报错/投资数据/用户反应；负反馈→修正框架，正反馈→强化，噪声→过滤；错误视作控制信号。
- 协议4 系统迭代（Control Gate）：每周控制论复盘（最大偏差根因）；修改路径而非重复旧模式；追踪偏差收敛。

---

### 协议3：媒介环境感知协议

**技能定义**：基于麦克卢汉《理解媒介》，建立媒介环境诊断与应对框架。原则："先诊断媒介环境，再设计认知策略"。

**底层原理**：
- 媒介即讯息：技术形式本身改变人类感知结构
- 冷热媒介：热媒介（高清晰/低参与）致被动；冷媒介（低清晰/高参与）激活深度加工
- 自我截肢：技术延伸感官同时引发神经麻木
- 公式：`感知改造 = f(媒介热值) × t(暴露时间)`

**运行协议**：
- 协议1 媒介环境审计：列每日前5媒介（按时长）；标注冷热属性（清晰度/参与度/感官通道）；计算热值指数 `Σ(清晰度×使用时长)/总使用时长`；热值>0.7需冷化，<0.3需提效。
- 协议2 冷热平衡干预：过热引入冷媒介（手写/复述/手动双链）；过冷引入热媒介（模板/脚本）；维持 0.4–0.6 认知甜区。
- 协议3 逆转预判：识别极端化媒介趋势；预判逆转方向（个性化→群体回归）；提前布局。
- 协议4 杂交创新定位：识别两媒介杂交可能；评估能量方向（创造/毁灭）；建创新试验田设安全边界。

---

### 协议4：指数型机会识别协议

**技能定义**：识别并捕捉指数型增长机会，避免将资源投入即将"去货币化"的线性技能。基于戴曼迪斯 6D 演进模型。

**底层原理**：
- 6D 模型：数码化→欺骗性→颠覆性→去物质化→去货币化→民主化
- 认知错配：人类线性思维 vs 技术指数增长，系统性低估长期
- 机会窗口：处于 D2（欺骗性）阶段最佳布局

**运行协议**：
- 协议1 技能6D审计：列5项核心技能；判断各处于6D哪阶段；标记将入 D5 的技能。执行频率：每季度1次。
- 协议2 机会窗口监测：识别 D2 阶段技术；评估进 D3 时间窗；算能力迁移路径。执行频率：每月1次。
- 协议3 跨界能力整合：寻2-3领域交叉点；设计"能力组合包"；构建护城河。执行频率：每半年1次。

*关联：[[6D演进模型]]*

---

### 协议5：杠铃策略实施协议

**技能定义**：运用杠铃策略构建反脆弱资产配置，通过极端两极化实现"有限下行+无限上行"非对称收益。

**核心公式**：`反脆弱性 = 保守端生存保障 × 激进端凸性敞口`

**执行步骤**：
- Phase 1 建立安全垫：评估生存底线；保守端85-90%（国债/现金/稳定主业/经典理论）；验证即使激进端全损也不影响生存。
- Phase 2 构建激进端：识别凸性机会（风投/天使/价外期权/副业/创业）；单次投入=可承受100%损失；分散多小项目。
- Phase 3 监控再平衡：每季度审计；激进端损超年度预算/保守端<80%/新凸性机会时再平衡；坚持无中间地带。

**异常处理**：无法确定生存底线→确保≥6个月；全部中等风险→`ERROR_NO_BELLBAR` 重识别；激进端持续亏损→查"损失有限"；保守端收益低→接受其目的为生存。

---

### 协议6：突破创新协议（XPRIZE模式）

**技能定义**：用结果悬赏制替代过程考核，激发自组织创新。基于 XPRIZE 成功经验，将"限制激发创新"转化为团队创新方法论。

**底层原理**：
- 限制创造创造力：明确目标+资源约束激发突破性思维
- 结果导向消除路径依赖：只奖励最终结果
- 开放竞争打破专家思维：跨领域提供非共识解法

**运行协议**：
- 协议1 个人XPRIZE设定：定义可量化成功标准；不预设路径；设个人奖励。每年1-2个。
- 协议2 团队创新竞赛：明确问题与标准；提供工具资源；开放内部竞争不规定路径。
- 协议3 失败复盘机制：分析失败模式（方向错/执行不足）；提取可复用负样本；更新禁止清单。

*关联：激励性竞赛机制*

---

### 协议7：选择权构建协议

**技能定义**：构建"损失有限、收益无限"的选择权结构，在不确定性中获益，实现反脆弱性。

**核心公式**：`选择权价值 = 潜在收益 / 最大损失`

**执行步骤**：
- Phase 1 识别机会：评估损失有限性（已知且有限、不危生存）；评估收益无限性（网络效应/规模经济/品牌溢价）；计算凸性评分（>3优秀，1-3一般，<1避免）。
- Phase 2 构建结构：设损失上限≤可承受且不危生存；建非对称头寸（期权买方/天使/副业/跨域学习）；分散多小选择权。
- Phase 3 执行学习：MVP 小规模试错；保留成功者扩大；放弃失败者不追加。

**异常处理**：无法确定最大损失→`ERROR_UNLIMITED_LOSS` 重评估；全对称→搜非对称或等待；损失超阈值→立即停止；收益低→接受小损失是成本。

## 🛡️ Three-Tier Boundaries `[v3新增]`

> 来源：addyosmani/agent-skills 的边界系统

### ✅ Always do（自动执行）
- 执行核心功能（见原技能流程）
- 输出结构化结果
- 检查常见错误

### ⚠️ Ask first（先问再做）
- 用户意图不明确时
- 操作不可逆时
- 涉及外部系统时

### 🚫 Never do（绝对禁止）
- 不跳过验证步骤
- 不在用户未确认时执行高风险操作
- 不伪装成功（失败就上报）

## 🔒 Gated Workflow `[v3新增]`

> 来源：addyosmani 的门禁 + claude-skills 的 Agent Harness

```
DISCUSS → PLAN → EXECUTE → VERIFY → CLOSE
   ↓         ↓        ↓          ↓        ↓
 Context   方案     执行      证据     Done/
 Read     确认     任务      检查    Escalate
```

### Phase 1: DISCUSS
- [ ] 输出 Context Read 一行判断
- [ ] 确认用户意图
- [ ] 确认约束条件

### Phase 2: PLAN
- [ ] 制定执行方案
- [ ] 确认资源可用
- [ ] 人工审批计划

### Phase 3: EXECUTE
- [ ] 逐个任务实现
- [ ] 每步有输出记录

### Phase 4: VERIFY
- [ ] 检查核心输出
- [ ] 验证完整性
- [ ] 输出证据

### Phase 5: CLOSE
- [ ] 所有检查通过 → 标记完成
- [ ] 有未通过项 → 升级给人类
- [ ] 预算耗尽 → 强制升级，不伪装成功

## 📋 Verification Evidence `[v3新增]`

> 来源：addyosmani 的证据要求 + claude-skills 的 verify

### 完成标志
- [ ] 核心输出已生成
- [ ] 输出格式符合预期
- [ ] 无明显错误

### 失败处理
- 输出不完整 → 继续补充，不标记完成
- 连续 3 次失败 → 升级给人类，附上当前状态
- 绝不伪装成功
