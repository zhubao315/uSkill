## 🔄 执行流程

**Step 0 — 路由**：依据 `problem_domain` 选择子协议（见 IF/THEN）。

**IF/THEN 决策分支**：
- IF `problem_domain == bias` THEN 进入协议1（认知偏差对抗）：识别偏差类型 → 构建反驳清单。
- IF `problem_domain == feedback` THEN 进入协议2（反馈闭环）：Input/Output/Feedback/Control 四闸门。
- IF `problem_domain == media` THEN 进入协议3（媒介感知）：计算热值指数，维持 0.4–0.6 认知甜区。
- IF `problem_domain == opportunity` THEN 进入协议4（指数机会）：用 6D 模型审计技能与机会窗口。
- IF `problem_domain == barbell` THEN 进入协议5（杠铃）：保守端≥85%、激进端≤15%，无中间地带。
- IF `problem_domain == innovation` THEN 进入协议6（突破创新）：结果悬赏制，不规定路径。
- IF `problem_domain == optionality` THEN 进入协议7（选择权）：凸性评分 = 潜在收益/最大损失，需 > 3。
- IF `risk_level == high` THEN 暂停执行并转人工确认（财务/医疗/法律）。

### 协议1：认知偏差对抗协议

**技能定义**：主动构建"基于证据的乐观主义"，对抗大脑天生的负面信息偏见，建立理性世界观。通过结构化的信息过滤和认知训练，将乐观从情绪转化为战略选择。

**底层原理**：
- 杏仁核偏好：进化遗留的负面敏感机制，在现代被媒体放大
- 邓巴数限制：人类社交圈上限 150 人，无法直观理解全球数据
- 信息过载：超出认知处理能力，导致决策疲劳

**运行协议**：
- 协议1 信息食谱优化：限流碎片化新闻（≤15分钟/天）；主动摄入指数型技术进展（30分钟/天）；建立"反驳清单"（每个悲观论点找一个技术解决案例）。执行频率：每日。
- 协议2 悲观论点解构：识别论点中的认知偏差类型；寻找反例数据；构建基于证据的反驳。执行频率：遇到悲观论点时。
- 协议3 乐观仪表盘：追踪关键领域的技术进步；量化"世界正在变好"的证据；定期回顾强化乐观信念。执行频率：每月1次。

### 协议2：反馈闭环构建协议

**技能定义**：基于维纳控制论，将"设计反馈"转化为可执行方法论。核心原则："不设计结果，设计反馈"——构建高质量反馈闭环，让系统自动趋向最优状态。

**底层原理**：控制论核心公式 `新行动 = 旧行动 + f(目标 - 真实输出)`。没有反馈的系统 = 开环运行 = 必然熵增。反馈质量决定控制精度。

**运行协议**：
- 协议1 负熵信息捕获（Input Gate）：仅接收高信噪比信息源；拒绝碎片化新闻/情绪化评论；每条信息用自己话重述为原子观点；与知识库建≥2条双链。
- 协议2 硬输出激活（Output Gate）：每学完模块必须"硬输出"（文章/分享/可运行代码）；输出须可反驳；进入公共领域。
- 协议3 反馈捕获与纠偏（Feedback Gate）：主动搜集同行评议/报错/投资数据/用户反应；负反馈→修正框架，正反馈→强化，噪声→过滤；错误视作控制信号。
- 协议4 系统迭代（Control Gate）：每周控制论复盘（最大偏差根因）；修改路径而非重复旧模式；追踪偏差收敛。

### 协议3：媒介环境感知协议

**技能定义**：基于麦克卢汉《理解媒介》，建立媒介环境诊断与应对框架。原则："先诊断媒介环境，再设计认知策略"。

**底层原理**：
- 媒介即讯息：技术形式本身改变人类感知结构
- 冷热媒介：热媒介（高清晰/低参与）致被动；冷媒介（低清晰/高参与）激活深度加工
- 自我截肢：技术延伸感官同时引发神经麻木
- 公式：`感知改造 = f(媒介热值) × t(暴露时间)`

**运行协议**：
- 协议1 媒介环境审计：列每日前5媒介（按时长）；标注冷热属性（清晰度/参与度/感官通道）；计算热值指数 `Σ(清晰度×使用时长)/总使用时长`；热值>0.7需冷化，<0.3需提效。
- 协议2 冷热平衡干预：过热引入冷媒介（手写/复述/手动双链）；过冷引入热媒介（模板/脚本）；维持 0.4–0.6 认知甜区。
- 协议3 逆转预判：识别极端化媒介趋势；预判逆转方向（个性化→群体回归）；提前布局。
- 协议4 杂交创新定位：识别两媒介杂交可能；评估能量方向（创造/毁灭）；建创新试验田设安全边界。

### 协议4：指数型机会识别协议

**技能定义**：识别并捕捉指数型增长机会，避免将资源投入即将"去货币化"的线性技能。基于戴曼迪斯 6D 演进模型。

**底层原理**：
- 6D 模型：数码化→欺骗性→颠覆性→去物质化→去货币化→民主化
- 认知错配：人类线性思维 vs 技术指数增长，系统性低估长期
- 机会窗口：处于 D2（欺骗性）阶段最佳布局

**运行协议**：
- 协议1 技能6D审计：列5项核心技能；判断各处于6D哪阶段；标记将入 D5 的技能。执行频率：每季度1次。
- 协议2 机会窗口监测：识别 D2 阶段技术；评估进 D3 时间窗；算能力迁移路径。执行频率：每月1次。
- 协议3 跨界能力整合：寻2-3领域交叉点；设计"能力组合包"；构建护城河。执行频率：每半年1次。
