# 📧 uSkill-311: 邮件处理

## 🎯 目标

> 基于规则分类处理邮件，提升处理效率，确保重要邮件不遗漏。

---

## 📥 输入

| 参数 | 类型 | 必填 | 说明 |
|------|------|:----:|------|
| `emails` | `array` | ✅ | 邮件列表（发件人、主题、内容摘要） |
| `rules` | `array` | ❌ | 自定义处理规则 |

---

## 📤 输出

```json
{
  "summary": "string",
  "classified": [{"email": "string", "level": "P0|P1|P2|P3", "action": "string"}],
  "manual_required": [{"email": "string", "reason": "string"}]
}
```

---

## 🔄 执行流程

```
1. [邮件解析] → 接收邮件列表，提取关键信息
   → 发件人、主题、内容摘要、附件、时间

2. [优先级分类] → 按规则分为P0-P3
   → P0（紧急）：客户投诉、系统故障、法律通知
   → P1（重要）：上级指令、项目更新、会议邀请
   → P2（普通）：内部通知、周报提醒、日常沟通
   → P3（可忽略）：订阅邮件、广告、群发通知
   → 判断条件：是否涉及法律/合同？
     → 是：必须人工处理
     → 否：按规则分类

3. [处理建议] → 为每封邮件生成具体处理建议
   → P0：立即回复或电话确认
   → P1：今日内处理
   → P2：本周内处理
   → P3：可批量删除或归档

4. [人工标注] → 标注需人工处理的邮件
   → 法律/合同类 → 标注原因
   → 敏感内容 → 标注风险

5. [输出报告] → 生成结构化分类报告
```

---

## 📝 Prompt 模板

### 标准处理 Prompt

```
你是邮件处理Agent。请分类处理以下邮件。

【邮件列表】
{emails}

【处理规则】
{rules}

【分类标准】
- P0（紧急）：客户投诉、系统故障、法律通知 → 立即处理
- P1（重要）：上级指令、项目更新、会议邀请 → 今日处理
- P2（普通）：内部通知、周报提醒、日常沟通 → 本周处理
- P3（可忽略）：订阅邮件、广告、群发通知 → 可忽略

【红线规则】
- 不得自动发送任何回复
- 法律/合同类邮件必须人工处理
- 涉密邮件不得在报告中展示原文

【输出格式】
按标准 JSON 输出，包含 classified 和 manual_required。
```

---

## ⚠️ 异常处理

| 异常场景 | 处理方式 | 降级策略 |
|----------|----------|----------|
| 邮件内容不完整 | 基于主题和发件人推断 | 标注"内容待确认" |
| 规则冲突 | 取更高优先级 | 标注冲突规则 |
| 大量邮件(>50封) | 分批处理 | 先处理P0/P1 |
| 未知发件人 | 标注为P2 | 建议人工确认 |

## 💡 使用示例

### 示例 1：正常分类

**输入**：
```json
{
  "emails": [
    {"from": "client@company.com", "subject": "项目交付延迟投诉", "summary": "客户对延期不满"},
    {"from": "manager@company.com", "subject": "周报提醒", "summary": "请提交本周周报"},
    {"from": "newsletter@tech.com", "subject": "本周技术精选", "summary": "技术文章合集"}
  ]
}
```

**输出**：
```json
{
  "classified": [
    {"email": "项目交付延迟投诉", "level": "P0", "action": "立即回复客户+电话确认"},
    {"email": "周报提醒", "level": "P1", "action": "今日下班前提交"},
    {"email": "本周技术精选", "level": "P3", "action": "可忽略"}
  ],
  "manual_required": [{"email": "项目交付延迟投诉", "reason": "客户投诉需人工回复"}]
}
```

### 示例 2：法律邮件（边界场景）

**输入**：
```json
{
  "emails": [
    {"from": "legal@partner.com", "subject": "合同续签通知", "summary": "合同到期需续签"}
  ]
}
```

**输出**：
```json
{
  "classified": [{"email": "合同续签通知", "level": "P0", "action": "必须人工处理"}],
  "manual_required": [{"email": "合同续签通知", "reason": "法律/合同类，必须人工处理"}]
}
```
