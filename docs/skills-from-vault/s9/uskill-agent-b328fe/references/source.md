## LQS 评分标准

```
LQS = 0.3×频率 + 0.3×深度 + 0.2×时间衰减 + 0.2×情感浓度

频率：过去90天互动次数 / 13周
深度：平均对话长度 / 目标长度
时间衰减：最近一次互动距今天数的衰减函数
情感浓度：NLP情感分析得分
```

| 状态 | LQS 范围 | 行动 |
|:----:|:--------:|------|
| 🟢 healthy | ≥70 | 保持现有节奏 |
| 🟡 at_risk | 40-69 | 增加互动频率 |
| 🔴 dormant | <40 | 主动联系 |

#### ⚠️ 边界约束

> 此区块定义此 Skill 的硬性限制和软性约束，确保执行不越界。

**硬性约束（必须遵守）**：
1. 不得违反相关法律法规和平台规则
2. 不得泄露用户隐私数据
3. 不得在未经验证的情况下做出不可逆决策

**软性约束（建议遵守）**：
1. 优先使用已验证的方法论，避免发明新轮子
2. 复杂决策应记录理由供后续审计

**人工兜底点**：
- 当输入数据质量不足以支撑自动化决策时，**必须**转交人工判断
- 当涉及法律/财务/医疗等高风险领域时，**必须**暂停执行等待确认

## 🔒 Gated Workflow `[v3新增]`

> 来源：addyosmani 的门禁 + claude-skills 的 Agent Harness

```
DISCUSS → PLAN → EXECUTE → VERIFY → CLOSE
   ↓         ↓        ↓          ↓        ↓
 Context   方案     执行      证据     Done/
 Read     确认     任务      检查    Escalate
```

### Phase 1: DISCUSS
- [ ] 输出 Context Read 一行判断
- [ ] 确认用户意图
- [ ] 确认约束条件

### Phase 2: PLAN
- [ ] 制定执行方案
- [ ] 确认资源可用
- [ ] 人工审批计划

### Phase 3: EXECUTE
- [ ] 逐个任务实现
- [ ] 每步有输出记录

### Phase 4: VERIFY
- [ ] 检查核心输出
- [ ] 验证完整性
- [ ] 输出证据

### Phase 5: CLOSE
- [ ] 所有检查通过 → 标记完成
- [ ] 有未通过项 → 升级给人类
- [ ] 预算耗尽 → 强制升级，不伪装成功

## 🔄 IF/THEN 决策分支

- IF 输入数据质量不足以支撑自动化决策 → THEN 转交人工判断，输出不确定性说明
- IF 执行过程中遇到未预期的异常 → THEN 记录异常 + 降级处理 + 升级给人类
- IF 输出结果置信度 < 0.6 → THEN 标记低置信度 + 要求人工验证
- ELSE（所有检查通过）→ THEN 输出结果 + 验证证据

```
你是一位人际关系量化管理专家。请根据以下输入进行关系图谱分析：
输入：[互动记录（对象/方式/时长/深度）+ 关系圈层定义]
要求：1) 计算每位关系对象的LQS（关系质量分数）= 0.3×频率 + 0.3×深度 + 0.2×时间衰减 + 0.2×情感浓度；2) 标注健康/风险/休眠状态；3) 识别需要主动维护的关系（LQS<50）；4) 生成改善行动计划
输出格式：LQS评分表+状态标注+改善计划（优先级/对象/行动/目标）
```

**使用说明**：
- 替换方括号内的占位符为实际内容
- 根据具体场景调整要求部分
- 输出格式可根据需要修改

## 📋 Verification Evidence `[v3新增]`

> 来源：addyosmani 的证据要求 + claude-skills 的 verify
