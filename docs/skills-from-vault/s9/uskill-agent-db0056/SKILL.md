# uSkill-投资标的筛选

> 基于价值投资框架系统化筛选投资标的，将直觉选股升级为可验证的量化流程。
> 分类：认知类 | 优先级：P0 | 排期：Q1

---

## 1. 目标定义

- **核心目标**：基于价值投资框架（安全边际+护城河+能力圈），对候选标的进行结构化筛选与评估，输出可验证的投资分析报告
- **价值对齐**：与「理性主义」强关联——价值投资本质是理性主义在金融领域的实践；与「长期主义」关联——价值投资=长期主义的金融表达；与「宇宙主义」关联——尾部风险管理
- **适用场景**：A股/港股/美股标的筛选、持仓标的定期复查、新行业/新赛道研究

---

## 2. 边界约束

- **能力边界**：
  - 能做：财务指标筛选、护城河评估、估值计算、风险量化、生成结构化分析报告
  - 不能做：代替人类做买卖决策、保证投资收益、获取非公开信息、预测短期股价走势
- **触发条件**：
  - 启动：人工指令「筛选：[行业/主题]」或「评估：[标的代码]」
  - 终止：分析报告生成+人类确认
- **红线规则**：
  - 所有分析必须附加「不构成投资建议」声明
  - 不得使用技术分析/趋势预测替代基本面分析
  - 不得忽略不利财务指标（损失厌恶防范）
  - 估值必须使用多种方法交叉验证
  - 必须标注信息时效性（财报日期）

### 输入格式
```yaml

  investment_horizon: short|medium|long  # 选填，投资期限
  risk_budget: float  # 选填，风险预算（最大可接受回撤%）
  custom_criteria:  # 选填，自定义筛选条件
    min_market_cap: float
    max_pe: float
    min_roe: float
    dividend_yield_min: float
```

- 标的财务数据缺失 → 标注「数据不完整」，输出精简版分析

## 4. 核心推理链路

```
1. [数据采集] → 拉取财务数据+行业数据+研报摘要
   → 判断条件：数据是否覆盖最近2个季度？
     → 是：进入步骤2
     → 否：标注数据缺口，用可用数据继续

2. [初筛过滤] → 基于硬指标快速过滤
   → 过滤规则：ROE<8% → 排除；资产负债率>70% → 警示；自由现金流连续3年负 → 排除
   → 判断条件：是否通过初筛？
     → 是：进入步骤3
     → 否：输出「未通过初筛」+未通过原因

3. [护城河评估] → 五维度逐一评估
   → 评分标准：1-5分，每个维度必须有具体依据
   → 综合评分 ≥ 3.5 → 护城河较强

4. [财务健康度分析] → 核心指标+趋势+行业对比
   → 趋势分析：3年数据，判断改善/稳定/恶化
   → 红旗检测：应收激增、存货异常、经营现金流与净利润背离

5. [估值计算] → 多方法交叉验证
   → 方法1：DCF（保守/中性/乐观三档）
   → 方法2：PE/PB历史分位对比
   → 方法3：同行业可比标的对比
   → 判断条件：三种方法结论是否一致？
     → 是：置信度高
     → 否：标注分歧，需人工判断

6. [风险评估] → 系统化识别风险
   → 行业风险/管理层风险/政策风险/尾部风险
   → 严重程度 = 影响范围 × 发生概率

7. [能力圈校验] → 三问检查
   → 是否理解？能否跟踪？是否有优势？
   → 任一项否 → 标注「超能力圈」

8. [报告生成] → 组装完整筛选报告
   → 最终输出：结构化投资分析文档
```

## 5. 校验验收规则

- **格式校验**：
  - 护城河五维度评分完整 ✅/❌
  - 估值至少3种方法 ✅/❌
  - 风险清单非空 ✅/❌
  - 能力圈校验完成 ✅/❌

- **内容校验**：
  - 不利财务指标未遗漏 ✅/❌
  - 估值结论有数据支撑 ✅/❌
  - 免责声明完整 ✅/❌
  - 信息时效性标注 ✅/❌

- **合规校验**：
  - 未使用技术分析替代基本面 ✅/❌
  - 未预测短期股价 ✅/❌
  - 未代替人类做买卖决策 ✅/❌

- **验收标准**：
  - 护城河评估一致性 ≥ 85%
  - 估值偏差 < 20%（6个月后回测）
  - 风险识别覆盖率 ≥ 80%
