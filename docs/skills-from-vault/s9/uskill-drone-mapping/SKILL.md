# 无人机测绘与实景建模

## 🎯 目标

> 从航线规划到成果交付，构建标准化的无人机测绘全流程。

**核心价值**：无人机测绘 80% 的质量问题源于航线规划和数据采集阶段。本 Skill 将质量控制前置到飞行前，而非后期补救。

**适用场景**：
- 城市更新区域现状测绘
- 建筑工地进度监测
- 地形测量与土方计算
- 北京古建筑/历史街区实景三维建模

## 📥 输入

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|:----:|--------|------|
| `mission_type` | enum | ✅ | — | 任务类型：`ortho`（正射）/ `mapping`（测绘）/ `3d_model`（实景建模）/ `inspection`（巡检） |
| `area_km2` | float | ✅ | — | 测绘面积（平方公里） |
| `gsd_target` | float | ❌ | `3` | 目标地面采样距离（厘米） |
| `output_products` | array | ❌ | `["orthomosaic","dsm","pointcloud"]` | 输出产品 |
| `accuracy_target` | enum | ❌ | `"medium"` | 精度：`low`（无GCP）/ `medium`（少量GCP）/ `high`（密集GCP+RTK） |
| `platform` | enum | ❌ | `"multirotor"` | 飞行平台：`multirotor`（多旋翼）/ `fixedwing`（固定翼）/ `hybrid` |

## 📤 输出

```json
{
  "flight_plan": {
    "altitude": "int — 飞行高度（米）",
    "overlap": "string — 旁向/航向重叠率",
    "route_length_km": "float — 航线总长",
    "flight_time_min": "int — 预计飞行时间",
    "waypoints": "int — 航点数"
  },
  "processing_results": {
    "orthomosaic": "string — 正射影像路径（如有）",
    "dsm": "string — 数字表面模型路径（如有）",
    "pointcloud": "string — 点云路径（如有）",
    "3d_model": "string — 三维模型路径（如有）"
  },
  "quality_report": {
    "gsd_cm": "float — 实际地面采样距离",
    "rmse_cm": "float — 控制点均方根误差",
    "overlap_actual": "string — 实际重叠率",
    "coverage_pct": "float — 覆盖率"
  }
}
```

## 📋 执行步骤

### Step 1: 航线规划
1. **地形分析** — 获取区域 DEM，确定最低/最高海拔
2. **高度计算** — 根据 GSD 目标和相机参数计算飞行高度
3. **重叠率设置** — 航向 ≥80%，旁向 ≥70%（三维建模需更高）
4. **GCP 布设** — 地面控制点均匀分布，每 km² ≥5 个
5. **检查点**：✅ 高度是否正确？重叠率是否达标？GCP 是否均匀？

### Step 2: 数据采集
1. **天气窗口** — 风速 <5m/s，无雨，能见度 >5km
2. **设备检查** — 电池/存储卡/相机参数/GPS 状态
3. **GCP 测量** — RTK 或后差分测量控制点坐标
4. **飞行执行** — 按航线执行，监控偏航和信号
5. **检查点**：✅ 天气是否合格？设备是否正常？GCP 是否已测量？

### Step 3: 数据处理
1. **影像质量检查** — 剔除模糊/过曝/遮挡影像
2. **空三计算** — 自动匹配连接点，解算相机位姿
3. **密集匹配** — 生成密集点云
4. **产品生成** — 正射影像/DSM/三维模型
5. **检查点**：✅ 影像质量是否达标？空三解算是否收敛？

### Step 4: 质量验证
1. **GCP 检查** — 用未参与解算的检查点验证精度
2. **目视检查** — 正射影像是否有拼接痕迹/变形
3. **产品交付** — 按项目需求裁剪和格式转换
4. **检查点**：✅ 精度是否达标？产品是否完整？

## ⚠️ 异常处理

| 异常 | 条件 | 处理方式 |
|------|------|----------|
| 精度不达标 | RMSE >目标值 | 增加 GCP、重新处理 |
| 影像缺失 | 覆盖率 <95% | 补飞缺失区域 |
| 空三失败 | 连接点不足 | 增加重叠率、手动添加控制点 |

## 💬 沟通风格

- **任务思维**：每次飞行都是数据采集任务，不是「飞一圈看看」
- **精度为王**：所有产品都有精度指标，不说「看着挺准」
- **文档化**：飞行日志、处理参数、质量报告缺一不可

## 📝 自检清单

- [ ] 飞行高度是否基于 GSD 目标计算？
- [ ] 重叠率是否达标（航向 ≥80%、旁向 ≥70%）？
- [ ] GCP 是否均匀分布？
- [ ] 检查点精度是否验证通过？
- [ ] 正射影像是否有拼接痕迹？
- [ ] 飞行日志是否完整记录？
