# uSkill-贝叶斯决策

> 用先验-证据-后验框架量化更新决策信念，让每一次决策都有迹可循、可回测、可迭代。
> 分类：认知类 | 优先级：P0 | 排期：Q1

---

## 1. 目标定义

- **核心目标**：将重大决策从直觉判断升级为贝叶斯量化推理，建立「先验信念→新证据→后验更新」的决策闭环，沉淀可回测的决策日志
- **价值对齐**：与「理性主义」强关联——贝叶斯推理是理性主义的核心认知工具；与「长期主义」关联——决策日志是长期复利的认知资产
- **适用场景**：投资决策、技术选型、项目优先级判断、职业选择等需要理性量化支撑的重大决策

---

## 2. 边界约束

- **能力边界**：
  - 能做：量化先验概率、评估证据强度、计算后验概率、记录完整推理链
  - 不能做：代替人类做最终决策、保证决策结果一定正确、自行收集非公开信息
- **触发条件**：
  - 启动：人工指令「贝叶斯分析：[决策问题]」或决策涉及金额≥5000元/影响周期≥1个月
  - 终止：后验概率计算完成+人类确认决策
- **红线规则**：
  - 不得使用主观猜测替代数据作为先验（先验必须有依据）
  - 不得忽略不利证据（确认偏误防范）
  - 所有概率估计必须标注置信区间
  - 不得将后验概率直接等同于决策结论（概率是输入，决策是输出）

## 3. 输入输出规范

### 输入格式
```yaml
inputs:
  decision_question: string  # 必填，待决策问题
  prior_belief:  # 必填，先验信念
    hypothesis: string  # 假设描述
    probability: float  # 先验概率 (0-1)
    basis: string  # 先验依据（历史数据/专家判断/类比推理）
    confidence: float  # 置信度 (0-1)
  evidence_list:  # 必填，新证据列表
    - description: string  # 证据描述
      strength: float  # 证据强度 (0-1)
      reliability: float  # 证据可靠性 (0-1)
      direction: supportive|contradictory|neutral  # 证据方向
  context:  # 选填
    deadline: date  # 决策截止日
    stakeholders: [string]  # 利益相关方
    risk_tolerance: low|medium|high  # 风险偏好
```

### 输出格式
```markdown

[清晰的决策问题陈述]
```

### 异常输出
- 先验依据不足 → 输出警告「先验依据薄弱，建议补充历史数据或专家判断」+ 无信息先验（50%）
- 证据矛盾 → 标注矛盾点，分别计算支持/反对路径的后验

## 4. 核心推理链路

```
1. [问题定义] → 将模糊决策问题拆解为可量化的假设
   → 判断条件：假设是否互斥且穷尽？
     → 是：进入步骤2
     → 否：重新定义假设空间

2. [先验估计] → 基于历史数据/专家判断/类比推理设定先验
   → 规则：先验必须有明确依据，不得凭空设定
   → 规则：标注先验的置信度
   → 中间产物：先验概率分布

3. [证据收集与评估] → 逐一评估每条证据
   → 评分维度：强度(0-1) + 可靠性(0-1) + 方向
   → 计算贝叶斯因子：P(证据|H1) / P(证据|H2)
   → 判断条件：是否存在矛盾证据？
     → 是：标注矛盾，分别计算
     → 否：继续

4. [后验更新] → 应用贝叶斯定理更新信念
   → 公式：P(H|E) = P(E|H) × P(H) / P(E)
   → 逐条证据顺序更新，记录每次更新的中间结果
   → 中间产物：后验概率分布

5. [敏感性分析] → 检验结论的稳健性
   → 操作：关键证据可靠性±50%，观察后验变化
   → 判断条件：后验是否翻转？
     → 是：标注「结论脆弱，需更多证据」
     → 否：标注「结论稳健」

6. [认知偏差检查] → 5项偏差系统性排查
   → 确认偏误/锚定/过度自信/可得性/沉没成本
   → 发现偏差 → 标注并建议修正

7. [决策输出] → 生成完整贝叶斯决策报告
   → 最终输出：结构化决策文档+回测提醒
```

## 5. 校验验收规则

- **格式校验**：
  - 先验-证据-后验完整链路 ✅/❌
  - 所有概率标注置信区间 ✅/❌
  - 认知偏差5项检查完成 ✅/❌

- **内容校验**：
  - 先验有明确依据（非凭空设定） ✅/❌
  - 不利证据未被忽略 ✅/❌
  - 敏感性分析完成 ✅/❌
  - 决策编号可回测 ✅/❌

- **合规校验**：
  - 未将后验概率等同于决策结论 ✅/❌
  - 投资决策附带免责声明 ✅/❌

- **验收标准**：
  - 推理链路完整性 ≥ 95%
  - 认知偏差检查覆盖率 100%
  - 3个月后回测率 ≥ 80%

## 🔒 Gated Workflow `[v3新增]`

> 来源：addyosmani 的门禁 + claude-skills 的 Agent Harness

```
DISCUSS → PLAN → EXECUTE → VERIFY → CLOSE
   ↓         ↓        ↓          ↓        ↓
 Context   方案     执行      证据     Done/
 Read     确认     任务      检查    Escalate
```

### Phase 1: DISCUSS
- [ ] 输出 Context Read 一行判断
- [ ] 确认用户意图
- [ ] 确认约束条件

### Phase 2: PLAN
- [ ] 制定执行方案
- [ ] 确认资源可用
- [ ] 人工审批计划

### Phase 3: EXECUTE
- [ ] 逐个任务实现
- [ ] 每步有输出记录

### Phase 4: VERIFY
- [ ] 检查核心输出
- [ ] 验证完整性
- [ ] 输出证据

### Phase 5: CLOSE
- [ ] 所有检查通过 → 标记完成
- [ ] 有未通过项 → 升级给人类
- [ ] 预算耗尽 → 强制升级，不伪装成功

## 📝 Prompt 模板

> 用于调用 AI 辅助执行本技能的标准提示词模板。

**核心提示词**：
```
你是一位贝叶斯推理与量化决策专家。请根据以下输入进行贝叶斯决策分析：
输入：[决策问题、先验信念（假设/概率/依据/置信度）、新证据列表（描述/强度/可靠性/方向）]
要求：1) 量化先验概率（必须有依据）；2) 逐一评估证据的贝叶斯因子；3) 应用贝叶斯定理逐条更新后验概率；4) 执行敏感性分析（关键证据可靠性±50%）；5) 进行5项认知偏差检查（确认偏误/锚定/过度自信/可得性/沉没成本）
输出格式：贝叶斯决策报告，包含先验信念表+证据评估表+后验更新表+敏感性分析+认知偏差检查+决策建议
```

**使用说明**：
- 替换方括号内的占位符为实际内容
- 根据具体场景调整要求部分
- 输出格式可根据需要修改
