# 情绪传染免疫

群体情绪如流感——恐慌、狂热、愤怒在社交网络中传播的速度远超理性思考的启动时间。情绪传染免疫不是压抑情绪，而是在情绪感染和决策行为之间插入一个觉察间隙。

## 核心方法

1. **情绪触发标记** — 识别个人情绪传染的早期信号：心跳加速、呼吸变浅、肌肉紧绷、社交媒体的"立刻分享"冲动。建立一个个人情绪触发清单，当这些信号出现时自动触发"暂停协议"。

2. **1-10-60 延迟规则** — 遇到引发强烈情绪的信息：**1 秒暂停呼吸** → **10 分钟冷处理**（不要转发/回复） → **60 分钟后决定**是否采取行动。时间是最好的情绪冷却剂。

3. **来源溯源** — 在情绪被激发后，追问：这个信息来自哪里？传播者的动机是什么？我的情绪反应是信息内容本身造成的，还是被表达方式操控的？情绪操纵识别是免疫的第一步。

4. **群体氛围隔离** — 在明显的群体狂热或恐慌中，主动从讨论群/社交媒体暂时退出 24 小时。单独评估时做出的判断，比在群体氛围中做出的判断平均理性 30% 以上。

5. **情绪-事实分离记录** — 面对重大事件时，在笔记本画一条竖线：左边记"我感觉"，右边记"事实是"。分离后再决定行动，避免情绪直接驱动决策。

## 关键认知

情绪不是敌人——它是信号系统。问题不在于有情绪，而在于让情绪直接短路了理性判断。健康的情绪免疫不是"没有感觉"，而是"有感觉但不被感觉控制"。

## 🔒 Gated Workflow `[v3新增]`

> 来源：addyosmani 的门禁 + claude-skills 的 Agent Harness

```
DISCUSS → PLAN → EXECUTE → VERIFY → CLOSE
   ↓         ↓        ↓          ↓        ↓
 Context   方案     执行      证据     Done/
 Read     确认     任务      检查    Escalate
```

### Phase 1: DISCUSS
- [ ] 输出 Context Read 一行判断
- [ ] 确认用户意图
- [ ] 确认约束条件

### Phase 2: PLAN
- [ ] 制定执行方案
- [ ] 确认资源可用
- [ ] 人工审批计划

### Phase 3: EXECUTE
- [ ] 逐个任务实现
- [ ] 每步有输出记录

### Phase 4: VERIFY
- [ ] 检查核心输出
- [ ] 验证完整性
- [ ] 输出证据

### Phase 5: CLOSE
- [ ] 所有检查通过 → 标记完成
- [ ] 有未通过项 → 升级给人类
- [ ] 预算耗尽 → 强制升级，不伪装成功

## 🔄 IF/THEN 决策分支

- IF 输入数据质量不足以支撑自动化决策 → THEN 转交人工判断，输出不确定性说明
- IF 执行过程中遇到未预期的异常 → THEN 记录异常 + 降级处理 + 升级给人类
- IF 输出结果置信度 < 0.6 → THEN 标记低置信度 + 要求人工验证
- ELSE（所有检查通过）→ THEN 输出结果 + 验证证据
