# 日记元数据 Agent — 实施手册

# 📝 日记元数据 Agent — 实施手册

> **定位**：每日自动补全日记的标签、分类、关联链接，确保元数据完整率 ≥95%
>
> **价值**：元数据是 Agent 检索和知识图谱的基础，缺失标签 = 知识孤岛

---

## 一、Agent 定义

| 字段 | 值 |
|------|-----|
| 名称 | Daily Notes Metadata Agent |
| 触发 | 每日 23:00 / 人工指令「补全日记元数据」 |
| 输入 | 日记正文 |
| 输出 | 补全后的 frontmatter + 关联推荐 |
| 红线 | **不修改日记正文**，仅补全元数据 |

---

## 二、当前问题诊断

### 日记元数据缺失情况

| 问题 | 数量 | 示例 |
|------|:----:|------|
| 缺少 `维度/` 标签 | ~30% | 只有"类型/日记"，无维度 |
| 缺少 `来源/` 标签 | ~80% | 未标注来源 |
| 标签格式不一致 | ~20% | `#日记` vs `类型/日记` |
| 缺少 frontmatter | ~5% | 无 YAML 头 |
| 缺少关联链接 | ~90% | 未链接相关笔记 |

## 四、执行流程

### Step 1：读取日记

```
输入：日记文件路径
输出：frontmatter + 正文内容
```

### Step 2：分析内容

```
关键词提取 → 匹配维度标签 → 匹配来源标签 → 生成类型标签
```

### Step 3：补全 frontmatter

```yaml
# 补全前
---
title: "2026-02-05"
created: 2026-02-05
tags:
  - "类型/日记"
---

# 补全后
---
title: "2026-02-05"
created: 2026-02-05
updated: 2026-06-17
call_count: 0
last_called: ""
tags:
  - "类型/日记"
  - "维度/科技"
  - "维度/投资"
  - "维度/生活"
  - "来源/个人经历"
aliases:
  - "2026-02-05"
---
```

### Step 4：生成关联推荐

```
基于内容关键词，推荐相关笔记：
- 提到"跑步" → 关联 [[跑步训练计划]]、[[心率区间训练]]
- 提到"投资" → 关联 [[风控规则手册]]、[[2026年度投资计划]]
- 提到"阅读" → 关联 [[深度阅读方法论]]
```

### Step 5：写回文件

```
仅修改 frontmatter，不触碰正文
更新 updated 字段为当前日期
```

## 五、Prompt 模板

### 自动补全 Prompt

```
你是日记元数据Agent。请分析以下日记内容，补全元数据。

【日记正文】
{{content}}

【任务】
1. 分析内容，推断维度标签（从：维度/学习、维度/生活、维度/科技、维度/投资、维度/管理、维度/健康、维度/艺术、维度/哲学 中选择）
2. 推断来源标签（从：来源/阅读、来源/媒体、来源/对话、来源/个人经历 中选择）
3. 保留已有的类型/日记标签
4. 确保 tags 格式统一为 "维度/学习" 或 "类型/方法" 或 "来源/项目"
5. 不修改正文，只补全 frontmatter

【输出格式】
直接输出补全后的完整 frontmatter（YAML格式）。
```

### 批量补全 Prompt

```
你是日记元数据Agent。请批量补全以下日记的元数据。

【日记列表】
{{list_of_files}}

【任务】
对每个日记文件：
1. 读取内容
2. 推断维度/来源标签
3. 输出补全后的 frontmatter

【输出格式】
文件路径 → 补全后的 frontmatter
```

| 正文未修改率 | 100% | 对比修改前后正文 |
