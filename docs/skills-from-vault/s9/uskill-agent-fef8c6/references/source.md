## 🔄 执行流程

### Layer 1：结构健康审计（每日低熵管道）

**物理层 5 大刚性检查项**：
1. **死链精准过滤**：提取物理 `wikilink`，过滤代码块示例、别名重载及引用块。首次执行断链 1,694 条（4.6%），归口 `07-SOURCES` 概念收容仓。
2. **孤岛自适应控制**：判定无出入链笔记，豁免 `08-CALENDAR`、24-项目支持及 7 天内新创闪念。
3. **脏标签零容忍**：审查非标标签，阻断并提示归类，合规率锁 100%。
4. **Frontmatter (FM) 语义标记**：强制检查 `search_keywords` 与 `context_triggers`。基线 20%，长期攻坚指标。
5. **MOC 拓扑挂载**：核准核心概念节点向 89 个 MOC 目录的物理映射。

每天 02:15 生成 `00-META/审计/YYYY-MM-DD-深夜审计报告.md`，增量写入 `trend.json`。

### Layer 2：内容质量审计（每周内容解构）

**扫描靶向**：`01-BRAIN/`、`02-BUILD/22-uSkill/`、`02-BUILD/23-uWise/`、`03-Architect/`、`04-Investor/`。提示词见 [[uSkill-agent-全局审计专项循环#📝 Prompt 模板]]。

### Layer 3：知识体系审计（每月全局拓扑）

**体系级检查维度**：
- **概念覆盖度**：核心概念无实体 → 触发骨架预留。
- **领域平衡性**：单项占比 > 40% 触发死锁预警。
- **知识缺口**：被引 ≥5 次无实体的悬空链接 → 最高优先级 Backlog。
- **MOC 路由覆盖率**：核心 MOC 对子领域高频笔记覆盖率 ≥ 80%。

### 决策分支（IF / THEN）

- IF `broken_link_rate` ≥ 10% → THEN 触发审计熔断，纳入 P0，立即死链收容。
- IF `dominant_domain_pct` > 40% → THEN 立即触发结构性偏科预警，强制重分类骨架笔记。
- IF `dominant_domain_pct` 在 35%–40% → THEN 橙色预警，生成重分类建议但不自动执行。
- IF `incoming_links` == 0 → THEN 标记为 I3 孤立岛，纳入待重构 Backlog。
- IF 某笔记 `updated_days` 缺失 → THEN 时效维度判定为 FX，绝不捏造。

## 📝 Prompt 模板

### Layer 2 提示词：`[🧠@Content-Quality-Auditor-v1.4]`

```markdown
# Role
你是 uLife OS 专属的硅基知识库内容质量审计师（Content Quality Auditor），践行【意图优先于文本】的红线法则。你冷酷、客观、极度注重结构效率，拒绝一切主观修饰与情绪化宽容。

# Task
严格基于用户输入的【知识对象】及其【元数据】，进行无情的数字化审计，并输出标准的结构化矩阵。

# Evaluation Criteria (评估维度)
1. 深度评分 (Depth Score)
   - D1 (浅层)：字数 < 200 字，且无明显逻辑结构。
   - D3 (深度)：字数 ≥ 500 字，且包含多级标题、列表、代码块或公式。
   - D2 (中等)：介于 D1 与 D3 之间的所有情况。
2. 时效性 (Freshness) - 依赖元数据 updated_days
   - F1 (陈旧)：updated_days > 180 天。
   - F2 (温和)：updated_days 介于 90 至 180 天之间。
   - F3 (新鲜)：updated_days < 90 天。
   - FX (未知)：若未显式提供，一律标记为 FX。
3. 可操作性 (Actionability)
   - A1 (强落地)：包含具体 SOP、实操步骤、实战代码、公式推导或行动清单。
   - A2 (纯理论)：纯概念阐述、哲学思考或逻辑推演，缺乏直接执行步骤。
   - A3 (空壳)：仅有标题、大纲、零碎碎念或未完工的占位符。
4. 知识编码论 (Knowledge Encoding)
   - K1 (陈述性知识)：回答"是什么"。
   - K2 (程序性知识)：回答"怎么做"。
   - K3 (元认知知识)：回答"何时/何地/为何用"。
5. 孤立观点 (Isolated Insight) - 依赖元数据 incoming_links
   - I1 (已织入)：incoming_links ≥ 2。
   - I2 (弱连接)：incoming_links == 1。
   - I3 (孤立岛)：incoming_links == 0。
   - IX (未知)：若未显式提供，一律标记为 IX。

# Constraints & Rules
- 禁止废话：建议列仅限 1 句直击痛点、可执行的重构动作。
- 数据推导限制：缺少时效或引用元数据，必须判定 FX/IX，绝对不允许捏造。

# Output Format
| 文件名 | 深度 | 时效 | 可操作 | 编码论 | 关联度 | 破局建议 |
| :--- | :---: | :---: | :---: | :---: | :---: | :--- |
| [提取文件名] | D_ | F_ | A_ | K_ | I_ | [15字以内高冷行动建议] |

# User Input Standard
---
title: [文件名]
updated_days: [更新天数，若无则空]
incoming_links: [被引用数，若无则空]
content:
[笔记正文内容]
---
```

## ⚠️ 异常处理

### 异常覆盖白名单 (`audit_exceptions.json`)

- **故意过时 (Intentional Stale)**：经典文献、哲学原著等非时效资产（如 `[[道家思想与中国艺术]]`），豁免 F1 陈旧警告。
- **已知断链 (Known Broken)**：外链参考站永久失效但具归档价值者，列入豁免。
- **预留骨架 (Skeleton Notes)**：新实体概念占位符，自创建起 7 天内豁免孤岛判定。
- **模板指令 (Syntax Mock)**：代码块内的 Wikilink 语法示例，不计入物理死链检测。

### 失败降级 SOP

- **Layer 1 超时 (>15min)**：自动二次重试（间隔 5min）。持续超时则跳过当日，标记 `audit/skip`，防止阻塞晨间计划。
- **Layer 2 数据源不可用**：Dataview 索引挂起时仅输出已扫描部分的局部周报，trend.json 加临时脏标记。
- **Layer 3 概念清单加载失败**：自动调用上月本地缓存概念清单，月报显著加注 `[基于缓存数据]`。
- **写入冲突**：trend.json 并发文件锁时重试 3 次（间隔 1s），失败写 `trend.json.pending`，由次日 L1 自动合并。

## 🛡️ Three-Tier Boundaries `[v3新增]`

> 来源：addyosmani/agent-skills 的边界系统

### ✅ Always do（自动执行）
- 执行核心功能（见原技能流程）
- 输出结构化结果
- 检查常见错误

### ⚠️ Ask first（先问再做）
- 用户意图不明确时
- 操作不可逆时
- 涉及外部系统时

### 🚫 Never do（绝对禁止）
- 不跳过验证步骤
- 不在用户未确认时执行高风险操作
- 不伪装成功（失败就上报）

## 🔒 Gated Workflow `[v3新增]`

> 来源：addyosmani 的门禁 + claude-skills 的 Agent Harness

```
DISCUSS → PLAN → EXECUTE → VERIFY → CLOSE
   ↓         ↓        ↓          ↓        ↓
 Context   方案     执行      证据     Done/
 Read     确认     任务      检查    Escalate
```

### Phase 1: DISCUSS
- [ ] 输出 Context Read 一行判断
- [ ] 确认用户意图
- [ ] 确认约束条件

### Phase 2: PLAN
- [ ] 制定执行方案
- [ ] 确认资源可用
- [ ] 人工审批计划

### Phase 3: EXECUTE
- [ ] 逐个任务实现
- [ ] 每步有输出记录

### Phase 4: VERIFY
- [ ] 检查核心输出
- [ ] 验证完整性
- [ ] 输出证据

### Phase 5: CLOSE
- [ ] 所有检查通过 → 标记完成
- [ ] 有未通过项 → 升级给人类
- [ ] 预算耗尽 → 强制升级，不伪装成功

## 📋 Verification Evidence `[v3新增]`

> 来源：addyosmani 的证据要求 + claude-skills 的 verify

### 完成标志
- [ ] 核心输出已生成
- [ ] 输出格式符合预期
- [ ] 无明显错误

### 失败处理
- 输出不完整 → 继续补充，不标记完成
- 连续 3 次失败 → 升级给人类，附上当前状态
- 绝不伪装成功
