# 精准筛查防御协议

# 🛠️ 精准筛查防御协议

## 1. 技能定义

构建从常规体检到多组学监测的四层防御体系，堵住"可预防致命风险"的黑天鹅漏洞。基于戴曼迪斯《Longevity Guidebook》的"零愚蠢死亡"原理，核心目标是**在疾病 0-1 期萌芽阶段完成拦截**，把晚期癌症、隐匿心血管事件、突发脑卒中等高致命性疾病的发现窗口前移 5-10 年。

## 2. 底层原理

- **早期癌症生存率悬崖**：0-1 期五年生存率 90%+，4 期 < 20%。癌症的预后与发现阶段的相关性远大于治疗手段的差异
- **心血管事件的隐匿性**：70% 的突发心梗发生在"斑块已存在但未被识别"的人群。常规冠脉 CTA 对软斑块识别率不足 30%
- **AI 影像的精度跃迁**：AI-CCTA 对易损斑块的识别敏感度是常规 CTA 的 3 倍；MCED 一次抽血可筛 50+ 种癌症，特异性 99.5%
- **筛查的边际收益**：每多发现一例早期癌症，挽救的 QALY 远高于晚期治疗的成本

## 3. 运行协议

### 协议 1：年度 AI 体检升级
```
输入：年龄段、家族史、当前风险因素
处理：
  1. ≥40 岁：每年 AI-CCTA + MCED + 全腹部 MRI
  2. ≥30 岁：每 2 年 MCED + 低剂量胸部 CT
  3. 全年龄段：每年全谱血液生化（含 ApoB、hs-CRP、HbA1c、空腹胰岛素）
  4. 直系亲属有早发癌症/猝死：基因测序 + 提前 10 年启动专项筛查
输出：年度风险图谱 + 下一年干预重点
执行频率：每年 1 次
```

### 协议 2：动态心血管风险监控
```
输入：血脂谱（ApoB 优先于 LDL-C）、血压、HRV、冠脉影像
处理：
  1. ApoB 目标 < 60 mg/dL（无风险因素），< 50 mg/dL（有风险因素）
  2. hs-CRP 目标 < 0.5 mg/L（心脑血管低风险层）
  3. 高风险者启动他汀/PCSK9 抑制剂咨询
  4. 每 3 年复查 AI-CCTA 跟踪斑块演化
  5. 同型半胱氨酸目标 < 8 μmol/L
输出：心脑血管 10 年风险评分
执行频率：每 6 个月
```

### 协议 3：癌症早期拦截系统
```
输入：家族史、基因背景、当前症状
处理：
  1. ≥35 岁：每 6-12 月做一次 MCED 液体活检
  2. ≥40 岁：增加胃肠镜（每 3-5 年一次）
  3. 高风险基因（BRCA、TP53、Lynch 等）携带者：定制专项筛查清单
  4. 任何持续 > 2 周的异常症状：触发深度影像学检查
  5. 持续异常的肿瘤标志物：低剂量 PET-CT 排查
输出：肿瘤早筛时间线
执行频率：持续
```

### 协议 4：基线数据建立
```
输入：个人基线状态
处理：
  1. 一次性完成全基因组测序（30× 深度），建立终生可用的基因背景档案
  2. 一次性完成 PhenoAge/GrimAge 甲基化时钟检测作为生物年龄基线
  3. 建立个人 HRV、静息心率、深睡眠比例的 30 天滚动基线
  4. 任何干预前后对比基线数据，量化效果
输出：个人健康基准坐标系
执行频率：基线建立后每年微调
```

## 🔒 Gated Workflow `[v3新增]`

> 来源：addyosmani 的门禁 + claude-skills 的 Agent Harness

```
DISCUSS → PLAN → EXECUTE → VERIFY → CLOSE
   ↓         ↓        ↓          ↓        ↓
 Context   方案     执行      证据     Done/
 Read     确认     任务      检查    Escalate
```

### Phase 1: DISCUSS
- [ ] 输出 Context Read 一行判断
- [ ] 确认用户意图
- [ ] 确认约束条件

### Phase 2: PLAN
- [ ] 制定执行方案
- [ ] 确认资源可用
- [ ] 人工审批计划

### Phase 3: EXECUTE
- [ ] 逐个任务实现
- [ ] 每步有输出记录

### Phase 4: VERIFY
- [ ] 检查核心输出
- [ ] 验证完整性
- [ ] 输出证据

### Phase 5: CLOSE
- [ ] 所有检查通过 → 标记完成
- [ ] 有未通过项 → 升级给人类
- [ ] 预算耗尽 → 强制升级，不伪装成功
