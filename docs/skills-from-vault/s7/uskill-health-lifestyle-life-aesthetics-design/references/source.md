# Life Aesthetics Design & Creative Implementation

## 🎯 目标

> AI增强的生活美学创意实现流水线——从意图定义、灵感探索、方案构思到落地执行与体验迭代，将从概念到完整设计方案的时间缩短70%。

## 📥 输入

| 参数 | 类型 | 必填 | 说明 | 默认值 |
|------|------|------|------|--------|
| `project_type` | enum | ✅ | 项目类型：`space_renovation` / `event_planning` / `personal_styling` / `other` | — |
| `core_intent` | string | ✅ | 核心意图与功能目标（如"将书房改造为心流空间"） | — |

## 📋 执行步骤

### Step 1: 定义意图 (Define Intent)

**动作：**
- 清晰定义本次设计要实现的核心功能和目标（如"将书房改造为既能高效工作又能沉浸阅读的心流空间"）
- 定义希望空间/体验带来的核心情感：宁静、专注、温暖、高级感等3-5个关键词
- 设定约束条件：预算上限、时间周期、空间尺寸、家庭成员偏好

**战略考量：**
设计始于意图，而非风格。首先要明确"为什么做"和"希望达到什么感受"，这是所有后续创意的原点。好的意图定义能将设计效率提升数倍。

**质量检查点：**
- [ ] 设计目标是否具体、可衡量？
- [ ] 情感基调是否清晰？（3-5个关键词）
- [ ] 约束条件是否已明确列出？

**AI提示词：**

```
你是一位生活美学顾问。我想要进行一个生活美学项目，请帮我梳理和深化设计意图。

【项目类型】
{project_type}

【我的初步想法】
{raw_intent}

请帮我：
1. 将我的模糊想法提炼为一个清晰的、可执行的设计目标
2. 根据我的描述，推荐3-5个情感基调关键词
3. 提醒我可能遗漏的约束条件（预算、时间、空间、家庭成员等）
4. 用一句话概括这个项目的"设计宣言"

注意：保持我的核心意图不变，只是帮助我更清晰地表达。
```

---

### Step 2: 探索灵感 (Explore & Envision)

**动作：**
- 基于情感基调和功能目标，进行关键词联想（如"宁静"→"侘寂、冥想、森林、流水"）
- AI扮演"创意总监"，根据关键词生成3种不同风格方向的视觉参考
- 使用AI绘画工具（Midjourney/SD）生成概念性空间氛围图，快速探索视觉可能性
- 确定主导的色彩体系和关键材质

**战略考量：**
让AI成为灵感的放大器，在短时间内探索传统方法难以触及的风格组合与视觉创意，打破思维定式。至少收集3种不同风格方向的参考。

**质量检查点：**
- [ ] 是否收集了至少3种不同风格方向的视觉参考？
- [ ] 是否已确定主导的色彩体系和关键材质？
- [ ] AI生成的灵感是否与我的情感基调一致？

**AI提示词（风格探索）：**

```
你是一位顶尖的生活美学杂志《Kinfolk》的创意总监。
我希望为一个{space_type}进行设计，我期望的情感基调是"{emotion_keywords}"。

请为我：
1. 推荐3种符合该基调的设计风格（如侘寂风、现代有机风、日式极简），并简要描述其核心元素
2. 为每种风格提供一个包含6-8种颜色的色彩板（含HEX色值）
3. 生成一段富有感染力的文字，描述置身于这种空间中的感受
4. 推荐3-5种关键材质（如原木、亚麻、黄铜等）
```

**AI提示词（视觉原型）：**

```
（适用于Midjourney/SD）
A photorealistic interior design photo of a {space_type}, 
style of {style_name}, main color palette of {colors}, 
key elements include {elements}, 
atmosphere is {atmosphere_keywords}. 
--ar 16:9 --style raw
```

### Step 3: 构思方案 (Enact & Prototype)

**动作：**
- 进行空间布局规划：动线设计、功能分区，绘制平面布局草图
- 确定具体的色彩板（Color Palette）、家具、灯具、纺织品和装饰品
- AI扮演"顶级室内设计师"，生成详细的设计方案建议，包含具体物品搭配和理由
- 使用Figma等工具将设计方案进行可视化拼贴，形成视觉原型

**战略考量：**
此步骤将灵感"落地"为可执行的方案。运用系统思维确保空间布局兼顾美观与实用，运用摄影构图知识预演最终视觉效果。每个元素都应服务于第一步定义的情感基调。

**质量检查点：**
- [ ] 设计方案中的各元素是否和谐统一，服务于情感基调？
- [ ] 空间布局是否兼顾了美观与实用？
- [ ] 是否有明确的物品清单（含名称、链接、预算）？

**AI提示词：**

```
你是一位米兰的顶级室内设计师，擅长将功能与美学完美融合。

【已确定的信息】
设计风格：{style_name}
核心元素：{key_elements}
空间尺寸：{space_size}
功能需求：{functional_requirements}

请为我提供一份详细的设计方案建议，包含：
1. 空间布局建议（动线、功能分区）
2. 具体的家具、灯具、地毯推荐（说明推荐理由和预估价格）
3. 墙面、地面材质和颜色的建议
4. 至少3个画龙点睛的装饰品或艺术品建议
5. 整体预算估算

要求：每个推荐都要说明"为什么选它"——它如何服务于整体情感基调。
```

---

### Step 4: 落地执行 (Produce & Construct)

**动作：**
- 将设计方案拆解为可执行的任务清单，制定详细的采购清单和预算表
- 为每个任务设定明确的时间节点和责任人
- 按照计划进行采购和施工/布置
- 在实施过程中通过拍照或笔记记录关键节点和遇到的问题

**战略考量：**
将创意项目化管理，确保美好的构想能够有条不紊地、在预算内落地。预算超支是美学项目最常见的失败原因，需严格控制。

**质量检查点：**
- [ ] 是否为每个任务都设定了明确的时间节点和负责人？
- [ ] 采购清单是否包含物品名称、链接、预算和实际花费？
- [ ] 是否预留了10-15%的预算缓冲？

**AI提示词：**

```
你是一位高效的项目经理。我有一份详细的设计方案，现在需要将其落地。

【设计方案要点】
{design_plan_summary}

请帮我生成一份详细的行动计划表格，包含：
1. "任务事项" —— 具体要做什么
2. "责任人" —— 谁来做
3. "预估工时" —— 需要多久
4. "前置任务" —— 必须先完成什么
5. "预估花费" —— 需要多少钱
6. "完成状态" —— 进度追踪

并生成一份分品类的采购清单（含物品名、数量、预算、推荐渠道）。
```

---

### Step 5: 体验与迭代 (Check & Cherish)

**动作：**
- 在新空间/新体验中生活、工作，感受是否达到功能目标和情感基调
- 邀请家人或朋友体验，收集真实反馈
- 根据反馈进行小范围调整和优化，让设计持续进化
- 通过摄影、写作等方式记录最终成果，分享创造过程

**战略考量：**
生活美学是一个持续动词，而非终点名词。真正的价值在于享受创造的过程和最终带来的持续幸福感。每次实践都是下一次设计的经验积累。

**质量检查点：**
- [ ] 最终效果是否解决了最初定义的问题？
- [ ] 情感基调是否被真实感受到（而非仅视觉上好看）？
- [ ] 这次实践带来了哪些新感悟，可以反哺到知识体系？

## ⚠️ 注意事项

### 设计原则
- **功能先于形式**：美观不能牺牲实用性，好的设计是两者的完美融合
- **少即是多**：避免过度堆砌元素，留白和克制本身就是美学
- **个人风格优先**：不要盲目追随潮流，设计方案必须反映居住者的个性和生活方式

### 预算控制
- 为每个品类设定上限，总预算预留10-15%缓冲
- 区分"必须品"和"加分项"，优先保障核心元素
- 善用二手市场和DIY，低成本也能实现高品质美学

### AI使用边界
- AI提供的物品推荐和价格可能不准确，需人工核实
- AI生成的视觉原型仅供参考，实际效果受材质、光线等因素影响
- 最终的设计决策应基于个人直觉和实际体验，AI仅作辅助

## 🔒 Gated Workflow `[v3新增]`

> 来源：addyosmani 的门禁 + claude-skills 的 Agent Harness

```
DISCUSS → PLAN → EXECUTE → VERIFY → CLOSE
   ↓         ↓        ↓          ↓        ↓
 Context   方案     执行      证据     Done/
 Read     确认     任务      检查    Escalate
```

### Phase 1: DISCUSS
- [ ] 输出 Context Read 一行判断
- [ ] 确认用户意图
- [ ] 确认约束条件

### Phase 2: PLAN
- [ ] 制定执行方案
- [ ] 确认资源可用
- [ ] 人工审批计划

### Phase 3: EXECUTE
- [ ] 逐个任务实现
- [ ] 每步有输出记录

### Phase 4: VERIFY
- [ ] 检查核心输出
- [ ] 验证完整性
- [ ] 输出证据

### Phase 5: CLOSE
- [ ] 所有检查通过 → 标记完成
- [ ] 有未通过项 → 升级给人类
- [ ] 预算耗尽 → 强制升级，不伪装成功

## 🔄 IF/THEN 决策分支

- IF 输入数据质量不足以支撑自动化决策 → THEN 转交人工判断，输出不确定性说明
- IF 执行过程中遇到未预期的异常 → THEN 记录异常 + 降级处理 + 升级给人类
- IF 输出结果置信度 < 0.6 → THEN 标记低置信度 + 要求人工验证
- ELSE（所有检查通过）→ THEN 输出结果 + 验证证据

## 📋 Verification Evidence `[v3新增]`

> 来源：addyosmani 的证据要求 + claude-skills 的 verify

### 完成标志
- [ ] 核心输出已生成
- [ ] 输出格式符合预期
- [ ] 无明显错误

### 失败处理
- 输出不完整 → 继续补充，不标记完成
- 连续 3 次失败 → 升级给人类，附上当前状态
- 绝不伪装成功
