## 一句话

用 HRV 监控有氧基础期的恢复与负荷：Zone2 打底，HRV 决定今天能不能上强度。

## 要点
- 指标用法：晨起 HRV 滚动基线；持续低于基线 = 恢复不足，优先 Zone2 或休息；稳定偏高 = 可安排阈值/间歇。
- 训练结构：周 80/20（低强度为主 + 少量高强度）；有氧基础是一切耐力的根基。
