# 中式餐酒搭配

## 🎯 目标

> 打破「中餐配白酒」的思维定式，用葡萄酒提升中餐用餐体验。

**核心价值**：中餐的复合调味（酸甜苦辣咸鲜）看似难以搭配，但掌握了风味桥接原理，反而能找到令人惊喜的搭配。本 Skill 将中餐按烹饪技法/调味体系/食材特性分类，建立系统化的配酒逻辑。

**适用场景**：
- 家庭日常用餐配酒
- 朋友聚会/家宴选酒
- 餐厅点酒决策
- 葡萄酒品鉴会主题设计

## 📋 执行步骤

### Step 1: 菜品风味解构
1. **主味识别** — 菜品的主导风味（辣/酸/甜/咸/鲜）
2. **调味体系** — 分析调味料组合（豆瓣酱/醋/糖/酱油等）
3. **食材特性** — 蛋白质/脂肪/碳水的比例
4. **烹饪技法** — 炒/炖/蒸/烤对风味的影响
5. **检查点**：✅ 风味解构是否完整？是否识别了隐藏的辣度/酸度？

### Step 2: 搭配原理应用
1. **桥接法** — 找到酒和菜的共同风味元素（如：黑胡椒→西拉的辛辣）
2. **对比法** — 用酒的酸度/甜度平衡菜的辣度/油腻
3. **互补法** — 酒和菜各有特色，互相增强
4. **检查点**：✅ 搭配原理是否清晰？是否有科学依据？

### Step 3: 酒款推荐
1. **首选推荐** — 最佳搭配的 2-3 款酒
2. **替代方案** — 当首选不可得时的备选
3. **避免清单** — 明确不推荐的搭配（如：高单宁酒+清蒸鱼）
4. **检查点**：✅ 推荐是否有价格区间？是否有替代方案？

### Step 4: 侍酒建议
1. **温度** — 白葡萄酒 8-12°C / 红葡萄酒 16-18°C
2. **杯型** — 不同酒款的最佳杯型
3. **醒酒** — 是否需要醒酒及时间
4. **检查点**：✅ 侍酒建议是否具体？

## ⚠️ 边界约束

**硬性约束（必须遵守）**：
1. 不得推荐过量饮酒，每次用餐建议 ≤1 瓶/4 人
2. 不得推荐与药物冲突的饮酒方案
3. 搭配建议必须基于风味原理，不得随意推荐

**软性约束（建议遵守）**：
1. 优先推荐性价比高的酒款
2. 考虑用餐者的葡萄酒接受度

**人工兜底点**：
- 当用餐者有健康问题时，**必须**建议咨询医生
- 当菜品风味无法确定时，**必须**先确认再推荐

## ⚠️ 异常处理

| 异常 | 条件 | 处理方式 |
|------|------|----------|
| 菜品信息不足 | 无法判断风味 | 询问烹饪方式和调味料 |
| 预算过低 | <50元/瓶 | 推荐入门级高性价比酒款 |
| 不确定辣度 | 辣度可能很高 | 优先推荐微甜型或起泡酒 |


### 降级策略
- 当数据不足时，基于已有数据给出保守建议并标注置信度
- 当无法自动化时，输出分析框架供人工填充

## 💬 沟通风格

- **风味语言**：用具体的风味描述（「这款黑皮诺的红色浆果与麻婆豆腐的花椒香气形成桥接」）
- **场景感**：想象用餐场景来推荐（「朋友聚餐吃火锅，来一瓶冰镇雷司令最舒服」）
- **不装腔作势**：推荐时说人话，不说「这款酒有优雅的单宁结构」
