# 力量训练体系

## 🎯 目标

> 为跑者构建互补性力量训练计划，提升跑步经济性并预防伤病。

**核心价值**：跑者最大的误区是「只跑不练力量」。本 Skill 将力量训练与跑步训练整合，确保两者互相增强而非互相消耗。

**适用场景**：
- 跑者的力量补充训练
- 核心稳定性提升
- 臀腿力量强化（预防膝盖伤病）
- 上肢力量维持（摆臂效率）

## 📥 输入

| 参数 | 类型 | 必填 | 默认值 | 说明 |

| `training_level` | enum | ❌ | `"intermediate"` | 级别：`beginner` / `intermediate` / `advanced` |

| `injury_history` | array | ❌ | — | 历史伤病（如膝盖/足底/髂胫束） |

## 📋 执行步骤

### Step 1: 需求评估
1. **跑步经济性分析** — 当前跑步的薄弱环节
2. **伤病风险评估** — 历史伤病和潜在风险
3. **器械可用性** — 家庭/健身房条件
4. **检查点**：✅ 是否识别了跑步相关的薄弱环节？是否有伤病史？

### Step 2: 训练计划设计
1. **动作选择** — 复合动作为主（深蹲/硬拉/卧推/引体）
2. **跑步互补** — 强化跑步中薄弱的肌群（臀中肌/核心/小腿）
3. **负荷安排** — 力量日与跑步日的间隔（≥6 小时）
4. **检查点**：✅ 动作是否覆盖了跑步相关肌群？负荷是否合理？

### Step 3: 渐进超负荷
1. **重量递增** — 每 1-2 周增加 2.5-5% 负荷
2. **容量管理** — 总组数 × 次数 × 重量的周趋势
3. **减载周期** — 每 4 周安排 1 周减载
4. **检查点**：✅ 是否有渐进计划？是否有减载周期？

### Step 4: 与跑步整合
1. **训练日编排** — 力量日 vs 跑步日的最佳排列
2. **赛前调整** — 赛前 2-3 周减少力量训练量
3. **恢复协调** — 力量训练后的恢复与跑步恢复的平衡
4. **检查点**：✅ 力量训练是否与跑步计划冲突？赛前是否调整？

## ⚠️ 边界约束

**硬性约束（必须遵守）**：
1. 动作质量必须优先于重量，技术不达标不得加重
2. 当跑步训练量 >60km/周时，力量训练必须减量
3. 不得在跑步前进行高强度力量训练

**软性约束（建议遵守）**：
1. 力量训练后 24 小时内不安排高强度跑步
2. 每次力量训练控制在 45-60 分钟

**人工兜底点**：
- 当出现关节疼痛时，**必须**停止相关动作并评估
- 当不确定动作标准时，**必须**观看教学视频或请教教练

## ⚠️ 异常处理

| 异常 | 条件 | 处理方式 |
|------|------|----------|
| 关节疼痛 | 力量训练中出现 | 立即停止，替换为无痛动作 |
| 跑步成绩下降 | 力量训练后配速变慢 | 检查训练量是否过大，减少力量容量 |
| 恢复不足 | 连续疲劳 | 增加休息日，降低力量训练强度 |


### 降级策略
- 当数据不足时，基于已有数据给出保守建议并标注置信度
- 当无法自动化时，输出分析框架供人工填充

## 💬 沟通风格

- **安全第一**：永远把动作质量放在重量前面
- **数据追踪**：每个动作的重量/次数都要记录
- **互补思维**：力量训练是为跑步服务的，不是独立目标

## 📝 自检清单

- [ ] 动作是否覆盖了跑步相关肌群？
- [ ] 是否有渐进超负荷计划？
- [ ] 力量日与跑步日是否合理间隔？
- [ ] 赛前是否调整力量训练量？
- [ ] 动作标准是否有保障？

## ✅ 校验验收规则

**格式校验**：
- [ ] 训练计划包含动作/组数/次数/休息时间
- [ ] 周计划结构清晰

**内容校验**：
- [ ] 动作选择与跑步互补
- [ ] 渐进规则具体可执行
- [ ] 伤病预防措施到位

**合规校验**：
- [ ] 未违反硬性约束
- [ ] 动作质量优先原则已落实


### OVP 验证信号
- 核心指标趋势是否向好
- 用户使用频率是否稳定
- 输出质量是否达到预期

## 🔄 迭代触发条件

**Self-Play 触发**：
- **频率**：monthly
- **触发条件**：
  - 用户反馈训练效果不明显
  - 跑步成绩停滞或下降
  - 出现新的伤病

**版本升级触发**：
- 当新增训练动作或周期化方案时，升级 minor 版本

**废弃触发**：
- 当所依赖的数据源/API 停止服务时，标记为 deprecated
- 当出现明显更优的替代方案时，评估迁移并标记版本
- 当建立完整的力量训练数据库时，升级 major 版本
