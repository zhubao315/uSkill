
# Coros 数据体系

> O-101 断链治理正本：中文入口，承接 uSkill 索引与 agency-agents 映射入链；详版见关联 uSkill。

## 一句话

COROS 手表采集的训练负荷、恢复与有氧基础数据，如何组成可执行的训练决策回路。

## 要点
- 数据层：每日 HRV/静息心率/睡眠 → 训练 EQ/EVO（负荷）→ 赛事预测与有氧基础分。
- 决策层：负荷急升 + HRV 走低 = 降量；连续绿灯 + 底线扎实 = 可加量；EPOC 堆积过高 = 强制恢复。
