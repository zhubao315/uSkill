# 跑步训练姿势矫正协议

## 1. 技能定义

将"本能跑步"重新编程为"技术跑步"的 8 周系统化矫正方案。覆盖感知→分解→整合→内化全周期，通过视觉反馈（录像分析）与本体感知反馈（赤足训练）双通道实现跑姿优化。核心目标：将肌肉从"推进引擎"降级为"姿态伺服器"。

## 2. 底层原理

- 旧的神经通路不会被删除，只会被新的更强通路覆盖（约第 6-8 周完成覆盖）
- 姿势矫正是"做减法"——去除多余动作（蹬地、过度跨步），而非添加新动作
- 步频 ≥ 180 spm 是物理约束——此步频下过度跨步的几何可能性被消除
- 赤足训练是强制约束——脚跟落地会立即产生疼痛反馈，建立"着地=轻盈"的本体感知锚点

## 3. 运行协议

**API-1：感知校准（第 1-2 周）**
```
输入：current_run_form（当前跑姿视频 10m×3 组，≥60fps）
处理：
  1. 逐帧分析错误信号（按风险权重排序）：
     [W=3] 着地点在重心前方 > 10cm？
     [W=3] 脚跟先着地？
     [W=2] 后腿蹬直（膝关节伸展 > 170°）？
     [W=2] 弯腰前倾（非脚踝前倾）？
     [W=1] 肩膀紧张上耸？
  2. 建立个人 Top 3 错误优先级清单
输出：error_priority_list
```

**API-2：分解训练（第 3-4 周）**
```
输入：error_priority_list
处理：
  1. 每日 15 分钟专项：
     - Pose 站姿：单脚平衡 30s × 5 组
     - Fall 练习：靠墙前倾 10 次（感受脚踝处倾倒）
     - Pull 练习：原地快速拉脚 20 次 × 3 组（脚跟接近臀部）
  2. 赤足短距离跑（草地 50m × 5 组）→ 建立前掌着地的本体感知
  3. 节拍器 180 BPM 跟拍跑步 10 分钟
  4. 每周录像对比基线
输出：technique_baseline（评分 0-10）
```

**API-3：整合内化（第 5-8 周）**
```
输入：technique_baseline + 日常跑步计划
处理：
  1. 跑前 5 分钟热身序列：Pose 站 30s → Fall 5 次 → Pull 10 次 → 串联慢跑 2min
  2. 每公里"3 秒自检"：着地轻盈？步频 ≥ 180？前倾从脚踝处？
  3. 距离和速度降低 20%，优先保证动作质量
  4. 每周录像评分，目标 ≥ 8/10 进入维护期
输出：run_form_score
```

**API-4：长期维护**
```
处理：
  1. 每月 1 次赤足跑 + 录像自检
  2. 每季度 1 次完整跑姿评估（10km+ 长距离后录像）
  3. 伤病出现时 → 第一步检查跑姿（不是休息）
  4. 步频日常监控：连续 3 次跑步步频 < 175 = 技术退化信号
```

## 异常处理

| 异常 | 处理 |
|------|------|
| 改正后反而更累 | 正常适应期（2-4 周），降低强度但不放弃 |
| 局部疼痛加剧 | 立即停止，检查是否引入新错误 |
| 步频无法提升 | 先缩短步幅，用节拍器强制锁定 |
| 视频分析无法自我判断 | 寻求专业教练或 AI 姿态分析工具 |
| 恢复期想追求速度 | 禁止——恢复期追求速度会重新触发旧错误模式 |

## 🛡️ Three-Tier Boundaries `[v3新增]`

> 来源：addyosmani/agent-skills 的边界系统

### ✅ Always do（自动执行）
- 执行核心功能（见原技能流程）
- 输出结构化结果
- 检查常见错误

### ⚠️ Ask first（先问再做）
- 用户意图不明确时
- 操作不可逆时
- 涉及外部系统时

### 🚫 Never do（绝对禁止）
- 不跳过验证步骤
- 不在用户未确认时执行高风险操作
- 不伪装成功（失败就上报）

## 🔒 Gated Workflow `[v3新增]`

> 来源：addyosmani 的门禁 + claude-skills 的 Agent Harness

```
DISCUSS → PLAN → EXECUTE → VERIFY → CLOSE
   ↓         ↓        ↓          ↓        ↓
 Context   方案     执行      证据     Done/
 Read     确认     任务      检查    Escalate
```

### Phase 1: DISCUSS
- [ ] 输出 Context Read 一行判断
- [ ] 确认用户意图
- [ ] 确认约束条件

### Phase 2: PLAN
- [ ] 制定执行方案
- [ ] 确认资源可用
- [ ] 人工审批计划

### Phase 3: EXECUTE
- [ ] 逐个任务实现
- [ ] 每步有输出记录

### Phase 4: VERIFY
- [ ] 检查核心输出
- [ ] 验证完整性
- [ ] 输出证据

### Phase 5: CLOSE
- [ ] 所有检查通过 → 标记完成
- [ ] 有未通过项 → 升级给人类
- [ ] 预算耗尽 → 强制升级，不伪装成功

## 🔄 IF/THEN 决策分支

- IF 输入数据质量不足以支撑自动化决策 → THEN 转交人工判断，输出不确定性说明
- IF 执行过程中遇到未预期的异常 → THEN 记录异常 + 降级处理 + 升级给人类
- IF 输出结果置信度 < 0.6 → THEN 标记低置信度 + 要求人工验证
- ELSE（所有检查通过）→ THEN 输出结果 + 验证证据


## 📝 Prompt 模板

> 用于调用 AI 辅助执行本技能的标准提示词模板。

**核心提示词**：
```
你是一位跑步姿势矫正专家，精通生物力学分析、常见跑姿问题诊断（过度跨步、骨盆下沉、手臂摆动异常等）和针对性矫正训练方案设计。
输入：用户提供的跑步视频、照片或跑姿描述
要求：从足部着地、膝盖位置、躯干前倾、手臂摆动等维度进行姿势分析，识别潜在损伤风险
输出格式：姿势诊断 → 风险评估 → 矫正动作处方 → 练习进阶计划
```

**使用说明**：
- 替换方括号内的占位符为实际内容
- 根据具体场景调整要求部分
- 输出格式可根据需要修改


## 🎯 技能概述

> 本技能提供 健康与运动 领域的标准化操作流程，帮助用户高效完成相关任务。

**核心价值**：将复杂操作标准化为可重复执行的步骤，降低出错率，提升效率。

**适用场景**：
1. 日常操作执行
2. 新手快速上手
3. 质量一致性保证

## 📋 Verification Evidence `[v3新增]`
