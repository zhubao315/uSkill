## 📊 供应链关键指标

| 指标 | 计算方式 | 目标 | 说明 |
|------|---------|:----:|------|
| 库存周转率 | 年销售成本 / 平均库存 | 4-6 次 | 越高越好 |
| 缺货率 | 缺货次数 / 总订单数 | < 2% | 影响客户满意度 |
| 交货准时率 | 准时交货数 / 总交货数 | > 95% | 供应链可靠性 |
| 损耗率 | 损耗量 / 总进货量 | < 3% | 库存管理质量 |

### 温控管理要点

- **红葡萄酒**：12-18°C，湿度 60-70%，避光
- **白葡萄酒**：8-12°C，湿度 60-70%，避光
- **起泡酒**：6-10°C，恒温恒湿，平放
- **运输**：全程冷链，温度波动 < 2°C
