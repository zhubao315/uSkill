## 一句话

用固定晨间序列降低启动成本、稳住皮质醇节律，把「决定今天干什么」从前额叶挪到脚本。

## 要点
- 经典序列：光照/补水 → 轻度活动 → 深度工作单任务 → 检查点；时长 30–60 分钟可裁剪。
- 生理锚点：晨间常规影响掌控感与皮质醇（见关联词条）；与昼夜节律优化技能同族。
