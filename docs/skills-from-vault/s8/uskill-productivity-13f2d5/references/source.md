# 费曼技巧学习法

## 核心定义

费曼技巧是以诺贝尔物理学奖得主理查德·费曼命名的学习方法，核心理念是"如果你不能用简单的语言解释，说明你没有真正理解"。

## 四步法

| 步骤 | 行动 | 关键点 |
|------|------|--------|
| **1. 选择概念** | 确定要学习的概念 | 一次一个 |
| **2. 教给别人** | 用简单语言解释 | 假设对方是12岁小孩 |
| **3. 识别卡壳** | 找出解释不清的地方 | 这是真正的学习点 |
| **4. 回顾简化** | 回到材料重新学习 | 用更简单的语言重述 |

## 为什么有效

| 机制 | 说明 |
|------|------|
| **主动提取** | 比被动阅读更有效 |
| **元认知** | 暴露知识盲区 |
| **简化压缩** | 深度理解需要高度概括 |
| **多角度** | 用不同方式解释加深理解 |

## 实践方式

1. **写作**：把学到的写成文章
2. **教学**：给别人讲解
3. **笔记**：用简单的话重写
4. **讨论**：参与话题讨论

## 🛡️ Three-Tier Boundaries `[v3新增]`

> 来源：addyosmani/agent-skills 的边界系统

### ✅ Always do（自动执行）
- 执行核心功能（见原技能流程）
- 输出结构化结果
- 检查常见错误

### ⚠️ Ask first（先问再做）
- 用户意图不明确时
- 操作不可逆时
- 涉及外部系统时

### 🚫 Never do（绝对禁止）
- 不跳过验证步骤
- 不在用户未确认时执行高风险操作
- 不伪装成功（失败就上报）

## 🔒 Gated Workflow `[v3新增]`

> 来源：addyosmani 的门禁 + claude-skills 的 Agent Harness

```
DISCUSS → PLAN → EXECUTE → VERIFY → CLOSE
   ↓         ↓        ↓          ↓        ↓
 Context   方案     执行      证据     Done/
 Read     确认     任务      检查    Escalate
```

### Phase 1: DISCUSS
- [ ] 输出 Context Read 一行判断
- [ ] 确认用户意图
- [ ] 确认约束条件

### Phase 2: PLAN
- [ ] 制定执行方案
- [ ] 确认资源可用
- [ ] 人工审批计划

### Phase 3: EXECUTE
- [ ] 逐个任务实现
- [ ] 每步有输出记录

### Phase 4: VERIFY
- [ ] 检查核心输出
- [ ] 验证完整性
- [ ] 输出证据

### Phase 5: CLOSE
- [ ] 所有检查通过 → 标记完成
- [ ] 有未通过项 → 升级给人类
- [ ] 预算耗尽 → 强制升级，不伪装成功

## 🔄 IF/THEN 决策分支

- IF 输入数据质量不足以支撑自动化决策 → THEN 转交人工判断，输出不确定性说明
- IF 执行过程中遇到未预期的异常 → THEN 记录异常 + 降级处理 + 升级给人类
- IF 输出结果置信度 < 0.6 → THEN 标记低置信度 + 要求人工验证
- ELSE（所有检查通过）→ THEN 输出结果 + 验证证据

## 🎯 技能概述

> 本技能提供 认知与学习 领域的标准化操作流程，帮助用户高效完成相关任务。

**核心价值**：将复杂操作标准化为可重复执行的步骤，降低出错率，提升效率。

**适用场景**：
1. 日常操作执行
2. 新手快速上手
3. 质量一致性保证

## 📋 Verification Evidence `[v3新增]`

> 来源：addyosmani 的证据要求 + claude-skills 的 verify

- [ ] 核心输出已生成
- [ ] 输出格式符合预期

### 失败处理

- 绝不伪装成功
