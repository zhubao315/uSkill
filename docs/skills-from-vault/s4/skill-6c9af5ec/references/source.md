
# 销售漏斗管理

> O-101 断链治理正本：中文入口，承接 uSkill 索引与 agency-agents 映射入链；详版见关联 uSkill。

## 一句话

漏斗不漏水才能算清每一分钱：按阶段定义转化率、停留时长与瓶颈动作，而不是月底看总数。

## 要点
- 阶段：线索 → MQL/SQL → 商机 → 方案/POC → 谈判 → 成交；每阶段定义进入/退出准则。
- 诊断：阶段转化率环比、停留超时商机数、输单原因 Pareto；先修最大泄漏段。
- 与 [[销售方案与提案]]、客户成功扩展笔记同链；详版 uSkill 提供管道分析模板。
