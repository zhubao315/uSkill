## 🔄 IF/THEN 决策分支

- IF 输入数据质量不足以支撑自动化决策 → THEN 转交人工判断，输出不确定性说明
- IF 执行过程中遇到未预期的异常 → THEN 记录异常 + 降级处理 + 升级给人类
- IF 输出结果置信度 < 0.6 → THEN 标记低置信度 + 要求人工验证
- ELSE（所有检查通过）→ THEN 输出结果 + 验证证据

## 🧪 Self-Play 测试用例

| # | 场景 | 输入 | 预期输出 | 验证点 |
|---|------|------|----------|--------|
| 1 | 正常执行 | 标准输入数据 | 符合预期的输出 | 格式正确 + 内容准确 |
| 2 | 边界输入 | 极端/空/超长输入 | 降级处理或错误提示 | 不崩溃 + 有明确反馈 |
| 3 | 数据缺失 | 缺少必填参数 | 参数补全提示 | 不编造数据 |
| 4 | 异常场景 | 非预期的输入类型 | 友好的错误处理 | 不泄露内部信息 |
| 5 | 并发场景 | 多个相同请求同时到达 | 结果一致或正确排队 | 无数据竞争 |


## 📊 操作规范

**前置条件**：
- 确认输入数据完整且格式正确
- 确认相关工具/环境可用
- 确认权限和访问级别足够

**执行标准**：
- 严格按照步骤顺序执行，不跳步
- 每步完成后记录执行结果
- 遇到异常立即记录并按降级策略处理
- 关键操作需二次确认

**后置检查**：
- 验证输出格式和内容完整性
- 检查是否有遗漏的副作用
- 更新相关状态和日志
- 通知相关方执行结果

## 📋 常见问题处理

| 问题 | 可能原因 | 处理方式 |
|------|---------|---------|
| 执行超时 | 数据量过大/资源不足 | 分批处理/扩容 |
| 输出异常 | 输入数据异常 | 数据清洗/人工复核 |
| 权限不足 | 角色配置问题 | 联系管理员/申请权限 |
| 工具不可用 | 服务故障/维护中 | 等待恢复/切换备用 |

## 📊 点单流程指标

| 指标 | 计算方式 | 目标 | 说明 |
|------|---------|:----:|------|
| 点单转化率 | 完成点单 / 进入页面 | > 80% | 流程顺畅度 |
| 平均点单时长 | 总时长 / 点单数 | < 3 min | 用户体验 |
| 放弃率 | 放弃数 / 开始数 | < 15% | 流程摩擦 |
| 复购率 | 重复购买 / 总购买 | > 40% | 客户忠诚度 |

### 关键优化节点

| 节点 | 优化方向 | 预期效果 |
|------|---------|---------|
| 浏览 → 选择 | 智能推荐 + 分类导航 | 转化率 +15% |
| 选择 → 确认 | 简化选项 + 默认值 | 时长 -30% |
| 确认 → 支付 | 一键支付 + 多渠道 | 放弃率 -20% |
| 支付 → 交付 | 实时状态 + 预计时间 | 满意度 +25% |
