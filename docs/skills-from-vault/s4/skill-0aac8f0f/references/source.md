
# 广告创意策略

> O-101 断链治理正本：中文入口，承接 uSkill 索引与 agency-agents 映射入链；详版见关联 uSkill。

## 一句话

在自动出价时代，创意是唯一真正由你控制的杠杆——策略先于素材，素材服务于可测假设。

## 要点
- 结构：受众洞察 → 信息角度（3–5 个可测假设）→ 素材变体 → 渠道适配 → 以 CTR/CVR/CPA 迭代。
- 与投放协同：创意假设必须能在 PPC/信息流后台被独立归因；程序化场景见归档笔记。
- agency-agents 映射中 Creative Strategist 角色对应本中文入口。
