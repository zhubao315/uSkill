
# 葡萄酒供应链管理最佳实践

> O-101 断链治理正本：中文入口，承接 uSkill 索引与 agency-agents 映射入链；详版见关联 uSkill。

## 一句话

从酿造到杯中：温控、溯源、库存周转与渠道合规构成葡萄酒供应链的四条硬约束。

## 要点
- 四条硬约束：全程温控（冷链断裂即货损）· 批次溯源（年份/产区/灌装）· 库存周转（陈年与动销平衡）· 进口合规（标签/税费/许可）。
- 渠道分层：直供餐饮 / 经销商 / 电商各对周转与毛利的要求不同，SKU 宽度随之收缩。
- 理论背景见 [[《葡萄酒商业管理》-霍尔]]；品鉴与选酒 SOP 属另一侧（SOP-32 起）。
