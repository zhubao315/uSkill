# 销售方案与提案

> O-101 断链治理正本：中文入口，承接 uSkill 索引与 agency-agents 映射入链；详版见关联 uSkill。

## 一句话

提案不是功能清单，是帮客户赢得他自己的战役——以客户业务结果重组证据与路径。

## 要点
- 结构：现状痛点量化 → 目标状态 → 方案与里程碑 → 证据（案例/数据）→ 风险与缓解 → 商务条款。
- 写作纪律：每页只回答客户一个反对意见；ROI 数字可复算；决策人与使用者分开表述。
- 与销售漏斗的「方案阶段」衔接：提案发出后必须绑定下一步会议，而非石沉大海。
