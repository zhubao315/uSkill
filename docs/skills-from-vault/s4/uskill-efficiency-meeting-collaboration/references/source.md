
# 会议效率与协作

> 提升会议质量和协作效率的系统方法——让每次会议都有明确产出。

## 会议分类

| 类型 | 时长 | 人数 | 产出 |
|------|:----:|:----:|------|
| **站会** | 15min | 5-8 | 同步进度/识别阻塞 |
| **决策会** | 30-60min | 3-7 | 明确的决策+责任人 |
| **头脑风暴** | 45-90min | 4-10 | 创意清单+优先级 |
| **复盘会** | 60min | 5-10 | 经验教训+行动项 |

## 效率提升清单

**会前**：
- [ ] 明确会议目标（同步/决策/头脑风暴）
- [ ] 只邀请必要参与者
- [ ] 提前发送议程和材料

**会中**：
- [ ] 准时开始，不等迟到者
- [ ] 指定记录人
- [ ] 控制讨论范围（Parking Lot 偏离话题）

**会后**：
- [ ] 24h 内发送会议纪要
- [ ] 明确 Action Item + 责任人 + 截止时间
- [ ] 跟踪执行进度

## 常见反模式

- ❌ 无议程会议 → 讨论发散，无产出
- ❌ 超员会议 → 人多嘴杂，效率低
- ❌ 无结论会议 → 讨论了但没决策
- ❌ 无跟进会议 → 纪要发了但没人执行

## 🔄 IF/THEN 决策分支

- IF 输入数据质量不足以支撑自动化决策 → THEN 转交人工判断，输出不确定性说明
- IF 执行过程中遇到未预期的异常 → THEN 记录异常 + 降级处理 + 升级给人类
- IF 输出结果置信度 < 0.6 → THEN 标记低置信度 + 要求人工验证
- ELSE（所有检查通过）→ THEN 输出结果 + 验证证据

## 🧪 Self-Play 测试用例

| # | 场景 | 输入 | 预期输出 | 验证点 |
|---|------|------|----------|--------|
| 1 | 正常执行 | 标准输入数据 | 符合预期的输出 | 格式正确 + 内容准确 |
| 2 | 边界输入 | 极端/空/超长输入 | 降级处理或错误提示 | 不崩溃 + 有明确反馈 |
| 3 | 数据缺失 | 缺少必填参数 | 参数补全提示 | 不编造数据 |
| 4 | 异常场景 | 非预期的输入类型 | 友好的错误处理 | 不泄露内部信息 |
| 5 | 并发场景 | 多个相同请求同时到达 | 结果一致或正确排队 | 无数据竞争 |


## 📊 时间追踪规范

**追踪粒度**：
- 深度工作：以 25 分钟（番茄钟）为单位
- 浅层工作：以 15 分钟为单位
- 会议/沟通：以实际时长为单位
- 休息/杂项：以 30 分钟为单位

**分类标准**：
- 深度工作：需要高度专注的创造性/分析性任务
- 浅层工作：邮件/消息/行政/常规操作
- 会议：同步沟通/协调/汇报
- 杂项：通勤/用餐/个人事务

**数据来源**：
- Toggl Track：自动追踪 + 手动校正
- RescueTime：后台监控 + 网站/App 分类
- 日历：会议时间 + 类型
- 任务管理工具：任务完成时间 + 优先级

## 📈 效率指标体系

| 指标 | 计算方式 | 目标值 | 数据源 |
|------|---------|:------:|--------|
| 深度工作占比 | 深度时间 / 总工作时间 | ≥ 40% | Toggl |
| 任务完成率 | 完成数 / 计划数 | ≥ 80% | Todoist |
| 番茄钟效率 | 有效番茄 / 总番茄 | ≥ 75% | Toggl |
| 会议效率 | 有结论会议 / 总会议 | ≥ 70% | 日历+笔记 |
| 切换成本 | 每日任务切换次数 | ≤ 15 次 | RescueTime |

## 📊 会议效能评估

### 会议ROI公式
```
会议ROI = 产出价值 / (参会人数 × 时长 × 人均时薪)
```

**目标ROI**：决策会 ≥ 5x，站会 ≥ 3x，头脑风暴 ≥ 2x

### 会议健康度指标

| 指标 | 计算方式 | 目标 | 预警 |
|------|---------|:----:|:----:|
| 会议占比 | 会议时间 / 总工作时间 | < 30% | > 40% |
| 决策率 | 有明确决策的会议 / 总会议 | > 80% | < 60% |
| 行动项完成率 | 完成的行动项 / 总行动项 | > 90% | < 70% |
| 参会人效 | 产出价值 / 参会总成本 | ≥ 3x | < 2x |

### 异步替代方案

| 会议类型 | 替代方式 | 适用场景 |
|---------|---------|---------|
| 信息同步 | 录屏+文档 | 单向信息传递 |
| 简单决策 | 异步投票+截止时间 | 选项明确的决策 |
| 进度更新 | 周报+看板 | 常规进度同步 |
| 头脑风暴 | 共享文档+评论 | 异步团队成员 |
