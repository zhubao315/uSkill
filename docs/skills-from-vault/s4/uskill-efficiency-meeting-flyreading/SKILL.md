# 会议飞读法

> 高效阅读和处理会议文档的技巧——在短时间内抓取关键信息。

## 三步飞读法

| 步骤 | 动作 | 时间 |
|------|------|:----:|
| **扫描** | 标题/摘要/结论，判断优先级 | 1min |
| **提取** | 关键数据/决策点/行动项 | 2-3min |
| **关联** | 与自己负责部分的关联 | 1-2min |

## 信息过滤

- **必读**：与自己直接相关的 Action Item
- **选读**：决策背景和推理过程
- **略读**：数据附录和详细分析

## 工具辅助

- 用高亮标注关键决策和截止时间
- 用批注记录自己的问题和行动项
- 会前 5 分钟飞读完所有材料


## 📤 输出 Schema

| 字段 | 类型 | 说明 |
|------|------|------|
| result | string | 分析/执行结果 |
| confidence | number | 置信度（0-1） |


## 📥 输入 Schema

| 参数 | 类型 | 必填 | 说明 |
|------|------|:----:|------|
| input_data | string | ✅ | 核心输入数据 |
| context | string | ❌ | 上下文信息 |


## 🔄 执行流程

1. **准备阶段**：收集输入数据，确认参数完整性
2. **分析阶段**：对输入进行分析处理，识别关键信息
3. **执行阶段**：按照标准流程执行操作
4. **验证阶段**：检查输出是否符合预期
5. **输出阶段**：生成最终结果并记录日志


## 🧪 Self-Play 测试用例

| # | 场景 | 输入 | 预期输出 | 验证点 |
|---|------|------|----------|--------|
| 1 | 正常执行 | 标准输入数据 | 符合预期的输出 | 格式正确 + 内容准确 |
| 2 | 边界输入 | 极端/空/超长输入 | 降级处理或错误提示 | 不崩溃 + 有明确反馈 |
| 3 | 数据缺失 | 缺少必填参数 | 参数补全提示 | 不编造数据 |
| 4 | 异常场景 | 非预期的输入类型 | 友好的错误处理 | 不泄露内部信息 |
| 5 | 并发场景 | 多个相同请求同时到达 | 结果一致或正确排队 | 无数据竞争 |


## 📊 时间追踪规范

**追踪粒度**：
- 深度工作：以 25 分钟（番茄钟）为单位
- 浅层工作：以 15 分钟为单位
- 会议/沟通：以实际时长为单位
- 休息/杂项：以 30 分钟为单位

**分类标准**：
- 深度工作：需要高度专注的创造性/分析性任务
- 浅层工作：邮件/消息/行政/常规操作
- 会议：同步沟通/协调/汇报
- 杂项：通勤/用餐/个人事务

**数据来源**：
- Toggl Track：自动追踪 + 手动校正
- RescueTime：后台监控 + 网站/App 分类
- 日历：会议时间 + 类型
- 任务管理工具：任务完成时间 + 优先级

## 📈 效率指标体系

| 指标 | 计算方式 | 目标值 | 数据源 |
|------|---------|:------:|--------|
| 深度工作占比 | 深度时间 / 总工作时间 | ≥ 40% | Toggl |
| 任务完成率 | 完成数 / 计划数 | ≥ 80% | Todoist |
| 番茄钟效率 | 有效番茄 / 总番茄 | ≥ 75% | Toggl |
| 会议效率 | 有结论会议 / 总会议 | ≥ 70% | 日历+笔记 |
| 切换成本 | 每日任务切换次数 | ≤ 15 次 | RescueTime |

- IF 输入数据质量不足以支撑自动化决策 → THEN 转交人工判断，输出不确定性说明

- ELSE（所有检查通过）→ THEN 输出结果 + 验证证据

## 📊 操作手册

### 执行前准备
1. 确认所有输入参数已就位
2. 检查环境和工具可用性
3. 阅读相关文档和历史案例
4. 准备异常处理预案

### 执行步骤详解
1. **初始化**：加载配置和依赖，验证环境
2. **数据采集**：收集必要的输入数据
3. **预处理**：清洗和转换数据格式
4. **核心处理**：执行主要业务逻辑
5. **后处理**：格式化输出，生成报告
6. **验证**：检查输出质量，确认无误
7. **归档**：保存结果，更新日志

### 常见问题处理

| 问题 | 症状 | 解决方案 |
|------|------|---------|
| 输入格式错误 | 解析失败 | 检查格式，参考示例 |
| 执行超时 | 长时间无响应 | 分批处理，增加超时 |
| 输出异常 | 结果不合理 | 降级处理，人工复核 |
| 权限不足 | 操作被拒绝 | 联系管理员，申请权限 |

### 最佳实践

### 质量保证
