
# 客户点单工作流优化

> O-101 断链治理正本：中文入口，承接 uSkill 索引与 agency-agents 映射入链；详版见关联 uSkill。

## 一句话

压缩客户从「想买」到「下单成功」的摩擦：路径、文案、支付、异常四段式诊断与重排。

## 要点
- 诊断四段：入口可见性 → 选项认知负荷 → 表单/支付阻力 → 失败挽回（超时、缺货、支付失败）。
- 度量：漏斗逐步转化率、下单时长 P50/P90、支付失败率；先修最大流失段再谈视觉。
- 住宿/餐饮点单变体与本技能同源，见关联 uSkill。
