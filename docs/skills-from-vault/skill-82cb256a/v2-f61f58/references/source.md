
# 剧作深度分析 v2

> O-101 断链治理正本：中文入口，承接 uSkill 索引与 agency-agents 映射入链；详版见关联 uSkill。

## 一句话

从结构、角色、主题三维深挖剧本/影视叙事——v2 强化「可复用的分析模板」而非印象式影评。

## 要点
- 三维：结构（节拍/转折点/高潮配置）· 角色（欲望-缺陷-弧光）· 主题（命题如何被情节演绎）。
- 输出形态：节拍表 + 关键场景细读 + 主题句；避免只复述剧情。
- 与电视剧深度解读 SOP、游戏叙事设计归档互补；详版 uSkill 含分析框架表。
