
# 地图制图设计

> O-101 断链治理正本：中文入口，承接 uSkill 索引与 agency-agents 映射入链；详版见关联 uSkill。

## 一句话

地图是论点不是壁纸：投影与尺度先于配色，图例与注记服务于一次说清的空间主张。

## 要点
- 决策序：用途（导航/分析/展示）→ 投影与范围 → 数据分级与符号 → 色彩与注记 → 可读性验收。
- 制图通则：少即是多（删无关注记）、色彩可辨（色盲安全）、比例尺与指北不可省。
- 与 GIS 空间分析、WebGIS 开发同属空间簇；详版 uSkill 见关联。
