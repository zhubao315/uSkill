# 抖音短视频策略

description: |
  当用户需要制作抖音短视频、策划账号定位、优化推荐流量时使用此 Skill。
  触发词：'抖音'、'短视频'、'抖音运营'、'抖音涨粉'、'完播率'、'抖音算法'。
  不适用于小红书/B站（各有专属策略卡）。

# [[抖音短视频策略]]

## 🎯 目标

> 构建以完播率为核心的抖音内容生产体系，从选题、脚本、拍摄到发布形成标准化流程。

**核心价值**：抖音算法 = 完播率 × 互动率 × 转发率，本 Skill 将每个环节对齐这三个指标。

**适用场景**：
- 知识类短视频（技术科普/生活技巧）
- 个人 IP 打造（专业人设）
- 产品展示与种草
- 本地生活推广（北京探店/活动）

## 📋 执行步骤

### Step 1: 选题与钩子设计
1. **热点追踪** — 查看抖音热搜/挑战赛/热门 BGM，找可蹭的结合点
2. **钩子设计** — 前 3 秒必须完成：制造悬念/提出问题/展示结果/反常识
3. **信息密度规划** — 60 秒视频 = 3-4 个信息点，每点 15-20 秒
4. **检查点**：✅ 钩子是否能在 1 秒内抓住注意力？信息点是否足够紧凑？

### Step 2: 脚本与分镜
1. **口播脚本** — 逐字稿控制语速，60 秒约 180 字
2. **画面配合** — 每个信息点配对应画面，避免纯口播
3. **文字覆盖** — 关键数据/结论用大字覆盖，辅助理解
4. **检查点**：✅ 脚本是否无废话？画面和文字是否配合紧密？

### Step 3: 拍摄与剪辑
1. **节奏控制** — 每 3-5 秒一个画面切换，保持视觉新鲜感
2. **BGM 选择** — 热门 BGM 提升推荐概率，节奏与内容情绪匹配
3. **字幕必须** — 80% 用户静音刷视频，字幕是必备项
4. **检查点**：✅ 视频节奏是否紧凑？字幕是否清晰？BGM 是否合适？

### Step 4: 发布与投流
1. **标题优化** — 包含搜索关键词，长度 15-25 字
2. **标签策略** — 2 个热门标签 + 3 个精准标签 + 1 个品牌标签
3. **发布时间** — 工作日 12:00/18:00/21:00，周末 10:00/15:00/21:00
4. **检查点**：✅ 发布时间是否在高峰期？标签是否覆盖目标人群？

### Step 5: 数据复盘与迭代
1. **核心指标** — 24h 完播率、互动率、转发率
2. **流量来源** — 分析推荐页/关注页/搜索各占多少
3. **迭代方向** — 完播率低改钩子，互动率低改 CTA，转发率低改内容价值
4. **检查点**：✅ 是否记录了关键数据？下一篇是否基于数据调整？

## ⚠️ 异常处理

| 异常 | 条件 | 处理方式 |
|------|------|----------|
| 视频无推荐 | 播放量 <500 | 检查是否违规、修改封面标题重新发布 |
| 完播率低 | <20% | 缩短视频时长、加强前 3 秒钩子 |
| 互动率低 | <2% | 增加争议性观点、设计投票/提问环节 |
| 涨粉慢 | 单条视频涨粉 <50 | 强化人设一致性、增加系列内容 |

## 💬 沟通风格

### 语气锚点
- **直接**：不说"可能""也许"，直接给结论和数字
- **节奏感**：像短视频本身一样，信息密度高、节奏快
- **实战派**：每个建议都来自实际运营数据，不是理论推演

### 输出原则
- 脚本必须精确到字，控制语速和时长
- 画面描述具体到构图和运镜，不说"拍好看点"
- 数据驱动：每条建议附带平台数据支撑

### 风格禁区
- ❌ 禁止：建议搬运/洗稿其他创作者内容
- ❌ 禁止：使用违反平台规定的引流方式（如微信号外链）
- ⚠️ 谨慎：涉及医疗/金融/教育类内容需加风险提示

## 📝 自检清单

- [ ] 前 3 秒钩子是否足够强？
- [ ] 脚本是否无废话、信息密度高？
- [ ] 字数是否匹配目标时长？
- [ ] 字幕是否覆盖全视频？
- [ ] BGM 是否与内容情绪匹配？
- [ ] 标题是否包含搜索关键词？
- [ ] 标签是否覆盖热门+精准两个层级？
- [ ] 发布时间是否在流量高峰期？
