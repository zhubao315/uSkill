
# 三段论推理

> 亚里士多德提出的演绎推理基本形式——从两个前提推出一个必然结论。

## 结构

```
大前提：所有 M 是 P（一般性原理）
小前提：S 是 M（具体情况）
结论：  S 是 P（推导结果）
```

**经典示例**：
```
大前提：所有人都会死
小前提：苏格拉底是人
结论：  苏格拉底会死
```

## 三种格

| 格 | 大前提结构 | 小前提结构 |
|----|-----------|-----------|
| 第一格 | M-P | S-M |
| 第二格 | P-M | S-M |
| 第三格 | M-P | M-S |

## 有效 vs 无效

| 类型 | 示例 |
|------|------|
| **有效** | 所有 A 是 B，X 是 A → X 是 B |
| **无效（中项不周延）** | 所有猫是动物，所有狗是动物 → 狗是猫 |
| **无效（大项不当）** | 所有鸟会飞，企鹅不会飞 → 企鹅不是鸟 |

## 局限性

- 结论的正确性取决于前提的真实性
- 日常语言中很少有严格的全称命题
- 容易被表面合理但逻辑错误的论证欺骗

## 🔄 IF/THEN 决策分支

- IF 输入数据质量不足以支撑自动化决策 → THEN 转交人工判断，输出不确定性说明
- IF 执行过程中遇到未预期的异常 → THEN 记录异常 + 降级处理 + 升级给人类
- IF 输出结果置信度 < 0.6 → THEN 标记低置信度 + 要求人工验证
- ELSE（所有检查通过）→ THEN 输出结果 + 验证证据

## 🧪 Self-Play 测试用例

| # | 场景 | 输入 | 预期输出 | 验证点 |
|---|------|------|----------|--------|
| 1 | 正常执行 | 标准输入数据 | 符合预期的输出 | 格式正确 + 内容准确 |
| 2 | 边界输入 | 极端/空/超长输入 | 降级处理或错误提示 | 不崩溃 + 有明确反馈 |
| 3 | 数据缺失 | 缺少必填参数 | 参数补全提示 | 不编造数据 |
| 4 | 异常场景 | 非预期的输入类型 | 友好的错误处理 | 不泄露内部信息 |
| 5 | 并发场景 | 多个相同请求同时到达 | 结果一致或正确排队 | 无数据竞争 |

- 必填参数检查：缺失时返回明确错误提示

- 必含字段：status/message/data/timestamp

## 📊 三段论类型详解

### 直言三段论（Categorical Syllogism）
最经典的形式，使用直言命题（所有/有些/没有）：
- **AAA-1（Barbara）**：所有M是P，所有S是M → 所有S是P
- **EAE-1（Celarent）**：没有M是P，所有S是M → 没有S是P
- **AII-1（Darii）**：所有M是P，有些S是M → 有些S是P

### 假言三段论（Hypothetical Syllogism）
使用条件命题：
- **肯定前件式**：如果P则Q，P为真 → Q为真
- **否定后件式**：如果P则Q，Q为假 → P为假

### 选言三段论（Disjunctive Syllogism）
使用选言命题：
- **否定肯定式**：P或Q，P为假 → Q为真

## ⚠️ 常见谬误

| 谬误类型 | 表现 | 示例 |
|---------|------|------|
| 四项谬误 | 中项含义不一致 | "法律是严肃的，法官是严肃的，所以法官是法律" |
| 中项不周延 | 中项在两个前提中都不周延 | "所有狗是动物，所有猫是动物，所以所有猫是狗" |
| 肯定后件 | 从结果推出原因 | "如果下雨地会湿，地湿了，所以下雨了" |
| 否定前件 | 从原因否定推出结果否定 | "如果努力会成功，没努力，所以不会成功" |
