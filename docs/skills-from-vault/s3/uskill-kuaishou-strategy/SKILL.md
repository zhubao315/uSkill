# 快手运营策略

description: |
  当用户需要运营快手账号、制作下沉市场内容、进行直播带货时使用此 Skill。

# [[快手运营策略]]

## 🎯 目标

> 建立以信任和真实感为核心的快手运营体系，深耕下沉市场和社区粘性。

**核心价值**：快手的社交推荐权重高于抖音，"老铁"文化强调真实和信任，本 Skill 将内容策略对齐这一底层逻辑。

## 📥 输入

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|:----:|--------|------|
| `topic` | string | ✅ | — | 内容主题 |
| `content_type` | enum | ❌ | `"video"` | 类型：`video`（短视频）/ `live`（直播）/ `pic`（图文） |
| `niche` | string | ❌ | `"生活"` | 垂类：生活/三农/技能/美食/健身/手工艺 |
| `region_focus` | string | ❌ | `"全国"` | 目标地域：全国/特定城市/下沉市场 |

## 📋 执行步骤

### Step 1: 人设与定位
1. **真实人设** — 快手用户偏好真实、接地气的内容，避免过度包装
2. **垂类选择** — 选一个你真正擅长的领域，持续深耕
3. **差异化** — 在同类账号中找到独特切入角度
4. **检查点**：✅ 人设是否真实可信？是否有一技之长？

### Step 2: 内容制作
1. **真实感优先** — 不需要精美画质，但需要真实场景和真实情感
2. **故事化** — 用故事串联内容，比纯教学更有吸引力
3. **互动设计** — 在视频中提问、设置投票、邀请评论
4. **检查点**：✅ 内容是否足够真实？是否有故事性？

### Step 3: 发布与社区运营
1. **发布时间** — 7:00-8:00、12:00-13:00、19:00-21:00
2. **评论互动** — 快手用户重视创作者回复，每条评论都应认真对待
3. **同城推荐** — 开启同城可见，利用地理位置获取本地流量
4. **检查点**：✅ 是否及时回复评论？是否开启了同城？

### Step 4: 直播与变现
1. **直播节奏** — 固定时间开播，培养观众习惯
2. **互动玩法** — 连麦/PK/抽奖提升直播间活跃度
3. **变现路径** — 直播打赏 → 直播带货 → 品牌合作
4. **检查点**：✅ 直播时间是否固定？互动玩法是否丰富？

## ⚠️ 异常处理

| 异常 | 条件 | 处理方式 |
|------|------|----------|
| 播放量低 | <500 | 检查内容是否违规、优化标题封面 |
| 直播间没人 | 在线 <10 | 固定时间开播、邀请好友捧场、优化直播封面 |
| 粉丝流失 | 取关率 >5% | 检查内容质量、减少低质更新 |

## 💬 沟通风格

- **真实接地气**：用生活化语言，不说官方话
- **有温度**：像和邻居聊天，不像在录节目
- **有烟火气**：展示真实生活场景，不过度美化

## 📝 自检清单

- [ ] 内容是否真实接地气？
- [ ] 人设是否一致且有辨识度？
- [ ] 是否有互动引导设计？
- [ ] 发布时间是否在高峰期？
- [ ] 评论区是否及时回复？
- [ ] 直播时间是否固定？

## 🛡️ Three-Tier Boundaries `[v3新增]`

> 来源：addyosmani/agent-skills 的边界系统

- 输出结构化结果
- 检查常见错误

- 不跳过验证步骤
- 不在用户未确认时执行高风险操作
