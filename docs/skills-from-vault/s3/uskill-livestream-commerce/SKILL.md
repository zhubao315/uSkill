# 直播电商运营

## 🎯 目标

> 构建从选品、话术设计、直播执行到数据复盘的标准化直播电商运营体系。

**核心价值**：直播电商的核心是「人货场」匹配，本 Skill 将每个环节量化为可执行的标准动作。

## 📥 输入

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|:----:|--------|------|
| `products` | array | ✅ | — | 商品列表（名称/价格/卖点） |
| `platform` | enum | ❌ | `"douyin"` | 平台：`douyin` / `kuaishou` / `taobao` / `wechat` |
| `duration` | enum | ❌ | `"4h"` | 直播时长：`2h` / `4h` / `8h` |
| `host_type` | enum | ❌ | `"solo"` | 主播形式：`solo`（单人）/ `duo`（双人）/ `guest`（嘉宾） |
| `budget` | int | ❌ | `0` | 投流预算（元） |

## 📤 输出

```json
{
  "run_of_show": [
    {
      "time": "string — 时间节点",
      "action": "string — 执行动作",
      "product": "string — 对应商品",
      "script": "string — 话术要点"
    }
  ],
  "product_script": [{"name": "string", "hook": "string", "selling_points": ["string"], "closing": "string"}],
  "interactive_design": ["string — 互动节点设计"],
  "traffic_plan": "string — 投流节奏和预算分配",
  "post_live_checklist": ["string — 下播后复盘清单"]
}
```

## 📋 执行步骤

### Step 1: 选品与排品
1. **选品逻辑** — 引流款（低价高性价比）+ 利润款（高毛利）+ 形象款（品牌背书）
2. **排品节奏** — 开场引流款拉人气 → 中间利润款做转化 → 穿插福利款维持热度
3. **库存确认** — 提前确认库存充足，避免直播中缺货
4. **检查点**：✅ 选品是否有梯度？排品节奏是否合理？

### Step 2: 话术设计
1. **开场话术** — 30 秒内说清今天有什么福利，留住观众
2. **产品话术** — 痛点引入 → 产品展示 → 卖点讲解 → 价格对比 → 限时优惠
3. **逼单话术** — "最后 XX 件""倒计时 3 分钟""抢完恢复原价"
4. **互动话术** — "扣 1 价格""想要的打'想要'""猜猜多少钱"
5. **检查点**：✅ 话术是否有紧迫感？是否设计了互动节点？

### Step 3: 直播执行
1. **开播预热** — 提前 1-2 小时发布预告短视频
2. **节奏控制** — 每 15-20 分钟一个高潮点（福利/秒杀/抽奖）
3. **场控配合** — 助播配合上链接、改价、回复评论
4. **数据监控** — 实时关注在线人数/停留时长/转化率
5. **检查点**：✅ 预热是否到位？节奏是否紧凑？

### Step 4: 投流策略
1. **开播投流** — 前 30 分钟密集投流拉人气
2. **平稳期投流** — 人气下降时追加投流
3. **爆款投流** — 转化率高的商品追加投流
4. **检查点**：✅ 投流节奏是否与内容节奏匹配？

### Step 5: 复盘优化
1. **数据复盘** — 观看人数/停留时长/GPM/转化率/退货率
2. **话术优化** — 哪些话术转化率高，哪些需要调整
3. **选品优化** — 哪些商品卖得好，哪些需要替换
4. **检查点**：✅ 是否记录了关键数据？下一场是否调整？

## ⚠️ 异常处理

| 异常 | 条件 | 处理方式 |
|------|------|----------|
| 在线人数骤降 | 掉粉 >20% | 增加福利互动、调整话术节奏 |
| 转化率低 | <1% | 优化产品话术、调整排品顺序 |
| 退货率高 | >30% | 检查产品质量、优化产品描述准确性 |

## 💬 沟通风格

- **有激情**：直播间需要能量感，但不要过度喊叫
- **有信任**：像朋友推荐好物，不像硬广推销
- **有紧迫感**：利用限时/限量制造稀缺性

## 📝 自检清单

- [ ] 选品是否有引流款+利润款+形象款梯度？
- [ ] 话术是否有痛点→展示→优惠→逼单的完整链路？
- [ ] 是否设计了足够的互动节点？
- [ ] 开播前是否有预热？
- [ ] 投流节奏是否与内容节奏匹配？
- [ ] 下播后是否有数据复盘？
