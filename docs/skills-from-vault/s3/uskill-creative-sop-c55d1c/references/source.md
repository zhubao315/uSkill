# 葡萄酒品鉴：SOP体系

> 系统化品鉴葡萄酒的方法论，覆盖从开瓶到品鉴记录的完整流程。对应 [[2026年度目标成果与输出物（成果物映射）]] P4 交付物。

## 适用场景
- 日常品鉴与记录
- 家庭品鉴会组织
- 餐厅/酒展选酒决策
- 葡萄酒知识体系化积累

## 五大品鉴维度（WSET 框架）

### 1. 观色
- 颜色深度：清澈/浅/中等/深
- 色调：紫红→宝石红→石榴红→茶色（红葡萄酒）；青柠→柠檬→金黄→琥珀（白葡萄酒）
- 挂杯：酒泪流速（酒精度和糖分指示）

### 2. 闻香
- 状态：干净/有缺陷（TCA 软木塞味/氧化/还原）
- 强度：淡/中/浓郁
- 风味类别：
  - 一类香（葡萄品种）：果香、花香、草本
  - 二类香（酿造工艺）：橡木、烤面包、黄油
  - 三类香（陈年）：皮革、蘑菇、干果、蜂蜜

### 3. 品味
- 甜度：干→半干→半甜→甜
- 酸度：低→中→高（口水分泌量）
- 单宁：低→中→高（口腔干涩感）
- 酒体：轻→中→饱满（牛奶/水/奶油口感类比）
- 酒精：低→中→高（喉咙灼热感）
- 余味：短→中→长（风味停留秒数）

### 4. 结论
- 质量评价：差/可接受/好/很好/特级
- 适饮期：现在饮用/可陈年/需陈年
- 食物搭配建议

### 5. 记录归档
使用 [[SOP-33-五大维度品酒记录]] 格式，归档至 [[uSkill]]。

## 品鉴 SOP 流程

| 步骤 | 操作 | 工具 |
|------|------|------|
| 1 | 选酒、检查温度 | 温度计（红 16-18℃ / 白 8-12℃） |
| 2 | 开瓶、检查软木塞 | 海马刀、闻软木塞 |
| 3 | 观色→闻香→品味→结论 | WSET 品鉴卡 |
| 4 | 记录 | [[SOP-33-五大维度品酒记录]] |
| 5 | 食物搭配验证 | 边吃边感受风味变化 |

## 🛡️ Three-Tier Boundaries `[v3新增]`

> 来源：addyosmani/agent-skills 的边界系统

### ✅ Always do（自动执行）
- 执行核心功能（见原技能流程）
- 输出结构化结果
- 检查常见错误

### ⚠️ Ask first（先问再做）
- 用户意图不明确时
- 操作不可逆时
- 涉及外部系统时

### 🚫 Never do（绝对禁止）
- 不跳过验证步骤
- 不在用户未确认时执行高风险操作
- 不伪装成功（失败就上报）

## 🔒 Gated Workflow `[v3新增]`

> 来源：addyosmani 的门禁 + claude-skills 的 Agent Harness

```
DISCUSS → PLAN → EXECUTE → VERIFY → CLOSE
   ↓         ↓        ↓          ↓        ↓
 Context   方案     执行      证据     Done/
 Read     确认     任务      检查    Escalate
```

### Phase 1: DISCUSS
- [ ] 输出 Context Read 一行判断
- [ ] 确认用户意图
- [ ] 确认约束条件

### Phase 2: PLAN
- [ ] 制定执行方案
- [ ] 确认资源可用
- [ ] 人工审批计划

### Phase 3: EXECUTE
- [ ] 逐个任务实现
- [ ] 每步有输出记录

### Phase 4: VERIFY
- [ ] 检查核心输出
- [ ] 验证完整性
- [ ] 输出证据

### Phase 5: CLOSE
- [ ] 所有检查通过 → 标记完成
- [ ] 有未通过项 → 升级给人类
- [ ] 预算耗尽 → 强制升级，不伪装成功

## 🔄 IF/THEN 决策分支

- IF 输入数据质量不足以支撑自动化决策 → THEN 转交人工判断，输出不确定性说明
- IF 执行过程中遇到未预期的异常 → THEN 记录异常 + 降级处理 + 升级给人类
- IF 输出结果置信度 < 0.6 → THEN 标记低置信度 + 要求人工验证
- ELSE（所有检查通过）→ THEN 输出结果 + 验证证据

## 📋 Verification Evidence `[v3新增]`

> 来源：addyosmani 的证据要求 + claude-skills 的 verify

### 完成标志
- [ ] 核心输出已生成
- [ ] 输出格式符合预期
- [ ] 无明显错误

### 失败处理
- 输出不完整 → 继续补充，不标记完成
- 连续 3 次失败 → 升级给人类，附上当前状态
- 绝不伪装成功
