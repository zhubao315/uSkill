# SCQA 结构化表达

> 麦肯锡经典叙事框架——通过「情境→冲突→问题→回答」的结构让表达清晰有力。

## 框架结构

| 要素 | 英文 | 作用 | 示例 |
|------|------|------|------|
| **S** | Situation | 建立共识背景 | 「我们的用户增长连续 3 个季度停滞」 |
| **C** | Complication | 打破平衡的变化 | 「同时竞品推出了低价替代方案」 |
| **Q** | Question | 核心要回答的问题 | 「如何在不降价的情况下重获增长？」 |
| **A** | Answer | 你的解决方案 | 「通过差异化功能和社区运营建立护城河」 |

## 变体用法

- **ASC**：先说答案，再补背景（适合汇报，领导时间有限）
- **QSCA**：先抛问题，引发好奇（适合演讲/提案）
- **SQCA**：简化版，适合日常沟通

## 适用场景

- 邮件/报告/提案的开头段落
- 会议发言的结构化表达
- 产品 PRD 的背景描述
- 跨部门沟通对齐

## 与其他框架对比

| 框架 | 侧重点 |
|------|--------|
| SCQA | 叙事逻辑，适合「讲故事」 |
| PREP | 观点先行，适合「说服」 |
| STAR | 行为描述，适合「面试」 |

## 🔄 IF/THEN 决策分支

- IF 输入数据质量不足以支撑自动化决策 → THEN 转交人工判断，输出不确定性说明
- IF 执行过程中遇到未预期的异常 → THEN 记录异常 + 降级处理 + 升级给人类
- IF 输出结果置信度 < 0.6 → THEN 标记低置信度 + 要求人工验证
- ELSE（所有检查通过）→ THEN 输出结果 + 验证证据

## 🧪 Self-Play 测试用例

| # | 场景 | 输入 | 预期输出 | 验证点 |
|---|------|------|----------|--------|
| 1 | 正常执行 | 标准输入数据 | 符合预期的输出 | 格式正确 + 内容准确 |
| 2 | 边界输入 | 极端/空/超长输入 | 降级处理或错误提示 | 不崩溃 + 有明确反馈 |
| 3 | 数据缺失 | 缺少必填参数 | 参数补全提示 | 不编造数据 |
| 4 | 异常场景 | 非预期的输入类型 | 友好的错误处理 | 不泄露内部信息 |
| 5 | 并发场景 | 多个相同请求同时到达 | 结果一致或正确排队 | 无数据竞争 |


## 📊 执行规范

**输入验证**：
- 必填参数检查：缺失时返回明确错误提示
- 类型校验：参数类型不匹配时返回类型错误
- 范围校验：数值超出合理范围时返回范围提示
- 格式校验：不符合预期格式时给出格式示例

**执行约束**：
- 单次执行超时：30 秒（可配置）
- 最大重试次数：3 次
- 并发限制：同一资源不并发写入
- 幂等性：相同输入产生相同输出

**输出规范**：
- 格式：JSON 结构化输出
- 必含字段：status/message/data/timestamp
- 错误输出：error_code/error_message/suggestion
- 日志：执行过程关键节点记录

## 📈 质量指标

| 指标 | 计算方式 | 目标 | 告警阈值 |
|------|---------|:----:|:--------:|
| 成功率 | 成功次数 / 总执行次数 | ≥ 95% | < 90% |
| 平均耗时 | 总耗时 / 执行次数 | < 10s | > 30s |
| 错误率 | 错误次数 / 总执行次数 | < 5% | > 10% |
| 重试率 | 重试次数 / 总执行次数 | < 10% | > 20% |

## 📊 SCQA 应用场景

| 场景 | S（情境） | C（冲突） | Q（问题） | A（答案） |
|------|----------|----------|----------|----------|
| 产品提案 | 用户增长放缓 | 竞品推出新功能 | 如何提升竞争力？ | 推出差异化功能 |
| 技术方案 | 现有架构瓶颈 | 高并发性能下降 | 如何支撑 10x 流量？ | 引入缓存+异步架构 |
| 复盘报告 | Q1 目标完成 80% | 转化率低于预期 | 关键瓶颈在哪？ | 优化注册流程 |
| 商业计划 | 市场规模 100 亿 | 竞争格局分散 | 如何快速获客？ | PLG+社区驱动 |

### SCQA 变体

- **SCQA-R**：加入 Result（结果），用于复盘
- **SCQA-I**：加入 Implication（影响），强调紧迫性
- **SCQA-AI**：加入 Alternative + Implication，用于方案对比
