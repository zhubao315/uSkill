## 核心规则

1. **三脚架必备**：任何 >1s 曝光必须稳定
2. **低 ISO**：ISO 100-400 减少噪点
3. **小光圈**：f/8-f/16 获得星芒效果
4. **遥控/定时**：避免机震

## 实操步骤

1. 选点：高处俯瞰、车流密集路段、水面倒影
2. 参数：f/8-f/11，ISO 100，快门 5-30s
3. 对焦：手动对焦到无穷远，再回退一点
4. 拍摄：B 门或 T 门，遥控触发
5. 后期：降噪 + 色温调整 + 高光压制

## 进阶技法

- **车灯轨迹**：10-30s 曝光，车流密集处
- **丝绸流水**：ND64 滤镜，30s+ 曝光
- **星轨**：多张叠加，每张 30s，连续拍摄 1h+

## 器材建议

- 超广角镜头 14-24mm
- 碳纤维三脚架
- ND 滤镜套装（ND8/ND64/ND1000）
- 遥控快门线

## 🔒 Gated Workflow `[v3新增]`

> 来源：addyosmani 的门禁 + claude-skills 的 Agent Harness

```
DISCUSS → PLAN → EXECUTE → VERIFY → CLOSE
   ↓         ↓        ↓          ↓        ↓
 Context   方案     执行      证据     Done/
 Read     确认     任务      检查    Escalate
```

### Phase 1: DISCUSS
- [ ] 输出 Context Read 一行判断
- [ ] 确认用户意图
- [ ] 确认约束条件

### Phase 2: PLAN
- [ ] 制定执行方案
- [ ] 确认资源可用
- [ ] 人工审批计划

### Phase 3: EXECUTE
- [ ] 逐个任务实现
- [ ] 每步有输出记录

### Phase 4: VERIFY
- [ ] 检查核心输出
- [ ] 验证完整性
- [ ] 输出证据

### Phase 5: CLOSE
- [ ] 所有检查通过 → 标记完成
- [ ] 有未通过项 → 升级给人类
- [ ] 预算耗尽 → 强制升级，不伪装成功

## 🔄 IF/THEN 决策分支

- IF 创意方向不明确（用户仅说"帮我拍"）→ THEN 先确认拍摄主体/场景/风格偏好，再给出方案
- IF 场景光线不足（ISO > 3200 或快门 < 1/60）→ THEN 推荐补光方案或调整拍摄时间
- IF 预算有限（设备/场地受限）→ THEN 给出低成本替代方案，不推荐超出预算的设备
- ELSE（条件充足）→ THEN 输出完整拍摄方案 + 参数建议
