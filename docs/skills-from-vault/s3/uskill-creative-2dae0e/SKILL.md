# 快门速度

# 快门速度

> 控制曝光时间——快门打开到关闭的时长。它决定"时间被如何记录在画面上"：冻结，还是流动。

## 🎯 目标

让拍摄者在按下快门前，能根据**主体运动速度 × 期望的动感表达 × 手持/三脚架条件**反推该用多快的快门，并与光圈、ISO 协同完成正确曝光（见 [[uSkill-creative-曝光三角]]）。

交付目标：
- 给出"主体 → 建议快门区间"的可执行映射。
- 区分"意外模糊"（失败）与"有意拖影"（表达）。
- 在手持边界内保证成片清晰。

## 📥 输入

| 参数 | 含义 | 来源 |
|------|------|------|
| `subject_speed` | 主体运动速度（静止/慢/中/快/极快） | 场景判断 |
| `intent` | 表达意图（冻结 / 拖影 / 光轨） | 创作构思 |
| `focal_length` | 当前焦距 mm | 镜头 |
| `stabilization` | 防抖（无 / 镜头 / 机身 IBIS） | 器材 |
| `light` | 环境照度 | 测光 |
| `nd_filter` | 是否使用减光镜 | 器材 |

## 📤 输出

```json
{
  "subject": "奔跑的狗",
  "subject_speed": "fast",
  "intent": "freeze",
  "recommended_shutter": "1/1000",
  "min_handheld": "1/50",
  "need_nd": false,
  "paired_aperture": "f/4",
  "paired_iso": 400
}
```

## 🔄 执行流程

1. **定意图**：先决定要"冻住"还是"拉出速度感"，意图优先于参数。
2. **判速度**：估计主体速度档位（静止/慢/中/快/极快）。
3. **选基准**：按映射表取快门基准（见使用示例）。
4. **校手持**：用倒数法则 `1/焦距` 校验手持下限，有 IBIS 可放慢约 3–4 档。
5. **协曝光**：固定快门后，用光圈（见 [[uSkill-creative-光圈]]）与 ISO（见 [[uSkill-creative-iso感光度]]）补足曝光；日光长曝必须加 ND（见 [[uSkill-creative-长曝光]]）。
6. **验成片**：回放放大检查运动部位是否达意图。

### 决策分支（IF / THEN）

- IF `intent` = freeze 且 `subject_speed` = fast → THEN 快门 ≥ 1/1000，必要时升 ISO 保曝光。
- IF `recommended_shutter` < `min_handheld`（1/焦距）且未上三脚架 → THEN 强制开启 IBIS 或提高 ISO/开大光圈，否则判定为"意外模糊风险"。
- IF `intent` = 光轨/丝绢流水 且环境为白天 → THEN 必须加 ND 减光镜，否则快门无法降到 1/4s 以下。
- IF `focal_length` ≥ 200mm 手持 → THEN 手持下限收紧到 1/250 以上，极快主体用 1/2000。
- IF 使用闪光灯 → THEN 快门不得快于闪光同步速度（约 1/200–1/250），否则出现黑边。

## ⚠️ 异常处理

- **光比极大（逆光）**：先保快门冻住主体，欠曝部分交后期（见 [[摄影后期处理]]）或补闪。
- **暗光且不能升 ISO**：上三脚架转长曝，放弃手持冻结。
- **主体速度估错**：连拍 + 张数冗余，回放挑最稳一帧。
- **ND 遗漏致过曝**：立即降 ISO / 缩光圈，或改到阴影处。
- **手机无原生快门优先**：用 Pro 模式手动设快门，其余交给自动。

## 💡 使用示例

**场景 A｜冻结**：拍摄奔跑的狗（fast），意图 freeze，50mm + IBIS。
→ 基准 1/1000；手持下限 1/50，安全；配对 f/4、ISO 400。成片四爪清晰。

**场景 B｜丝绢流水**：日间瀑布，意图拖影，意图 1/2s。
→ 白天直拍必过曝 → 加 ND1000，快门 1/2s，f/11，ISO 100（见 [[uSkill-creative-风光摄影]]）。

**场景 C｜车流光轨**：夜晚天桥，意图光轨。
→ 三脚架，快门 15s，f/8，ISO 100，多帧堆栈降噪（见 [[uSkill-creative-夜景长曝光摄影]]）。

### 快门速度标尺（常用档位与用途）

| 快门 | 典型用途 |
|------|------|
| 1/8000–1/2000 | 极快运动：飞鸟、体育运动、溅水瞬态 |
| 1/1000–1/500 | 奔跑宠物、儿童、街道快动作 |
| 1/250–1/125 | 闪光同步上限、一般手持安全线 |
| 1/60–1/30 | 摇拍（panning）拉出背景速度感 |
| 1/15–1/4 | 弱光手持极限、流水初阶拖影 |
| 1/2–2s | 丝绢流水、云雾（需 ND + 三脚架） |
| 4–30s | 车流光轨、星空、星轨（B 门更长） |

### 倒数法则与防抖

手持最慢快门 ≈ 1 / 焦距（mm）。50mm 约 1/50，200mm 约 1/200。机身 IBIS 通常可放慢 3–4 档（如 1/50 → 约 1/6），但主体运动速度仍是冻结的上限。长曝（>1s）会出现**互易率失效**：胶片/部分传感器长时间曝光需补偿，数码影响较小但热噪上升，靠多帧堆栈降噪（见 [[摄影后期处理]]）。

实战口诀：**先定意图，再选快门，最后用光圈/ISO 补曝光**。意图错则全盘错——把"冻结"设成 1/30 必糊，把"光轨"设成 1/1000 必黑。

### 与曝光三角的协同

固定快门后，曝光缺口由光圈与 ISO 补足：要更慢快门且不过曝 → 缩光圈（见 [[uSkill-creative-光圈]]，代价是景深变深、见 [[uSkill-creative-景深]]）或降 ISO（见 [[uSkill-creative-iso感光度]]）；要更快快门且不过暗 → 开大光圈或升 ISO（代价是噪点）。三者见 [[uSkill-creative-曝光三角]] 的统一约束。

> 注意：1/8000 以上电子快门在拍快速旋转体（螺旋桨、风扇）会出现**滚动快门扭曲**；此类题材改用机械快门或降速。
