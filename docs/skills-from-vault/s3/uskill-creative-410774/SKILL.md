# 葡萄酒产国选酒策略

> 基于产国/产区的选酒方法论。对应 [[2026年度目标成果与输出物（成果物映射）]] P4 交付物（之二）。

## 选酒三步法

### 第一步：定风格偏好
| 偏好 | 推荐产国 |
|------|----------|
| 果味浓郁、无需陈年 | 🇨🇱 智利 / 🇦🇺 澳大利亚 |
| 优雅细腻、层次复杂 | 🇫🇷 法国 / 🇮🇹 意大利 |
| 物美价廉、性价比 | 🇪🇸 西班牙 / 🇵🇹 葡萄牙 |
| 新世界探索 | 🇳🇿 新西兰 / 南非 / 阿根廷 |
| 中国本土 | 🇨🇳 宁夏贺兰山东麓 / 新疆 |

### 第二步：看葡萄品种
- 赤霞珠 Cabernet Sauvignon → 波尔多 / 纳帕谷 / 智利
- 黑皮诺 Pinot Noir → 勃艮第 / 新西兰 / 俄勒冈
- 霞多丽 Chardonnay → 勃艮第白 / 加州 / 澳大利亚
- 雷司令 Riesling → 德国摩泽尔 / 阿尔萨斯
- 马尔贝克 Malbec → 阿根廷门多萨
- 桑娇维塞 Sangiovese → 意大利基安蒂

### 第三步：查年份
- 使用 Wine Searcher / Vivino 查年份评分
- 好年份 ≠ 最高分，而是符合该产区的经典风格
- 入门选热情年份（果味成熟），进阶选经典年份（结构平衡）

## 超市选酒速查

| 预算 | 策略 | 示例产区 |
|------|------|----------|
| < 100 元 | 智利/澳洲入门级 | 中央山谷 / 南澳 |
| 100-200 元 | 西班牙 Crianza / 新西兰 | 里奥哈 / 马尔堡 |
| 200-400 元 | 法国村庄级 / 意大利 DOCG | 波尔多村庄 / 基安蒂 |
| > 400 元 | 名庄入门 / 勃艮第大区 | 二级庄 / 勃艮第村级 |

## 🛡️ Three-Tier Boundaries `[v3新增]`

> 来源：addyosmani/agent-skills 的边界系统

### ✅ Always do（自动执行）
- 执行核心功能（见原技能流程）
- 输出结构化结果
- 检查常见错误

### ⚠️ Ask first（先问再做）
- 用户意图不明确时
- 操作不可逆时
- 涉及外部系统时

### 🚫 Never do（绝对禁止）
- 不跳过验证步骤
- 不在用户未确认时执行高风险操作
- 不伪装成功（失败就上报）

## 🔒 Gated Workflow `[v3新增]`

> 来源：addyosmani 的门禁 + claude-skills 的 Agent Harness

```
DISCUSS → PLAN → EXECUTE → VERIFY → CLOSE
   ↓         ↓        ↓          ↓        ↓
 Context   方案     执行      证据     Done/
 Read     确认     任务      检查    Escalate
```

### Phase 1: DISCUSS
- [ ] 输出 Context Read 一行判断
- [ ] 确认用户意图
- [ ] 确认约束条件

### Phase 2: PLAN
- [ ] 制定执行方案
- [ ] 确认资源可用
- [ ] 人工审批计划

### Phase 3: EXECUTE
- [ ] 逐个任务实现
- [ ] 每步有输出记录

### Phase 4: VERIFY
- [ ] 检查核心输出
- [ ] 验证完整性
- [ ] 输出证据

### Phase 5: CLOSE
- [ ] 所有检查通过 → 标记完成
- [ ] 有未通过项 → 升级给人类
- [ ] 预算耗尽 → 强制升级，不伪装成功

## 🔄 IF/THEN 决策分支

- IF 输入数据质量不足以支撑自动化决策 → THEN 转交人工判断，输出不确定性说明
- IF 执行过程中遇到未预期的异常 → THEN 记录异常 + 降级处理 + 升级给人类
- IF 输出结果置信度 < 0.6 → THEN 标记低置信度 + 要求人工验证
- ELSE（所有检查通过）→ THEN 输出结果 + 验证证据
