# Options Basic Strategies

> **角色**: 期权策略师 | **核心工具**: AI大模型, Black-Scholes计算器, 期权链数据 | **效率目标**: 系统化理解期权定价与基础交易策略

## 🎯 目标

构建**期权投资基础知识体系**，掌握Black-Scholes定价模型、希腊字母风险管理，以及备兑开仓、保护性看跌等基础期权策略的设计与执行。

**适用场景**:
1. **持仓保护** — 为现有股票持仓购买看跌期权对冲下行风险
2. **增强收益** — 对长期持仓使用备兑开仓策略获取额外权利金
3. **波动率交易** — 基于波动率判断构建跨式/宽跨式策略
4. **定向投机** — 用有限风险表达方向性观点

## 📋 执行步骤

### 阶段一：期权定价基础

1. **理解期权基本概念** — 看涨/看跌期权、实值/平值/虚值、内在价值与时间价值
2. **Black-Scholes定价模型** — 掌握公式核心变量：
   - 标的价格(S)、行权价(K)、无风险利率(r)、到期时间(T)、波动率(σ)
3. **隐含波动率分析** — 计算当前隐含波动率(IV)相对于历史波动率(HV)的位置
4. **波动率曲面理解** — 分析不同行权价和到期日的IV分布（微笑/偏斜）

### 阶段二：希腊字母风险管理

5. **Delta (Δ)** — 衡量标的价格变动$1时期权价格的变动量
6. **Gamma (Γ)** — 衡量Delta对标的价格的敏感度
7. **Theta (Θ)** — 衡量时间流逝对期权价格的影响（时间衰减）
8. **Vega (ν)** — 衡量隐含波动率变动1%时期权价格的变动量
9. **组合希腊字母** — 计算整个策略组合的净希腊字母暴露

### 阶段三：基础策略构建

10. **备兑开仓 (Covered Call)** — 持有标的 + 卖出虚值看涨期权
    - 适用：温和看涨，愿意限制上行换取权利金收入
    - 最佳环境：低波动、横盘震荡
11. **保护性看跌 (Protective Put)** — 持有标的 + 买入看跌期权
    - 适用：看涨但担心短期下行
    - 最佳环境：高不确定性、重大事件前
12. **牛市价差 (Bull Spread)** — 买入低行权价看涨 + 卖出高行权价看涨
    - 适用：温和看涨，限制成本
13. **跨式策略 (Straddle)** — 同时买入看涨和看跌（同行权价）
    - 适用：预期大幅波动但方向不确定

### 阶段四：执行与管理

14. **选择合约** — 基于流动性（成交量、持仓量）、价差、IV选择最优合约
15. **情景分析** — 计算不同标的价格、波动率、时间流逝下的损益
16. **制定管理计划** — 设定止盈止损条件、展期策略、提前平仓规则

## ✅ 检查清单

- [ ] 是否理解每个策略的最大盈利、最大亏损和盈亏平衡点

## ⚠️ 常见陷阱

| 陷阱 | 说明 | 规避方法 |
|------|------|---------|
| 忽视时间衰减 | 买入期权长期持有被Theta吃掉价值 | 期权买方控制持有期（< 60天） |
| 卖出无保护期权 | 裸卖Call风险无限 | 新手只做Covered Call或价差策略 |
| 忽略流动性 | 交易冷门合约导致无法平仓 | 选择持仓量>1万、日成交>1000的合约 |
| IV过高时买入 | 高IV环境下买期权成本过高 | 参考IV Rank，低于50%时才买入 |
| 过度杠杆 | 小资金买大量期权 | 单策略不超过账户的5-10% |
| 不设止损 | 期权可能归零 | 亏损50%强制止损 |

```
   ↓         ↓        ↓          ↓        ↓

 Read     确认     任务      检查    Escalate
```

## 🔄 IF/THEN 决策分支

- IF 输入数据质量不足以支撑自动化决策 → THEN 转交人工判断，输出不确定性说明
- IF 执行过程中遇到未预期的异常 → THEN 记录异常 + 降级处理 + 升级给人类
- IF 输出结果置信度 < 0.6 → THEN 标记低置信度 + 要求人工验证
- ELSE（所有检查通过）→ THEN 输出结果 + 验证证据
