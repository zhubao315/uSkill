## 🔄 IF/THEN 决策分支

- IF 输入数据质量不足以支撑自动化决策 → THEN 转交人工判断，输出不确定性说明
- IF 执行过程中遇到未预期的异常 → THEN 记录异常 + 降级处理 + 升级给人类
- IF 输出结果置信度 < 0.6 → THEN 标记低置信度 + 要求人工验证
- ELSE（所有检查通过）→ THEN 输出结果 + 验证证据


## ⚠️ 异常处理

| 异常类型 | 触发条件 | 处理方式 |
|---------|---------|---------|
| 输入缺失 | 必填参数为空 | 提示用户补充输入 |
| 格式错误 | 输入格式不符合要求 | 给出格式示例 + 重新输入 |
| 执行超时 | 单次执行超过阈值 | 降级处理 + 记录日志 |
| 结果异常 | 输出明显不合理 | 标记异常 + 人工复核 |

**降级策略**：
- 当 AI 辅助不可用时，回退到手动执行模式
- 当数据源不可用时，使用缓存数据并标注时效性
- 当遇到未知异常时，记录现场 + 升级给人类
