# IP管理与知识资产运营

> 个人知识产权（IP）和数字资产的系统化管理方法。对应 [[2026年度目标成果与输出物（成果物映射）]] D4 交付物。

## 适用场景
- 个人知识产品的确权与保护
- 数字资产（文章/代码/音乐/设计）的管理与授权
- 个人品牌 IP 的使用许可与合规审查
- AI Agent 协作创作中的权责界定

## 核心原则
1. **先做确权**：所有创作成果第一时间登记——平台首发时间戳、区块链存证、本地镜像存档
2. **分层管理**：开源级 / 共享级 / 私有级 三个使用层级，AI Agent 自动识别访问权限
3. **追溯全链**：每份输出物记录来源、修改历史、协作方
4. **定期审计**：季度扫描知识资产状态，更新使用授权

## 执行流程

### 一、资产盘点（建册）
1. 扫描全库输出物 → 按类型归类（文章/代码/音乐/设计/课程）
2. 标记每项资产的确权状态（已确权 / 待确权 / 无需确权）
3. 填写 [[知识产权]] 资产登记表
4. AI 辅助生成确权报告

### 二、分类与授权
| 层级 | 范围 | 授权 | 示例 |
|------|------|------|------|
| 🟢 开源 | 全公开 | MIT / CC BY 4.0 | uLife 框架、SOP |
| 🟡 共享 | 知识库内 | CC BY-NC | 读书笔记、分析报告 |
| 🔴 私有 | 仅个人 | 保留所有权利 | 交易记录、个人数据 |

### 三、AI Agent 合规执行
1. Agent 引用知识库内容时自动检测授权层级
2. 生成外部输出时附加正确版权声明
3. 第三方请求引用时启动授权审批流程

### 四、季度审查
- 新增资产确权
- 过期授权更新
- 使用情况统计（引用次数、转载记录）

## 🛡️ Three-Tier Boundaries `[v3新增]`

> 来源：addyosmani/agent-skills 的边界系统

### ✅ Always do（自动执行）
- 执行核心功能（见原技能流程）
- 输出结构化结果
- 检查常见错误

### ⚠️ Ask first（先问再做）
- 用户意图不明确时
- 操作不可逆时
- 涉及外部系统时

### 🚫 Never do（绝对禁止）
- 不跳过验证步骤
- 不在用户未确认时执行高风险操作
- 不伪装成功（失败就上报）

## 🔒 Gated Workflow `[v3新增]`

> 来源：addyosmani 的门禁 + claude-skills 的 Agent Harness

```
DISCUSS → PLAN → EXECUTE → VERIFY → CLOSE
   ↓         ↓        ↓          ↓        ↓
 Context   方案     执行      证据     Done/
 Read     确认     任务      检查    Escalate
```

### Phase 1: DISCUSS
- [ ] 输出 Context Read 一行判断
- [ ] 确认用户意图
- [ ] 确认约束条件

### Phase 2: PLAN
- [ ] 制定执行方案
- [ ] 确认资源可用
- [ ] 人工审批计划

### Phase 3: EXECUTE
- [ ] 逐个任务实现
- [ ] 每步有输出记录

### Phase 4: VERIFY
- [ ] 检查核心输出
- [ ] 验证完整性
- [ ] 输出证据

### Phase 5: CLOSE
- [ ] 所有检查通过 → 标记完成
- [ ] 有未通过项 → 升级给人类
- [ ] 预算耗尽 → 强制升级，不伪装成功

## 🔄 IF/THEN 决策分支

- IF 输入数据质量不足以支撑自动化决策 → THEN 转交人工判断，输出不确定性说明
- IF 执行过程中遇到未预期的异常 → THEN 记录异常 + 降级处理 + 升级给人类
- IF 输出结果置信度 < 0.6 → THEN 标记低置信度 + 要求人工验证
- ELSE（所有检查通过）→ THEN 输出结果 + 验证证据

## 🎯 技能概述

> 本技能提供 投资理财 领域的标准化操作流程，帮助用户高效完成相关任务。

**核心价值**：将复杂操作标准化为可重复执行的步骤，降低出错率，提升效率。

**适用场景**：
1. 日常操作执行
2. 新手快速上手
3. 质量一致性保证

## 📋 Verification Evidence `[v3新增]`

> 来源：addyosmani 的证据要求 + claude-skills 的 verify

### 完成标志
- [ ] 核心输出已生成
- [ ] 输出格式符合预期
- [ ] 无明显错误

### 失败处理
- 输出不完整 → 继续补充，不标记完成
- 连续 3 次失败 → 升级给人类，附上当前状态
- 绝不伪装成功
