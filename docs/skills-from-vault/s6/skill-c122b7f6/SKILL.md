## 一句话

少决策、大决策、高确定性决策——像等待击球点一样等待赔率与安全边际同时到位的时刻。

## 要点
- 三少原则：减少交易频率 · 单次决策加大权重 · 只在高确定性区间出手（芒格/巴菲特击球区比喻）。
- 与安全边际联动：价格显著低于内在价值才进入击球区；否则宁愿空仓看球。
