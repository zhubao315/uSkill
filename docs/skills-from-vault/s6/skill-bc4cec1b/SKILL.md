# 财报解读

## 一句话

三表勾稽 + 关键指标趋势：先看现金流与利润的背离，再拆业务质量，最后才对标估值。

## 要点
- 顺序：现金流量表（真实造血）→ 利润表（含金量与一次性项目）→ 资产负债表（杠杆与存货风险）→ 附注（藏污纳垢处）。
- 常用勾稽：净现比、应收/存货周转、经营现金流 vs 净利润、有息负债率。
