# 盘中行情监控

> 实时跟踪市场动态、个股异动的监控系统和应对策略。

## 监控维度

| 维度 | 指标 |
|------|------|
| **指数** | 上证/深证/创业板/恒生 |
| **个股** | 涨跌幅/成交量/换手率 |
| **板块** | 行业轮动/概念热度 |
| **资金** | 北向资金/融资余额 |

## 异动判断

| 信号 | 含义 |
|------|------|
| 放量突破 | 可能启动行情 |
| 缩量下跌 | 惜售，可能企稳 |
| 大单流入 | 主力关注 |
| 跌停板打开 | 多空博弈激烈 |

## 📊 执行规范

- 必填参数检查：缺失时返回明确错误提示
- 类型校验：参数类型不匹配时返回类型错误
- 范围校验：数值超出合理范围时返回范围提示
- 格式校验：不符合预期格式时给出格式示例

**执行约束**：
- 单次执行超时：30 秒（可配置）
- 最大重试次数：3 次
- 并发限制：同一资源不并发写入
- 幂等性：相同输入产生相同输出

**输出规范**：
- 格式：JSON 结构化输出
- 必含字段：status/message/data/timestamp
- 错误输出：error_code/error_message/suggestion
