# 定投策略优化

> Dollar-Cost Averaging——通过定期定额投资降低择时风险，优化买入成本。

## 基础策略

| 策略 | 说明 |
|------|------|
| **普通定投** | 固定时间、固定金额 |
| **价值平均** | 市场下跌多投，上涨少投 |
| **目标止盈** | 达到目标收益率后赎回重新开始 |

## 优化方向

1. **估值定投**：PE 低于历史均值时加投
2. **分批止盈**：不一次性卖出，分 3-5 批
3. **标的轮动**：在股债之间动态调整
4. **费率优化**：选择低费率渠道

## 关键指标

| 指标 | 说明 |
|------|------|
| **持仓成本** | 平均买入价格 |
| **年化收益** | IRR 计算的真实收益 |
| **最大回撤** | 承受的最大亏损 |
