# 个人财富管理体系

## 🎯 目标

> 构建从现金流管理到资产配置的完整个人财务系统。

**核心价值**：大多数人把「财富管理」等同于「炒股」，忽略了更基础的现金流和资产配置。本 Skill 从底层向上构建完整的财务系统。

**适用场景**：
- 个人/家庭财务规划
- 投资组合构建与再平衡
- 现金流优化与债务管理
- 财务自由度评估

## 📋 执行步骤

### Step 1: 财务体检
1. **资产负债表** — 梳理所有资产和负债
2. **现金流分析** — 收入/支出/净现金流
3. **储蓄率计算** — 净现金流 / 收入
4. **应急资金** — 是否有 6 个月支出的应急储备
5. **检查点**：✅ 净资产是否准确？应急资金是否充足？

### Step 2: 资产配置设计
1. **风险评估** — 基于年龄/收入/负债评估风险承受能力
2. **配置方案** — 现金/债券/股票/另类的比例
3. **标的选择** — 每类资产的具体标的
4. **再平衡规则** — 偏离目标配置多少时触发再平衡
5. **检查点**：✅ 配置是否匹配风险偏好？是否有再平衡规则？

### Step 3: 现金流优化
1. **支出审计** — 找到可以优化的支出
2. **收入增长** — 主动收入和被动收入的增长策略
3. **税务优化** — 合法的税务规划
4. **检查点**：✅ 储蓄率是否有提升空间？是否有税务优化机会？

### Step 4: 系统化执行
1. **自动投资** — 设置自动定投/再平衡
2. **定期审查** — 每月/每季度的财务回顾
3. **目标追踪** — 财务自由度的量化追踪
4. **检查点**：✅ 是否有自动化机制？是否有定期审查？

## ⚠️ 边界约束

**硬性约束（必须遵守）**：
1. 不得建议超过风险承受能力的投资
2. 必须保留应急资金，不得全部投入
3. 投资建议仅供参考，不构成投资建议

**软性约束（建议遵守）**：
1. 先保障后增值（保险/应急/储蓄优先）
2. 长期投资为主，短期投机为辅

**人工兜底点**：
- 当涉及重大财务决策时，**必须**建议咨询专业顾问
- 当市场剧烈波动时，**必须**建议保持冷静不追涨杀跌

## ⚠️ 异常处理

| 异常 | 条件 | 处理方式 |
|------|------|----------|
| 储蓄率过低 | <20% | 优先优化支出结构 |
| 应急资金不足 | <3 月支出 | 优先建立应急储备 |
| 投资亏损 | 单只 >20% | 评估是否止损或持有 |


### 降级策略
- 当数据不足时，基于已有数据给出保守建议并标注置信度
- 当无法自动化时，输出分析框架供人工填充

## 💬 沟通风格

- **系统思维**：用「财务系统」而非「炒股技巧」描述
- **长期视角**：强调复利效应和长期主义
- **务实导向**：给出可执行的具体步骤
