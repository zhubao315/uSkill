# cognitive flow state activation

# 心流状态激活法

## 🎯 目标
帮助使用者在工作、学习、创作等场景中主动触发心流状态，进入全神贯注的最佳体验。

## 📥 输入
- 当前要执行的任务
- 当前技能水平评估
- 可用时间和环境条件

## 📤 输出
- 心流触发条件清单
- 执行计划
- 反馈机制设计

## 📋 执行步骤

### Step 1: 任务明确化
- 将模糊目标拆解为具体、可衡量的子目标
- 每个子目标应在15-45分钟内可完成
- 明确完成标准

### Step 2: 难度校准
- 评估当前技能水平（1-10分）
- 设定目标难度 = 技能水平 + 1（略高于当前能力）
- 如果任务过大，拆解到合适粒度

### Step 3: 环境准备
- 消除干扰源（手机静音、关闭通知）
- 准备计时工具
- 准备进度记录工具

### Step 4: 反馈机制
- 设定检查点（每15-20分钟）
- 使用可见化进度条或清单
- 记录质量感受

### Step 5: 执行与调整
- 启动专注计时
- 全身心投入任务
- 如果感到无聊→提高难度
- 如果感到焦虑→降低难度

### Step 6: 心流后处理
- 记录心流持续时间
- 记录触发条件
- 反思哪些条件最有效
- 更新个人心流档案

## ⚠️ 异常处理
- 如果30分钟未进入心流，暂停检查难度是否匹配
- 如果频繁被打断，切换到更封闭的环境
- 如果感到疲惫，先休息再尝试

## 🛡️ Three-Tier Boundaries `[v3新增]`

> 来源：addyosmani/agent-skills 的边界系统

### ✅ Always do（自动执行）
- 执行核心功能（见原技能流程）
- 输出结构化结果
- 检查常见错误

### ⚠️ Ask first（先问再做）
- 用户意图不明确时
- 操作不可逆时
- 涉及外部系统时

### 🚫 Never do（绝对禁止）
- 不跳过验证步骤
- 不在用户未确认时执行高风险操作
- 不伪装成功（失败就上报）

## 🔒 Gated Workflow `[v3新增]`

> 来源：addyosmani 的门禁 + claude-skills 的 Agent Harness

```
DISCUSS → PLAN → EXECUTE → VERIFY → CLOSE
   ↓         ↓        ↓          ↓        ↓
 Context   方案     执行      证据     Done/
 Read     确认     任务      检查    Escalate
```

### Phase 1: DISCUSS
- [ ] 输出 Context Read 一行判断
- [ ] 确认用户意图
- [ ] 确认约束条件

### Phase 2: PLAN
- [ ] 制定执行方案
- [ ] 确认资源可用
- [ ] 人工审批计划

### Phase 3: EXECUTE
- [ ] 逐个任务实现
- [ ] 每步有输出记录

### Phase 4: VERIFY
- [ ] 检查核心输出
- [ ] 验证完整性
- [ ] 输出证据

### Phase 5: CLOSE
- [ ] 所有检查通过 → 标记完成
- [ ] 有未通过项 → 升级给人类
- [ ] 预算耗尽 → 强制升级，不伪装成功

## 🔄 IF/THEN 决策分支

- IF 输入数据质量不足以支撑自动化决策 → THEN 转交人工判断，输出不确定性说明
- IF 执行过程中遇到未预期的异常 → THEN 记录异常 + 降级处理 + 升级给人类
- IF 输出结果置信度 < 0.6 → THEN 标记低置信度 + 要求人工验证
- ELSE（所有检查通过）→ THEN 输出结果 + 验证证据
