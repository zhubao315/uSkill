
# MBTI人格分析

> 基于荣格心理类型的四维八极人格分类框架，用于理解个体认知偏好与行为模式。

## 四个维度

| 维度 | 极A | 极B | 核心区别 |
|------|-----|-----|---------|
| 能量来源 | **E** 外倾 | **I** 内倾 | 注意力指向外部世界 vs 内心世界 |
| 信息获取 | **S** 感觉 | **N** 直觉 | 关注具体事实 vs 抽象可能性 |
| 决策方式 | **T** 思维 | **F** 情感 | 逻辑分析 vs 价值判断 |
| 生活态度 | **J** 判断 | **P** 感知 | 有序计划 vs 灵活适应 |

## 16 种类型速查

**分析家（NT）**：INTJ · INTP · ENTJ · ENTP
**外交家（NF）**：INFJ · INFP · ENFJ · ENFP
**守护者（SJ）**：ISTJ · ISFJ · ESTJ · ESFJ
**探险家（SP）**：ISTP · ISFP · ESTP · ESFP

## 实践应用

- **团队协作**：理解不同成员的信息处理和决策偏好
- **沟通适配**：对 T 型讲逻辑，对 F 型讲影响
- **职业匹配**：NT 适合战略/技术，SJ 适合管理/运营

## 局限性

- MBTI 测的是偏好非能力，同一类型的人能力差异巨大
- 二分法过于简化，实际是连续光谱
- 重测一致性约 50%，稳定性存疑

## 🔄 IF/THEN 决策分支

- IF 输入数据质量不足以支撑自动化决策 → THEN 转交人工判断，输出不确定性说明
- IF 执行过程中遇到未预期的异常 → THEN 记录异常 + 降级处理 + 升级给人类
- IF 输出结果置信度 < 0.6 → THEN 标记低置信度 + 要求人工验证
- ELSE（所有检查通过）→ THEN 输出结果 + 验证证据

## 🧪 Self-Play 测试用例

| # | 场景 | 输入 | 预期输出 | 验证点 |
|---|------|------|----------|--------|
| 1 | 正常执行 | 标准输入数据 | 符合预期的输出 | 格式正确 + 内容准确 |
| 2 | 边界输入 | 极端/空/超长输入 | 降级处理或错误提示 | 不崩溃 + 有明确反馈 |
| 3 | 数据缺失 | 缺少必填参数 | 参数补全提示 | 不编造数据 |
| 4 | 异常场景 | 非预期的输入类型 | 友好的错误处理 | 不泄露内部信息 |
| 5 | 并发场景 | 多个相同请求同时到达 | 结果一致或正确排队 | 无数据竞争 |


## 📊 执行规范

**输入验证**：
- 必填参数检查：缺失时返回明确错误提示
- 类型校验：参数类型不匹配时返回类型错误
- 范围校验：数值超出合理范围时返回范围提示
- 格式校验：不符合预期格式时给出格式示例

**执行约束**：
- 单次执行超时：30 秒（可配置）
- 最大重试次数：3 次
- 并发限制：同一资源不并发写入
- 幂等性：相同输入产生相同输出

**输出规范**：
- 格式：JSON 结构化输出
- 必含字段：status/message/data/timestamp
- 错误输出：error_code/error_message/suggestion
- 日志：执行过程关键节点记录
