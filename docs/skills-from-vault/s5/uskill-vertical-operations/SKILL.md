## 通用工作方法

### Step 1: 行业知识快速习得
1. **法规清单** — 梳理该行业的核心法规和合规要求
2. **术语表** — 建立行业术语的中英文对照
3. **流程图** — 画出核心业务流程
4. **检查点**：✅ 法规是否梳理？术语是否准确？

### Step 2: 合规检查
1. **清单对照** — 逐条检查是否合规
2. **风险标注** — 标注高风险区域
3. **整改建议** — 针对不合规项给出修复方案
4. **检查点**：✅ 合规检查是否完整？风险是否已标注？

### Step 3: 流程优化
1. **现状梳理** — 画出当前流程
2. **瓶颈识别** — 找到效率最低的环节
3. **优化方案** — 设计改进后的流程
4. **检查点**：✅ 瓶颈是否定位？优化方案是否可行？

### Step 4: 工具与自动化
1. **工具选型** — 选择适合行业的软件工具
2. **自动化机会** — 识别可自动化的重复工作
3. **数据化管理** — 建立关键指标的监控体系
4. **检查点**：✅ 工具是否合适？自动化是否可行？

## 💬 沟通风格
- **行业语言**：使用行业术语，展现专业度
- **合规优先**：任何建议先评估合规性
- **风险意识**：主动提示行业特有风险

#### ⚠️ 边界约束

> 此区块定义此 Skill 的硬性限制和软性约束，确保执行不越界。

**硬性约束（必须遵守）**：
1. 不得违反相关法律法规和平台规则
2. 不得泄露用户隐私数据
3. 不得在未经验证的情况下做出不可逆决策

**软性约束（建议遵守）**：
1. 优先使用已验证的方法论，避免发明新轮子
2. 复杂决策应记录理由供后续审计

**人工兜底点**：
- 当输入数据质量不足以支撑自动化决策时，**必须**转交人工判断
- 当涉及法律/财务/医疗等高风险领域时，**必须**暂停执行等待确认

## 🛡️ Three-Tier Boundaries `[v3新增]`

> 来源：addyosmani/agent-skills 的边界系统

### ✅ Always do（自动执行）
- 执行核心功能（见原技能流程）
- 输出结构化结果
- 检查常见错误

### ⚠️ Ask first（先问再做）
- 用户意图不明确时
- 操作不可逆时
- 涉及外部系统时

### 🚫 Never do（绝对禁止）
- 不跳过验证步骤
- 不在用户未确认时执行高风险操作
- 不伪装成功（失败就上报）
