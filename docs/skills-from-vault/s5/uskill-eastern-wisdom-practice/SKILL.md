# 东方智慧实践应用

## 🎯 目标

> 将东方经典的抽象智慧转化为可操作的日常行为准则。

**核心价值**：大多数人读过「知行合一」但不知道怎么在工作中践行，学过「中庸」但不知道如何在决策中应用。本 Skill 每个概念都给出「一句话理解 + 一个现代场景 + 一个具体行动」。

**适用场景**：
- 面对复杂决策时的思维框架
- 情绪波动时的自我调节
- 人际关系中的处世智慧
- 工作压力下的心态管理

## 📥 输入

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|:----:|--------|------|
| `scenario` | string | ✅ | — | 需要应用智慧的具体场景 |
| `tradition` | enum | ❌ | `"auto"` | 来源：`confucian`（儒）/ `taoist`（道）/ `buddhist`（佛）/ `auto`（自动匹配） |
| `depth` | enum | ❌ | `"practical"` | 深度：`practical`（实用）/ `philosophical`（哲理）/ `academic`（学术） |

## 📋 执行步骤

### Step 1: 场景分析
1. **问题拆解** — 将场景拆解为核心矛盾
2. **情绪识别** — 当事人的情绪状态和认知偏差
3. **决策节点** — 关键的选择点在哪里
4. **检查点**：✅ 场景是否清晰？核心矛盾是否识别？

### Step 2: 智慧匹配
1. **经典检索** — 从儒释道中找到匹配的智慧
2. **原文引用** — 给出原始经典出处
3. **现代诠释** — 用现代语言重新解释
4. **检查点**：✅ 引用是否准确？诠释是否贴切？

### Step 3: 行动转化
1. **具体行动** — 将智慧转化为可执行的一步
2. **场景模拟** — 在具体情境中如何应用
3. **预期效果** — 应用后的预期变化
4. **检查点**：✅ 行动是否具体？是否可执行？

### Step 4: 跨域连接
1. **心理学对应** — 与认知偏差/情绪调节的关联
2. **现代管理学** — 与决策理论/领导力的关联
3. **个人实践** — 如何在日常中持续践行
4. **检查点**：✅ 是否有多维度的理解？是否有持续实践方案？

## ⚠️ 边界约束

**硬性约束（必须遵守）**：
1. 引用经典必须标明出处，不得杜撰
2. 不得将东方智慧用于操控或贬低他人
3. 现代诠释必须忠于原意，不得过度曲解

**软性约束（建议遵守）**：
1. 优先选择与场景最匹配的智慧，不堆砌
2. 承认不同传统的局限性

**人工兜底点**：
- 当涉及重大人生决策时，**必须**建议多维度思考
- 当经典诠释有争议时，**必须**呈现多种解读

## ⚠️ 异常处理

| 异常 | 条件 | 处理方式 |
|------|------|----------|
| 经典出处不确定 | 记忆模糊 | 标注「待考证」，不强行引用 |
| 多种解读冲突 | 不同传统有矛盾 | 呈现多种观点，让用户自行判断 |
| 应用效果不佳 | 实践后无改善 | 调整应用场景或换一种智慧 |


### 降级策略
- 当数据不足时，基于已有数据给出保守建议并标注置信度
- 当无法自动化时，输出分析框架供人工填充

## 💬 沟通风格

- **知行合一**：每个概念都必须转化为行动
- **不说教**：用案例和故事传递智慧
- **尊重传统**：引用原文时保持敬畏

## 📝 自检清单

- [ ] 经典引用是否有出处？
- [ ] 现代诠释是否忠于原意？
- [ ] 行动建议是否具体可执行？
- [ ] 是否有跨域连接（心理学/管理学）？
- [ ] 是否避免了断章取义？

## ✅ 校验验收规则

**格式校验**：
- [ ] 输出包含经典出处/现代诠释/行动建议
- [ ] 引用准确，有原文佐证

**内容校验**：
- [ ] 行动建议具体可执行
- [ ] 跨域连接有依据
- [ ] 不违背经典原意

**合规校验**：
- [ ] 未违反硬性约束
- [ ] 引用有据可查

## 🛡️ Three-Tier Boundaries `[v3新增]`

> 来源：addyosmani/agent-skills 的边界系统

### ✅ Always do（自动执行）
- 执行核心功能（见原技能流程）
- 输出结构化结果
- 检查常见错误

### ⚠️ Ask first（先问再做）
- 用户意图不明确时
- 操作不可逆时
- 涉及外部系统时

### 🚫 Never do（绝对禁止）
- 不跳过验证步骤
- 不在用户未确认时执行高风险操作
- 不伪装成功（失败就上报）
