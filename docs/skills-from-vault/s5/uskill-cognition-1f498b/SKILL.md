# 间隔重复系统设计

艾宾浩斯遗忘曲线揭示：遗忘不是记忆的失败，而是大脑的节能机制——不用的信息自动清理。间隔重复是在大脑即将遗忘的临界点重新激活记忆，以最小的复习投入获得最大的长期记忆收益。

## 核心方法

1. **复习节奏设计** — 基于遗忘曲线制定渐进间隔：第 1 天 → 第 3 天 → 第 7 天 → 第 14 天 → 第 30 天 → 第 90 天。这个节奏覆盖了记忆从短期到长期的完整固化路径。工具可用 Anki、RemNote 或 Obsidian 插件。

2. **主动回忆优先** — 复习时不看原文，强制从记忆中提取答案。卡片设计原则：正面是问题/提示，背面是答案/要点。**阅读是假复习**——只有主动回忆才能强化神经通路。

3. **原子化卡片设计** — 每张卡片只问一个问题，只覆盖一个知识点。复合知识拆解为多张卡片。一条经验法则：如果你能在 5 秒内回答，卡片大小合适；如果需要 30 秒以上，需要拆分。

4. **最小阻力的捕获** — 在阅读或学习时，立即将关键知识点做成卡片格式，而不是先记笔记再转卡片。间隔重复系统的最大挑战不是复习，而是坚持——减少从"学到"到"进卡"的步骤。

5. **渐进合并** — 随着理解加深，将相关的原子卡片逐步合并为一张更综合的卡片。从"什么是资产负债表"和"什么是利润表"到"三张报表如何联系起来"。卡片不是静态的，它会随着你的理解而进化。

## 关键认知

间隔重复系统本质上是**用时间换效率**——单次复习时间短（30 秒/卡），但需要长期坚持。大多数人失败不是方法不对，而是缺乏前半年的坚持。前 3 个月是最痛苦的适应期，撑过去后复习量会大幅下降。

## 🛡️ Three-Tier Boundaries `[v3新增]`

> 来源：addyosmani/agent-skills 的边界系统

### ✅ Always do（自动执行）
- 执行核心功能（见原技能流程）
- 输出结构化结果
- 检查常见错误

### ⚠️ Ask first（先问再做）
- 用户意图不明确时
- 操作不可逆时
- 涉及外部系统时

### 🚫 Never do（绝对禁止）
- 不跳过验证步骤
- 不在用户未确认时执行高风险操作
- 不伪装成功（失败就上报）

## 🔒 Gated Workflow `[v3新增]`

> 来源：addyosmani 的门禁 + claude-skills 的 Agent Harness

```
DISCUSS → PLAN → EXECUTE → VERIFY → CLOSE
   ↓         ↓        ↓          ↓        ↓
 Context   方案     执行      证据     Done/
 Read     确认     任务      检查    Escalate
```

### Phase 1: DISCUSS
- [ ] 输出 Context Read 一行判断
- [ ] 确认用户意图
- [ ] 确认约束条件

### Phase 2: PLAN
- [ ] 制定执行方案
- [ ] 确认资源可用
- [ ] 人工审批计划

### Phase 3: EXECUTE
- [ ] 逐个任务实现
- [ ] 每步有输出记录

### Phase 4: VERIFY
- [ ] 检查核心输出
- [ ] 验证完整性
- [ ] 输出证据

### Phase 5: CLOSE
- [ ] 所有检查通过 → 标记完成
- [ ] 有未通过项 → 升级给人类
- [ ] 预算耗尽 → 强制升级，不伪装成功

## 🔄 IF/THEN 决策分支

- IF 输入数据质量不足以支撑自动化决策 → THEN 转交人工判断，输出不确定性说明
- IF 执行过程中遇到未预期的异常 → THEN 记录异常 + 降级处理 + 升级给人类
- IF 输出结果置信度 < 0.6 → THEN 标记低置信度 + 要求人工验证
- ELSE（所有检查通过）→ THEN 输出结果 + 验证证据
