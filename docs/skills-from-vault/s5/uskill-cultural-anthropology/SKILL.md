# 跨文化人类学洞察

description: |
  当用户需要理解特定文化背景下的行为模式、进行跨文化沟通、本地化策略时使用此 Skill。
  触发词：'文化分析'、'跨文化'、'人类学'、'本地化'、'文化差异'、'anthropology'。

# [[跨文化人类学洞察]]

## 🎯 目标

> 基于人类学方法论提供文化洞察，避免跨文化沟通中的误解和误判。

**核心价值**：文化差异不是「对方不讲道理」，而是「对方有不同的道理」。本 Skill 将文化分析结构化，帮助在不同文化语境中有效沟通和行动。

## 📥 输入

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|:----:|--------|------|
| `culture_context` | string | ✅ | — | 目标文化/地区 |
| `analysis_type` | enum | ❌ | `"communication"` | 类型：`communication`（沟通）/ `business`（商务）/ `product`（产品本地化）/ `user_research`（用户研究） |
| `specific_question` | string | ❌ | — | 具体问题 |

## 📤 输出

```json
{
  "cultural_insight": {
    "core_values": ["string — 该文化核心价值观"],
    "communication_style": "string — 沟通风格特点",
    "business_norms": "string — 商务惯例",
    "taboos": ["string — 文化禁忌"]
  },
  "practical_recommendations": [{"context": "string", "recommendation": "string", "reason": "string"}],
  "avoid": ["string — 绝对不要做的事"]
}
```

## 📋 执行步骤

### Step 1: 文化框架分析
1. **霍夫斯泰德维度** — 权力距离/个人主义/不确定性规避等
2. **高语境 vs 低语境** — 沟通中隐含信息的比例
3. **时间观念** — 单线程/多线程时间观
4. **检查点**：✅ 是否用了结构化框架？是否避免了刻板印象？

### Step 2: 行为模式分析
1. **沟通风格** — 直接/间接、正式/非正式
2. **决策方式** — 个人/集体、快速/共识
3. **关系构建** — 先做事还是先交朋友
4. **检查点**：✅ 分析是否基于具体场景？是否区分了代际差异？

### Step 3: 实践建议
1. **场景化建议** — 针对具体场景给出行动建议
2. **禁忌清单** — 列出绝对不要做的事
3. **沟通模板** — 提供文化适配的沟通话术
4. **检查点**：✅ 建议是否具体可执行？是否有沟通模板？

### Step 4: 持续学习
1. **反馈收集** — 实践后收集文化方的反馈
2. **修正迭代** — 根据反馈修正文化假设
3. **案例积累** — 记录成功的跨文化沟通案例
4. **检查点**：✅ 是否有反馈机制？案例是否积累？

## ⚠️ 异常处理

| 异常 | 条件 | 处理方式 |
|------|------|----------|
| 文化误读 | 造成误解 | 立即道歉，了解对方真实意图 |
| 代际差异 | 年轻人与长辈文化不同 | 区分代际差异，不一概而论 |
| 地域差异 | 同一国家内部差异大 | 细化到具体地区/城市 |

## 💬 沟通风格

- **尊重为先**：不说「落后」，说「不同」
- **具体场景**：不给泛泛的文化描述，给具体场景的行动建议
- **动态视角**：文化是变化的，不基于过时的刻板印象
