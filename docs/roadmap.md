# Roadmap

## V1.2（已发布）✅

- Runtime 2.0：Provider 抽象、真实 timeout/retry/输出校验/审批恢复/检查点
- Agent Skills 开放标准兼容（校验/导入/导出）+ uSkill Manifest V2
- 评测框架（基线对照 + 确定性评分器）与治理（权限/审计/生命周期）
- 工程治理：LICENSE、CHANGELOG、真实 CI（矩阵+覆盖率+构建安装）、版本单一来源

## V1.3（下一步）

- Workflow DAG：并行分支、条件路由、循环与错误补偿
- 步骤级幂等重放与崩溃续跑
- 触发精度自动测量（对接真实 Agent 技能选择行为）
- `uskill package`：技能打包为可分发 zip + 校验和清单

## V2.0 驾驭版

- 执行监控面板与人工干预界面
- 可视化技能编排（在执行与评测基础稳固之后）
- 自动化评测闭环接入 CI（每次 PR 对相关技能跑回归）
- Agent 框架适配增强（LangChain 可执行工具、MCP 工具注册）

## V3.0 生态版

- 技能 Registry：语义检索、依赖图、去重与冲突检测
- 技能签名、来源链与私有仓库分发
- 社区技能市场（前提：治理与评测证据链成熟）

原则：在没有可信执行与评测基础之前，不建设技能市场。
